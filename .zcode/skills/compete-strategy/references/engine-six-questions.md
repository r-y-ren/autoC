## 真实导读（kagriculture 引擎 kagriculture.py 1086 行，七段）

来源：`kaggle_environments` wheel 内场景文件（2026-09-19 逐行核验）。每段格式：**代码说什么 → 因此我们做什么**。

### ① 定价函数（`market_price`，~192 行）——问 1

```python
def market_price(item, inventory, params=None):
    p = (params or MARKET_PARAMS)[item]
    ...
    if inventory < I0:
        price = base + amp * _shape(f, I0 - inventory, T)   # 稀缺加价
    else:
        price = base - amp * _shape(f, inventory - I0, T)   # 过剩减价
    return max(PRICE_FLOOR, int(round(price)))
```

说什么：价格**只是共享库存的确定函数**，无随机数；参数表写死（base/I0/T/形状）；注释里 T 的定义="一块田 24 天产能"——引擎作者拿生产规模校准价格敏感度。
因此做什么：①价格预测类学习**出局**（不用预测，公式直接算——实证 LSTM 连 persistence 基线都打不过）②终局清算可精确推演→做**离线求解器**③真问题是**控制库存轨迹**（价格是果、库存是因）。

### ② 市场撮合循环（`_process_market`，~544 行）——问 2

```python
"""Per-unit lockstep: at each step, quote both players' current-unit
   prices, then commit both."""
queues.append(q[:max_orders])          # 每拍最多 10 单，超出静默截断
# Both players see the same pre-commit inventory for this unit.
```

说什么：双方订单**逐单位锁步撮合**，同一库存报价、交替成交——对手的卖单直接压低你这一拍的成交价；每拍 10 单上限静默截断。
因此做什么：①对手建模从可选变**必选**（耦合点在代码里）②动作空间极小（10 单/拍），拼单子质量不拼数量③超前控制要考虑对手反推。

### ③ 静默失败（`_apply_unit_action`，~313 行）——问 3

```python
"""Invalid / illegal actions are silent no-ops."""
```

说什么：非法动作静默跳过、超限静默截断——引擎**永不报错**。

## 无源码时怎么办（反事实实验清单）

拿不到引擎实现（闭源如金铲铲）时，把六问改写成**可实验问题**逐个测：
1. 计分口径：用极端构造局验证分数公式（分数是不是钱的线性函数？库存计不计价？）
2. 交互耦合：镜像局对照（双方同动作 vs 单方变招，观察差分）——对手在哪拍影响你
3. 失败语义：故意发非法动作，看回放里是跳过还是报错
4. 时间边界：跨日/跨回合边界行为逐拍核对
5. 信息结构：对比回放里"你看到的"vs"事后公开的全量"，列出隐藏字段
6. 随机源：同种子重放（确定性？）；换种子对照（哪些环节分叉）——分叉点=随机源全集
原则：**社区攻略当"待验证假设"，反事实实验当事实**。
