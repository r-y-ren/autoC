## build.py 设计（确定性构建器）

- **构建前检（修订 3）**：扫描 9 个模块的顶层名字全集，**重名即 fail**（扁平命名空间下后合并模块会静默遮蔽先合并同名定义，必须前置拦截）。
- 固定拓扑序：`constants → telemetry → observer → strategy → mission → solver → executor → market → entry`（entry 恒最后）。import 时副作用已核验仅三处且自足：`_WHEAT_FARM_PLAN` 双行赋值（仅依赖常量）、`_FIB_CUM` 循环（自足）、dict 初始化——其余全是 def，运行期解析，顺序无关。
- 模块间插 `# ===== src/<name>.py =====` 分隔注释；显式 `encoding="utf-8"`、LF 字节写盘。
- 内建后检：`compile()`；AST 顶层 callable 清单最后一个是 `agent`；import 白名单 {copy, math}；**参照集 ⊆ 构建集** 名字 diff（只报缺失不报新增）；**"当前阶段无模块引用 `_execute_routes`"**（占位零引用断言）。
- **`--check` 模式**：重建到内存与盘上 main.py 字节比对（防手改漂移），固化为常驻测试 `tests/test_build_determinism.py`。
- **末尾打印产物双哈希（修订 6）**：sha256 与 canonical LF sha256，直接供身份链重登记抄录，消除手工计算错误。

## 风险与对策

- 档案头丢失/被改写 → 三块逐字节并入头模板 + AST 检查显式比对 module docstring。
- import 时副作用顺序 → 已核验三处自足；smoke/contract 测试兜底。
- 扁平命名空间静默遮蔽 → 构建前顶层重名检测 fail-fast。
- Windows CRLF/编码 → build.py 显式 LF/utf-8 + 路径级 .gitattributes。
- 身份链漂移 → build.py 直印双哈希 + 重登记 + check 脚本（先例 000b8bc）。
- 手滑改行为 → AST 等价（参照集逐名）+ 回放 A/B（动作+订单双序列）双保险；现有测试零修改即全绿为硬线。
