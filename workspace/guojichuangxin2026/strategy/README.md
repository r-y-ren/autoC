# 安航云盾演示系统（材料冲刺版）

> 面向队员查阅的功能说明，零术语。技术细节见同目录 `requirements.md` 与 `frontier-tech.md`。

## 工作流程

1. **打开演示**：在一台电脑上运行启动脚本，浏览器打开本地页面，就能看到"安航云盾地面管理平台"。
2. **仿真飞机起飞**：演示用一架仿真无人机（不是真飞机），它按乡村配送航线飞行：从配送站起飞 → 爬升 → 巡航 → 投递 → 返航。
3. **我们"使坏"**：在飞行途中人为制造三种危险——
   - 电池越掉越快、还顶着逆风（危险慢慢积累）；
   - 一个电机突然出问题（危险瞬间发生）；
   - 无人机和地面之间的无线链路被别的信号挤占（用一台手机开热点打流量就能模拟，完全合法）。
4. **系统提前反应**：机载程序持续盯着一百多项飞行数据。对慢慢积累的危险，它要**提前 5 秒以上**喊"再飞就不安全了"，并算出"返航还够不够电、附近哪里能备降"；对瞬间发生的危险，它要在 **0.2 秒内**确认"是电机坏了"，立刻给出处置建议。
5. **页面实时显示**：风险有多高（正常→关注→预警→严重→紧急五档）、为什么（哪项数据异常）、还剩多少安全时间、建议怎么办（减速/返航/备降）。旁边还有一张"频谱瀑布图"，能看到手机热点把 2.4G 频段挤占的实时画面。
6. **事后回放**：每次飞行的事件像录像一样能回放——什么时间出现什么风险、系统当时怎么判断、依据是什么，一条时间线看完，方便答辩时讲清楚。

## 项目功能

- **实时风险监视**：仿真飞行中持续刷新电量、链路、导航、姿态四类风险，页面仪表盘实时可见。
- **提前预警**：对电量衰减、链路变差这类"慢危险"，提前给出预警并估计剩余安全时间。
- **快速确认突发故障**：对电机异常这类"快危险"，两百毫秒内确认故障类型。
- **处置建议**：根据风险等级和任务阶段，建议减速、返航、备降或降落，并说明理由；系统只给建议，不直接抢飞控的控制权。
- **风险解释**：每个告警都列出"证据"——是哪几项数据、超了什么线，答辩时经得起追问。
- **频谱监视**：用一台无线电接收设备（USRP B210）监听无人机遥控/图传频段，看到干扰和拥挤，页面显示实时频谱瀑布图。
- **事件回放**：按时间线回放整次飞行的风险判断和处置过程。
- **实测数字**：每次演示运行的真实成绩（提前量、确认耗时等）自动记录存档，写进材料里的每个数字都有据可查。

## 这个版本不做什么

不飞真飞机（等有成果后向导师申请硬件）、不控制仿真机做自动处置（只出建议）、不做多品牌飞控适配（演示只接 PX4 仿真）、不做多机。
