## T1 共形预测校准层——给风险概率上"统计保险"

**是什么**：计划书 4.2 现在用保序回归校准概率（"校准过的概率"）。共形预测是在模型输出外再套一层统计后处理：不改模型，只拿一小份校准数据，把点预测变成**带覆盖率保证的区间**——例如"以 90% 的统计保证，未来 5 秒进入危险状态的概率在这个区间内"。

**为什么值得**：这是 2024–2026 年时序不确定性度量的热点方向（NeurIPS 2025、ICML 2025、ICLR 2026 都有专题工作），答辩时有两问它都能接：评委问"你的概率可信吗"→回答"有有限样本覆盖率保证，实测覆盖率在此"；问"误报怎么权衡"→回答"覆盖率-区间宽度的权衡曲线我们实测过"。模型无关、后处理实现、边缘开销可忽略——低成本高辨识度。

**计划书落点**：
- 4.2 节"验证集采用保序回归校准概率" → "保序回归校准 + 共形预测区间（有限样本覆盖率保证），覆盖率与区间宽度按风险类型分别报告"；
- 7.3 消融试验增加一组"去共形层"对照；
- 5.1 技术创新段补一句差异化表述。

**实现方案**：inductive split conformal（约百行 Python，PyTorch DataLoader 后处理钩子）；校准集来自 SITL 运行留出集；二期可升级 adaptive conformal 应对分布漂移（在线适应）。训练在 RTX 4070 笔记本，推理随 TCN 上 Jetson Orin NX。

## T2 链路一致性检测（DroneMA 式）——链路健康从"断没断"到"被没被干扰/欺骗"

**是什么**：计划书 4.1 的链路健康度基于协议层（遥测到达间隔、序号丢包、信号质量）。补强：用 RSSI（信号强度）时序推算无人机距离的变化趋势，与 GNSS 真实距离互相校验——两者不一致，就是链路被干扰、被中继欺骗或异常退化的物理层证据。该法只需正常样本即可训练（适配攻击样本稀缺的现实）。

**为什么值得**：KB 卡 DroneMA 论文用 **Pixhawk + Jetson + MAVLink** 实飞验证——与我们硬件栈完全同构，论文报告检出率约 92.78%（论文报告值，非我方实测；引用时标注）。它回答的是计划书现在没正面回答的问题："RSSI 看着正常，链路就正常吗？"——乡村场景里 2.4G 频段拥挤恰恰是这种"隐性退化"。

**计划书落点**：
- 4.1 链路健康度定义增加"RSSI-距离一致性"物理层证据；
- 4.2 突发故障通道特征列表加入一致性残差（进 CUSUM）；
- 5.1 技术创新与 5.3 竞争分析（"单项故障诊断"行）补充差异点。

**实现方案**：pymavlink 收 RSSI/GPS → 统计基线（IQR 自适应阈值，DroneMA 论文同款起步）→ 一致性残差进 R3 突发通道；GRU 版（论文方法）作为二期升级。演示级用统计基线即可出"链路退化注入 → 触发链路事件"的实测记录。

**来源**：KB 技术卡 `li2025DroneMADroneMobility` DroneMA：移动性一致性驱动的无人机 AI 欺骗检测（RSSI 时序 GRU 距离趋势预测 + 一致性校验 + IQR 自适应阈值；Pixhawk+Jetson Nano+MAVLink 实飞验证；库内 provenance）。

## T3 SDR 频谱感知站——把"可控链路衰减"从脚本模拟升级为真实射频级

**是什么**：用 USRP B210（清单现有，K7 优化版，56 MHz 实时带宽）+ 2.4G 双频胶棒天线做**只收不发**的遥测频段频谱监测：能量检测 + 占用率统计 + 实时瀑布图，作为独立于机载链路遥测的第二证据源接入地面平台。

**为什么值得**：
1. **验证可信度**：计划书 7.1 的"可控链路衰减"场景，现在只能靠脚本丢包模拟；有 SDR 后可以做真实射频级的拥塞/干扰观察（演示用手机热点打 2.4G 流量=完全合法的干扰源），"干扰发生了 → 频谱占用率抬升 → 机载链路质量下降 → 系统预警"整条证据链全部实测——这是答辩现场最直观的一段。
2. **学术对齐**：USRP B210 正是 2025–2026 年无人机射频监测研究的标准平台（见来源），方法学有直接文献可引。
3. **双战役互借力**：隔壁 chuangxin2026 战役（禾策同队的另一项目"无人机通信链路电磁干扰测试平台"）做干扰发射/测试侧，本战役做感知侧——GNU Radio/UHD 代码栈、标定方法、甚至频谱数据两战役复用；材料叙事互补（一攻一防）。

**计划书落点**：
- 4.1 新增"地面频谱感知"小节（物理层链路健康证据源）；
- 3.1 产品组成表"地面管理平台"行交付内容加入频谱监测选件；
- 7.1 场景表"通信质量下降/可控链路衰减"改为 SDR 真实射频注入；
- 7.4 指标表链路类指标补充"频谱占用率/干扰检出"实测口径。

**实现方案**：UHD Python API 采谱（56 MHz 带宽覆盖 2.4G ISM 全频段；衰减器+负载做校准，清单现有）→ FFT 能量/占用率特征 → WebSocket 推 Web 瀑布图 → 阈值告警进地面平台事件流。跑在高性能笔记本（USB 3.0 直连 B210）。

**来源**（均为 2026-10-03 抓取）：
- Saber 2026, Design and development of an SDR-based system for real-time RF drone detection（USRP B210 平台实时射频无人机检测与分类）：https://pmc.ncbi.nlm.nih.gov/articles/PMC13260802/
- Șorecău 2026, Wideband Monitoring System of Drone Emissions, MDPI Drones 10(2):117（B210 宽带监测、50 MHz 采样）：https://www.mdpi.com/2504-446X/10/2/117
- IEEE Spectrum, Spectral Monitoring for Drone Defense（USRP+GNU Radio 频谱监测实战）：https://spectrum.ieee.org/spectral-monitoring-for-drone-defense-applications

## 附：演示地基事实（PX4 仿真与故障注入，支撑三场景）

以下为 PX4 官方文档实抓（2026-10-03，https://docs.px4.io/main/en/simulation/ ）：
- **故障注入**：PX4 提供官方 failure injection（`/main/en/debug/failure_injection.html`：传感器/执行器级故障注入）与 failsafe 仿真（`/main/en/simulation/failsafes.html`：GPS 失效、电池耗尽等安全失效场景触发）——三场景（低电量+逆风、电机故障、链路退化）的注入机制官方原生支持，无需自造。
- **仿真器选型**：Gazebo（新版，官方推荐，多机/ROS 支持）为主，SIH（轻量无头、零外部依赖、可直接跑在飞控硬件上 SYS_HITL=2）为低配机备选——两台笔记本都能跑演示，断网可用。

## 合规与边界注记

3. **数字纪律**：DroneMA 92.78% 等论文数字引用时一律标"论文报告值"；我方材料中的性能数字只出自 metrics 实测（评审规则：技术参数须真实可追溯）。
