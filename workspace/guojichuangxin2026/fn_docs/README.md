# 安航云盾演示系统（材料冲刺版）

> 面向队员查阅的功能说明，零术语。本文件在需求变更时才更新，平时保持静态。
> （2026-10-03 任务重开版：上一版因流程违规作废，本版经两轮确认式拷问重新定稿。）

## 工作流程

1. **打开演示**：在一台电脑上运行启动脚本，浏览器打开本地页面，就能看到"安航云盾地面管理平台"。
2. **仿真飞机起飞**：演示用一架仿真无人机（不是真飞机），按乡村配送航线飞行：从配送站起飞 → 爬升 → 巡航 → 投递 → 返航。
3. **我们"使坏"**：在飞行途中人为制造三种危险——
   - 电池越掉越快、还顶着逆风（危险慢慢积累）；
   - 一个电机突然出问题（危险瞬间发生）；
   - 无人机和地面之间的无线链路被别的信号挤占（用一台手机开热点打流量就能模拟，完全合法）。
4. **系统提前反应**：机载程序持续盯着一百多项飞行数据。对慢慢积累的危险，它要**提前 5 秒以上**喊"再飞就不安全了"，并算出"返航还够不够电、附近哪里能备降"；对瞬间发生的危险，它要在 **0.2 秒内**确认"是电机坏了"，立刻给出处置建议。
5. **页面实时显示**：风险有多高（正常→关注→预警→严重→紧急五档）、为什么（哪项数据异常）、还剩多少安全时间、建议怎么办（减速/返航/备降）。旁边还有一张"频谱瀑布图"——如果频谱设备（USRP B210）已接入，能看到手机热点把 2.4G 频段挤占的实时画面；设备不在时用录好的数据回放，画面一样，来源会如实标注。
6. **操控测试（控制台）**：演示全程可以只用浏览器操作——选场景、点起飞、按按钮注入危险、拖滑杆调强度、拖时间轴回放，**不碰终端不碰代码**。界面先把功能做全做稳（这最重要），好看是加分项，有余力再打磨。
7. **事后回放**：每次飞行的事件像录像一样能回放——什么时间出现什么风险、系统当时怎么判断、依据是什么，一条时间线看完，方便答辩时讲清楚。

## 项目功能

- **实时风险监视**：仿真飞行中持续刷新电量、链路、导航、姿态四类风险，页面实时可见。
- **提前预警**：对电量衰减、链路变差这类"慢危险"，提前给出预警并估计剩余安全时间。
- **快速确认突发故障**：对电机异常这类"快危险"，两百毫秒内确认故障类型。
- **处置建议**：根据风险等级和任务阶段，建议减速、返航、备降或降落，并说明理由；系统只给建议，不直接抢飞控的控制权。
- **风险解释**：每个告警都列出"证据"——是哪几项数据、超了什么线，答辩时经得起追问。
- **频谱监视（设备模块）**：用一台无线电接收设备（USRP B210）监听无人机频段，看干扰和拥挤；**只收不发**。这是"设备模块"——设备没到不挡开发（用回放数据顶上），设备一到直接插上就能测真数据，不用改代码结构。
- **边缘实测（设备模块）**：借用 Jetson Orin NX 板子实测"处理耗时"指标；同样是设备模块，没到先用电脑跑，到了即插即测。
- **演示控制台**：浏览器里操控整个测试流程（功能完整性优先，UI 精致度是加分项）。
- **事件回放**：按时间线回放整次飞行的风险判断和处置过程。
- **实测数字**：每次演示运行的真实成绩（提前量、确认耗时等）自动记录存档，写进材料里的每个数字都有据可查。

## 软件全清阶段（本轮新增）

- **真仿真接管**：接上真实的 PX4 仿真器（需在电脑上装一次它的工具箱，装的时候需要你输一次管理员密码）；装好后演示和测数字都从"程序模拟的飞机"换成"真仿真引擎的飞机"，数字口径自动标注来源。
- **数字更可信**：故障"从发生到确认"的耗时改为从注入那一刻起算；"提前量达标率"只对慢危险场景统计——报告里的每个数字口径都干净。
- **一键自检升级**：启动自检从"代码编译检查"升级为"真起一次演示→探活网页服务→探活回放"三步全过才算好。
- **设备脚本备好**：频谱仪标定、边缘板子测速的脚本先写好并自测，设备到了插上就跑。
- **像产品一样装**：可以像正规软件那样一条命令安装；附一份零术语用户手册；连续跑 1 小时稳定性测试；打包成"解压即用"的绿色包（拷到别的 Linux 电脑也能直接演示）。

## 前沿技术补强（本轮新增）

- **提前预警更可信**：预测算法按最新学术实证重训（稀疏事件专用路线），"提前 5 秒"更稳。
- **概率带保险**：风险区间自带统计保证，飞行环境变化时自动调整（漂移也不掉线）。
- **证据链解释**：事件时间线里每个告警附一段人话"证据→结论"摘要，答辩直接读。
- **材料带文献背书**：计划书各技术段落配齐参考文献（评审可溯），并附硬件采购表。

## 审计修复项（本轮新增）

- **模型选优真正生效**：训练时选出的更准模型（稀疏事件探针）在批量测试里真正用上（此前断链）。
- **仓库瘦身**：评估中间产物不再进 git（只留归档结果）。
- **数字口径对齐**：每次运行只记一个提前量值，统计口径（P10/中位数/达标率）在汇总层算——与计划书一致。

## 模块化说明（这版的新要求）

系统按"核心 + 设备模块"搭：**核心**只依赖仿真和回放数据，没有外部设备也能完整开发、演示、出材料数字；**设备模块**（频谱站、边缘板子、将来可能的真机）各自独立成模块，设备到位后接入对应模块即可测试真实数据，**不需要重构已有代码**。

## 这个版本不做什么

不飞真飞机（等有成果后向导师申请硬件）、不控制仿真机做自动处置（只出建议）、不做多品牌飞控适配（演示只接 PX4 仿真）、不做多机、不做手动开飞机（二期彩蛋）、不追求 UI 炫技（3D 场景/动效不做，功能完整最重要）。
