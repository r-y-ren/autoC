# 需求文档：安航云盾演示系统（材料冲刺版，国创赛 2026 主赛道）

> fn-grill 产物（2026-10-03 收口）。拷问记录：两轮问答（2026-10-03 /deliver 会话）+ 边界重算（同日 /self 会话，工程默认值经用户"开工"确认）；战役级攻略见 `../strategy.md`，蓝图见 `../blueprint.md`（11 验收项=本 R 条目的汇总视图）。

## 根本目的

让安航云盾在国创赛 2026 校赛/省赛材料与答辩中拿出**真实可跑、数字可溯**的证据：一套跑通三个风险场景的仿真演示系统 + 地面 Web 平台 + 演示视频 + 计划书补强修订建议。成功长什么样：答辩现场一键启动演示、每个引用数字都能翻出对应运行记录、评委追问"概率怎么校准/链路怎么知道被干扰"时有实物流可指。

## 环境与技术栈决策

| 项 | 决策 |
|---|---|
| 语言/框架/运行时 | Python 3.11+；pymavlink（遥测接入）+ MAVSDK-Python（任务控制/故障注入）；PyTorch（TCN/GRU 训练与推理）；FastAPI + WebSocket + uvicorn（地面平台）；UHD Python API（USRP B210 采谱，必要时 GNU Radio 3.10） |
| 机器分工 | **开发+SITL：Arch 笔记本**（Linux 原生，PX4 构建最顺）；**训练：RTX 4070 笔记本**（Windows/WSL2）；**边缘实测：借用 Jetson Orin NX 16GB**（JetPack 6.x，Python 推理起步，TensorRT 后置） |
| 仿真环境 | PX4 SITL：Gazebo 为主（Arch 笔记本），SIH 为低配备选；故障注入走 PX4 官方 failure injection（docs.px4.io/main/en/debug/failure_injection.html）与 failsafe 仿真（/main/en/simulation/failsafes.html） |
| 错误处理风格 | 传感器/数值异常不中断：质量掩码 + 关闭依赖该字段的模型分支（降级）；顶层仅系统级错误可抛 |
| 日志方式 | Python logging → JSON 行；每次运行独立目录（配置、随机种子、原始遥测、事件流）；事件与度量双通道 |

## 术语表

| 术语 | 精确定义 |
|---|---|
| 渐进风险 | 有演化过程的风险（电量衰减、链路退化、GNSS 质量下降、风场增强）；考核指标=预警提前量与误报率 |
| 突发故障 | 无稳定前兆的故障（电机/电调异常、通信瞬断）；考核指标=确认时延与最终安全状态 |
| 提前量 | 失控判据成立时刻 − 首次有效预警时刻（秒）；报告 P10、中位数与达标比例 |
| 失控判据（提前量的尺子） | 场景1 低电量+逆风：返航能源余量跌破安全裕量或电压触保护线；场景2 电机故障：姿态失控或被迫降落；场景3 链路：失联超时。判据写进数据字典，评估脚本用它计时 |
| 统一状态序列 | 20 Hz 对齐的多源字段帧（姿态/位置/电池/GNSS/链路/IMU 特征），带质量掩码与来源标记 |
| 风险状态 S0–S4 | 正常/关注/预警/严重/紧急五档；转换条件=阈值+持续时间+证据完整性，带迟滞区间 |
| 共形校准 | 模型输出外再套一层统计后处理，使风险区间在有限样本下满足指定覆盖率（本任务=90%） |
| RSSI-距离一致性 | 用信号强度时序推算的距离趋势与 GNSS 真实距离互检；不一致=链路被干扰或欺骗的证据 |
| 占用率 | SDR 在 2.4 GHz ISM 目标信道上采样得到的频谱能量占用比例 |
| 端到端时延口径 | 20Hz 状态输入→风险事件输出的处理耗时（不含网络传输）；P95≤100ms |
| 演示场景 | 低电量+逆风（渐进）、电机故障（突发）、SDR 频谱干扰联动（链路）三个 SITL 注入场景；每场景低/中/高三档强度，演示主打中档 |

## 需求条目

### R1 统一数据接入层 [P0]
- 内容：从 PX4 SITL（pymavlink）读取姿态/位置/速度/电池/GNSS/链路/飞行模式等消息，输出 20 Hz 统一状态序列（含质量掩码、时间戳、缺失标记）；字段字典对齐计划书 4.1 数据定义，含失控判据字段。
- 验收方式：`python -m demo.replay_check --run <运行目录>` → 输出统一帧率 ≥ 20 Hz、字段覆盖率清单，PASS/FAIL。

### R2 渐进风险通道（物理基线+TCN+共形校准） [P0]
- 内容：物理基线（返航能源/导航/链路/控制余量阈值）+ 轻量 TCN（10 s 窗口 → 1/3/5/10 s 危险概率 + 剩余安全时间）+ 共形校准层（90% 覆盖率风险区间）。输入=统一状态序列；输出=统一事件对象。
- 验收方式：`python -m demo.eval --scenario lowbat_headwind --runs 30` → 提前量 P10/中位数/达标比例、共形覆盖率实测值写入 metrics 分片（设计目标见计划书 7.4，达标与否如实记录）。

### R3 突发故障通道（CUSUM+轻量分类） [P0]
- 内容：惯导创新残差、姿态跟踪残差、转速-电流一致性残差 + 遥测到达间隔/序号丢包序列，CUSUM 确认突变后轻量分类器区分故障来源。
- 验收方式：`python -m demo.eval --scenario motor_fail --runs 30` → 故障确认时延 P90、事件类型正确率写入 metrics 分片。

### R4 链路一致性检测（DroneMA 式，统计基线版起步） [P0]
- 内容：RSSI 时序与 GNSS 距离的一致性校验（先用 IQR 自适应阈值统计基线，GRU 版二期），一致性残差并入突发通道特征与链路健康度。
- 验收方式：`python -m demo.eval --scenario link_degrade --runs 30` → 链路事件触发、正常段误报数写入分片。

### R5 SDR 频谱感知站 [P0]
- 内容：USRP B210 + 2.4G 双频天线采样 2.4 GHz ISM 遥测频段，输出能量/占用率特征与瀑布流（WebSocket 推送）；只收不发；干扰演示用手机热点打流量做合法拥塞源。
- 验收方式（可观察判据）：手机热点空闲 vs 打流量两种状态下，Web 频谱页占用率出现可辨差异并触发告警；`python -m demo.sdr_check` 输出采样带宽/帧率自检 PASS。设备不可用时降级回放模式并如实注记。

### R6 安全状态机与处置建议 [P0]
- 内容：S0–S4 状态机（阈值+持续时间+证据完整性+迟滞）；策略层计算返航/备降/原地降落三类方案的能源需求与可行性检查，输出建议动作（不执行自动处置）。
- 验收方式（可观察判据）：三场景回放日志中每次 S 状态转换均有完整触发证据链与建议动作；阈值附近抖动注入不产生状态反复（迟滞生效）。

### R7 地面 Web 管理平台 [P0]
- 内容：FastAPI+WebSocket 本地单机服务：实时仪表盘（风险等级/剩余安全时间/能源）、事件时间线、频谱瀑布页、飞行后回放页；一键启动、断网可用。
- 验收方式：`./demo.sh` 一键启动 → 浏览器 localhost 可完整观看三场景实时画面与回放，无需手动拼装。

### R8 材料包（视频+计划书修订建议+实测数字表） [P0]
- 内容：演示视频（三场景各一段+整体故事线，脚本先行）；**计划书逐节修订建议+可直接粘贴段落**（团队消化改写融入，留人机分工记录——合规口径：核心材料团队独立完成）；实测数字引用表（每个数字标注 metrics 键）。
- 验收方式（可观察判据）：材料中出现的每个性能数字都能在 metrics 分片找到来源键；视频脚本与素材入库。

### R9 演示控制台（游戏化操控，演示零代码） [P0]
- 内容：2D 指挥中心风控制台页（深色任务控制台：地图+飞行器航迹、姿态/电量/链路仪表、频谱瀑布嵌入、事件时间轴）；演示会话全流程 UI 化——选场景→一键起飞→飞行中故障注入按钮+强度滑杆（低/中/高）→实时看预警与处置建议→时间轴回放（暂停/加速/拖动）；演示全程不碰终端、不碰代码。
- 验收方式（可观察判据）：非开发人员（队员模拟评委）仅用浏览器完成"选场景→注入→预警→处置建议→回放"完整演示，全程零终端命令；注入按钮按下→画面可见变化 ≤2 秒（演示节奏可接受线）。
- 明确范围外（本轮不做）：手动接管模式（键盘/手柄直接开仿真机），列为 P1 二期件。

## 非功能约束

| 约束 | 判据 |
|---|---|
| 边缘时延 | Jetson 上端到端（输入→事件输出，不含网络传输）P95 ≤ 100 ms，实测记录；不达标按计划书 4.5 降级预案处理并如实记录 |
| 推理频率 | 风险计算 20 Hz 稳定运行 |
| 演示可用性 | 单机 localhost 一键启动，全程无需外网 |
| SDR 合规 | 只接收不发射；干扰源仅用合法民用设备（手机热点） |
| 数字纪律 | 对外材料数字只出自 metrics 分片实测（评审规则：技术参数须真实可追溯）；论文数字一律标"论文报告值" |
| AI 合规 | apply 口径：AI 辅助（代码/资料/润色），核心创意与文本团队独立完成，人机分工记录归档 |

## 外部依赖

| 依赖 | 用途与边界 |
|---|---|
| PX4-Autopilot（BSD-3） | SITL 仿真+故障注入；不改飞控源码，外挂接入 |
| Gazebo / SIH | 仿真物理与传感器；SIH 为低配备选 |
| pymavlink / MAVSDK-Python | 遥测解析与命令交互 |
| PyTorch | 模型训练与边缘推理（Orin NX） |
| UHD / GNU Radio（GPL） | B210 采谱。GPL 边界：只调库不修改则演示代码不受传染；若改 GNU Radio 块需开源该块（知识产权材料注明） |
| FastAPI/uvicorn | 地面平台 |
| **结果数据源** | 每次评估/演示运行的完整产物（原始遥测、事件流、配置、种子、metrics 分片）落 `fn_docs/results/<运行目录>/` **全量保留**；其中 metrics 分片同时供战役 merge_metrics 汇总（对外数字唯一来源）。数据拉取：`python -m demo.eval --scenario <名> --runs <n>` 批量产出 |

## 范围外

- 明确不做：真实飞行（待导师批硬件后另立阶段）；A2/A3 级自动处置执行（演示只输出建议+模拟回执）；ArduPilot 第二飞控适配（二期）；深度相机备降点评估（二期，方法已存档 ../strategy/frontier-tech.md）；多机/集群；地面平台多用户与权限。
