# 需求文档：安航云盾演示系统（材料冲刺版，国创赛 2026 主赛道）

> fn-grill 产物（2026-10-03 重开版）。拷问记录：两轮确认式问答（同日，八条必问全过+两条新增约束）；本任务为流程违规后重开的全新任务，前版 fn_docs 已按用户裁定删除（git 历史 13e70b7c 前可查）；战役级蓝图/攻略见 `../blueprint.md` 与 `../strategy.md`（不受本重开影响）。

## 根本目的

让安航云盾在国创赛 2026 校赛/省赛材料与答辩中拿出**真实可跑、数字可溯**的证据：一套跑通三个风险场景的仿真演示系统 + 地面 Web 平台 + 演示视频 + 计划书补强修订建议。成功长什么样：答辩现场一键启动演示、每个引用数字都能翻出对应运行记录、评委追问"概率怎么校准/链路怎么知道被干扰"时有实物流可指。交付深度=材料冲刺+演示级原型（不飞真机，雏形验证后向导师申请硬件）。

## 环境与技术栈决策

| 项 | 决策 |
|---|---|
| 语言/框架/运行时 | Python 3.11+；pymavlink（遥测接入）；PyTorch（TCN/GRU 训练与推理）；FastAPI + WebSocket + uvicorn（地面平台）；UHD Python API（USRP B210 采谱，设备模块内） |
| 机器分工 | 开发+SITL：Arch 笔记本（Linux 原生）；训练：RTX 4070 笔记本；边缘实测：借用 Jetson Orin NX 16GB（**设备模块**，后置即插即测） |
| **模块化架构约束（本轮新增）** | **核心只依赖 SITL/回放数据**（无外部设备可完整开发/演示/出数）；SDR 频谱站与 Jetson 边缘为**设备模块**：各自独立封装（统一设备接口），设备到位后接入模块即测真实数据，**不重构核心**；未来真机亦按此模式扩展 |
| 仿真环境 | PX4 SITL：Gazebo 主，SIH 低配备选；故障注入用 PX4 官方 failure injection 与 failsafe 仿真 |
| 错误处理风格 | 传感器/数值异常不中断：质量掩码 + 关闭依赖该字段的模型分支（降级）；顶层仅系统级错误可抛 |
| 日志方式 | Python logging → JSON 行；每次运行独立目录（配置、随机种子、原始遥测、事件流）；事件与度量双通道 |

## 术语表

| 术语 | 精确定义 |
|---|---|
| 渐进风险 | 有演化过程的风险（电量衰减、链路退化、GNSS 质量下降、风场增强）；考核=预警提前量与误报率 |
| 突发故障 | 无稳定前兆的故障（电机/电调异常、通信瞬断）；考核=确认时延与最终安全状态 |
| 提前量 | 失控判据成立时刻 − 首次有效预警时刻（秒）；报告 P10、中位数与达标比例 |
| 失控判据（提前量的尺子） | 场景一 低电量+逆风：返航能源余量跌破安全裕量或电压触保护线；场景二 电机故障：姿态失控或被迫降落；场景三 链路：失联超时 |
| 统一状态序列 | 20 Hz 对齐的多源字段帧（姿态/位置/电池/GNSS/链路/IMU 特征），带质量掩码与来源标记 |
| 风险状态 S0–S4 | 正常/关注/预警/严重/紧急五档；转换=阈值+持续时间+证据完整性，带迟滞区间 |
| 共形校准 | 模型输出外的统计后处理层，使风险区间在有限样本下满足指定覆盖率（本任务=90%） |
| RSSI-距离一致性 | 信号强度时序推算的距离趋势与 GNSS 真实距离互检；不一致=链路被干扰/欺骗的证据 |
| 占用率 | SDR 在 2.4 GHz ISM 目标信道上采样得到的频谱能量占用比例 |
| **设备模块（本轮新增）** | 依赖外部物理设备（USRP B210 / Jetson Orin NX / 未来真机）的可插拔功能单元；实现统一设备接口，核心经该接口消费，设备缺席时核心自动用回放/本机模式，设备到位即插即测 |
| 端到端时延口径 | 20Hz 状态输入→风险事件输出的处理耗时（不含网络传输）；P95≤100ms |
| 演示场景 | 低电量+逆风（渐进）、电机故障（突发）、SDR 频谱干扰联动（链路）；每场景低/中/高三档，演示主打中档 |

## 需求条目

### R1 统一数据接入层 [P0]
- 内容：从 PX4 SITL（pymavlink）读多源遥测，输出 20 Hz 统一状态序列（质量掩码、时间戳、缺失标记、失控判据字段）；字段字典对齐计划书 4.1；原始遥测全量落运行目录。
- 验收方式：`replay_check --run <运行目录>` → 统一帧率 ≥20 Hz、字段覆盖率清单，PASS/FAIL。

### R2 渐进风险通道（物理基线+TCN+共形校准） [P0]
- 内容：物理基线（四类余量阈值）+ 轻量 TCN（10 s 窗口 → 1/3/5/10 s 危险概率+剩余安全时间）+ 共形校准层（90% 覆盖率区间）。
- 验收方式：三档强度下场景一 30 次评估 → 提前量 P10/中位数/达标比例、共形覆盖率实测入 metrics 分片（达标与否如实记录）。

### R3 突发故障通道（CUSUM+轻量分类） [P0]
- 内容：四类残差通道（惯导创新/姿态跟踪/转速-电流/遥测丢包）+ CUSUM 确认 + 轻量分类判源。
- 验收方式：场景二 30 次评估 → 确认时延 P90、类型正确率入分片。

### R4 链路一致性检测（DroneMA 式，统计基线起步） [P0]
- 内容：RSSI 时序与 GNSS 距离互检（IQR 自适应阈值统计基线，GRU 二期），残差并入 R3 特征与链路健康度。
- 验收方式：场景三 30 次评估 → 链路事件触发、正常段误报数入分片。

### R5 频谱感知站（设备模块） [P0]
- 内容：**设备模块**——USRP B210 采谱 2.4G ISM（只收不发），占用率/能量+瀑布流；**设备缺席时核心自动回放模式（画面等价、来源如实标注），不阻塞开发与演示**；设备到位接入即测真数据（不改核心结构）。
- 验收方式：回放模式下 `sdr_check` 自检 PASS（带宽/帧率/占用率响应）；设备在场时加测"手机热点空闲 vs 打流量占用率可辨差异+告警触发"。

### R6 安全状态机与处置建议 [P0]
- 内容：S0–S4 状态机（阈值+持续+证据完整性+迟滞）；三方案（返航/备降/原地降落）能源校验出建议动作（不执行）。
- 验收方式：三场景回放日志中每次状态转换有完整证据链与建议动作；阈值邻域抖动注入不产生状态反复。

### R7 地面 Web 管理平台 [P0]
- 内容：FastAPI+WebSocket 单机服务：仪表盘/事件时间线/频谱瀑布/回放四页+控制台页；一键启动、断网可用；**功能完整性优先，界面精致度为加分项**（深色主题基线，不做 3D/动效投入）。
- 验收方式：一键启动 → 浏览器完整观看三场景实时画面与回放，无需手动拼装。

### R8 材料包（视频+计划书修订建议+实测数字表） [P0]
- 内容：演示视频（三场景+故事线，脚本先行）；**计划书逐节修订建议+可粘贴段落**（团队消化改写，人机分工记录留档）；实测数字引用表（每数字带 metrics 键）。
- 验收方式：材料中每个性能数字都能在分片找到来源键；视频脚本与素材入库。

### R9 演示控制台（功能完整 P0，UI 加分项） [P0]
- 内容：浏览器内操控整个测试：选场景→一键起飞→飞行中注入故障（按钮+低/中/高滑杆）→看预警与处置建议→时间轴回放（暂停/加速/拖动）；**演示零终端零代码**。功能全流程可用与稳定是 P0；2D 指挥中心风为界面基线方向，视觉打磨为加分项。
- 验收方式：非开发人员仅用浏览器完成"选场景→注入→预警→处置建议→回放"完整流程，零终端命令；注入按钮→画面可见变化 ≤2 秒。
- 范围外：手动接管模式（键盘/手柄开仿真机）列 P1。

### R10 设备模块化架构（本轮新增） [P0]
- 内容：SDR 频谱站与 Jetson 边缘实测封装为独立设备模块（统一设备接口：发现/健康/数据帧/降级）；核心（R1-R4/R6/R7/R9）只经接口消费；模块缺席=回放/本机模式自动顶替，模块到位=接入即测，**两者切换不改核心代码**。
- 验收方式（可观察判据）：拔掉设备模块配置（或设备不在场）系统全功能可演示；接入后同一套核心代码产出真实设备数据，差异仅在数据来源标注——以 SDR 模块做实证（回放帧 vs 实采帧跑同一占用率管线）。

### R11 真数据面与批量跑批 [P0]
- 内容：PX4 SITL 真跑接入（spawn_sitl px4 路径+环境探测；工具链由用户 sudo 安装——环境动作不可代理）；train_tcn 合成重训后接入 eval 风险通道（synthetic-trained 口径如实标注）；三场景×30 次批量跑批，产物归档 fn_docs/results/；PX4 环境不可用时合成源兜底、口径字段标明数据面来源。
- 验收方式：批量命令产出 runs≥90 的 metrics 分片且落 fn_docs/results/；风险事件带共形区间（模型通道启用证据）；快照含 data_source 字段（px4|synthetic）。

### R12 指标口径修正 [P0]
- 内容：运行清单记录 inject_at_s；突发确认时延=确认时刻−注入时刻；hit_rate 仅渐进场景输出。
- 验收方式：电机档（合成）confirm_p90∈[0.1,0.6]s；motor_fail 分片无 hit_rate 键。

### R13 验收深度与归档规约 [P0]
- 内容：smoke_boot 升级三步真验收（合成会话起→服务探活→回放 API 探活）；运行产物归档 fn_docs/results/（与数据源条目对齐）。
- 验收方式：smoke_boot 单命令输出三项 PASS；新评估运行的产物自动出现在 fn_docs/results/（不再手工搬运）。

### R14 设备就绪脚本 [P0]
- 内容：bench_edge.py（Orin NX 部署与时延采样）与 B210 标定/实测脚本；脚本带回放/干跑自测，真机执行项列 manual 待设备。
- 验收方式：两脚本 --dry-run（回放）自检 PASS；真机项列入硬件待办（设备到位即跑，不改核心代码——R10 语义延续）。

### R15 打包与安装 [P0]
- 内容：pyproject 打包；pip 可安装；用户手册（零术语版操作指南）。
- 验收方式：干净 venv 中 pip install 本包后，demo.sh 一次起服务且五页可访问。

### R16 长跑稳定性与便携交付包 [P0]
- 内容：1 小时长跑稳定性脚本（连续会话+内存/线程健康记录）；免 root 便携交付包（tar 目录布局：自含运行环境+数据+手册，解压即跑；ISO 镜像需 root 工具故以便携包为等价交付物——口径注记）。
- 验收方式：长跑 1h 无崩溃且留痕（会话数/帧数/内存曲线记录入 fn_docs/results/）；便携包在目标机（Linux x86_64）解压后 demo.sh 起服务。

## 非功能约束

| 约束 | 判据 |
|---|---|
| 模块化（新增） | 设备缺席不阻塞；设备到位即插即测；核心不因设备变化重构 |
| 边缘时延 | Jetson 上端到端 P95≤100ms 实测记录（设备模块；缺席时本机实测并标注口径差异） |
| 推理频率 | 风险计算 20 Hz 稳定 |
| 演示可用性 | 单机 localhost 一键启动，全程无需外网 |
| SDR 合规 | 只接收不发射；干扰源仅合法民用设备（手机热点） |
| 数字纪律 | 对外材料数字只出自 metrics 分片实测；论文数字标"论文报告值" |
| AI 合规 | apply 口径：AI 辅助，核心创意与文本团队独立完成，人机分工记录归档 |

- 明确不做：真实飞行（待导师批硬件后另立）；A2/A3 自动处置执行（只建议+模拟回执）；ArduPilot 二飞控适配（二期）；深度相机备降点评估（二期）；多机/集群；手动接管开飞机（P1）；UI 精致度投入（3D 场景/动效，加分项不进 P0）。
