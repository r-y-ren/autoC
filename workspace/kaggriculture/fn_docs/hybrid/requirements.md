# 需求文档：v48 混合候选（方案甲）

## 根本目的
以线上实证可信的 v48 字节为基底，补上我方架构里已被法证证明有价值的三件鲁棒能力（中期卖出经济把控、极端形态经济护栏、剧本偏离监测），产出终交收口件候选。成功 = 离线四门全绿 + 探针线上收敛 ≥600 且 WR≥55% 转正（否则回 v14.1，衍生版主承载位全程不动）。

## 环境与技术栈决策（继承战役既有裁决）
| 项 | 决策 |

| 提交包运行时 | Kaggle 官方环境（vendored 1.32.7 语义），stdlib-only、离线自主 |
| 开发/测试侧 | Python 3.14 + pytest + vendored wheel + 数字孪生（seated 口径） |
| 基底 | software/kaggle_simulations/v48_derivative/main.py（107,008B，sha256 dadee25a…，零改动区=磁带/路由/反克隆/终局清仓） |

| 错误处理 | 补丁层失败→回退 v48 原生行为（fail-safe，不许崩） |
| 日志 | 无运行时日志（提交包），验证侧产物落本子树 |

## 需求条目
### R1 基底完整性 [P0]
- 内容：v48 基底字节中磁带/路由/反克隆抢卖/卖单槽位重排/终局清仓五区零改动；补丁只经窄缝注入。
- 验收方式：混合 main.py 对基底的 diff 审计=改动仅落在三补丁注入点；五区语义对照 reverse-eng digest 逐点确认。
### R2 中期卖出层（P1） [P0]
- 内容：中期卖单由三门卖出计划器语义接管（吸收表×投影×批次）；反克隆/终局清仓保留，冲突时 v48 优先。输入=每回合观测（价格/库存/资金）；输出=中期卖单；错误=计划器异常→回退剧本默认卖单。
- 验收方式：h2h 门（seated 通道 ≥16 局对 v48 互胜≥0.65）+ 面板门（孪生 d0 资金 ratio≥0.98）。
### R3 经济护栏（P2） [P0]
- 内容：双死价检测→否决剧本买畜/建棚步骤；触发阈值窄化并文档化；未触发=零动作。
- 验收方式：触发面覆盖测试（构造双死价局必触发）+ 正常局零影响证明（未触发局与纯 v48 行为一致）。
### R4 剧本健康监测（P3） [P0]
- 内容：里程碑偏离监测（d10-12 窗口资金/库存 vs 剧本预期）；偏离超阈→只调卖单时点，不动产线。
- 验收方式：同 R3 双测试（触发偏离局调整卖单/正常局零影响）。
### R5 确定性与装载 [P0]
- 内容：同 obs 同动作；官方 get_last_callable 装载语义通过；包确定性双跑逐字节一致。
- 验收方式：发射四件套（装载语义/双席自打 DONE/确定性/体积与身份链登记）。
### R6 门禁与转正 [P0]
- 内容：四门全绿才可探针；线上转正=收敛分≥600 且公共局 WR≥55%；否则回 v14.1。
- 验收方式：逐门数字台账（manifest）；探针读数记录入 docs/endgame_decision_tree.md §五。

### R8 终局保果层（lead-protection，战后资产） [P0]
- 内容：d24+ 且领先差 ≥3k 形态启用保守卖时——前移/确保清仓成交以锁定胜势（领先时对手可低价倾倒反超，固定清仓脚本不看领先差，见分析 02 领先崩塌簇 14 局）。不触发形态行为与 v4b 逐字节一致。注入缝=卖单干预（P 家族先例），不改基底五区（718 清仓脚本本体不动，只在其决策点前后调整卖时/卖量）。领先差口径：对手资金若 obs 不暴露则以可观测代理（我方资金+库存估值 vs 对手产出代理）计算，精确口径实现期定并登记。错误：任何评估异常→回退 v4b 行为（fail-safe）。
