# 需求文档：v48 混合候选（方案甲）

## 根本目的
以线上实证可信的 v48 字节为基底，补上我方架构里已被法证证明有价值的三件鲁棒能力（中期卖出经济把控、极端形态经济护栏、剧本偏离监测），产出终交收口件候选。成功 = 离线四门全绿 + 探针线上收敛 ≥600 且 WR≥55% 转正（否则回 v14.1，衍生版主承载位全程不动）。

## 环境与技术栈决策（继承战役既有裁决）
| 项 | 决策 |
|---|---|
| 提交包运行时 | Kaggle 官方环境（vendored 1.32.7 语义），stdlib-only、离线自主 |
| 开发/测试侧 | Python 3.14 + pytest + vendored wheel + 数字孪生（seated 口径） |
| 基底 | software/kaggle_simulations/v48_derivative/main.py（107,008B，sha256 dadee25a…，零改动区=磁带/路由/反克隆/终局清仓） |
| 我方层源 | 旧树 kaggle_simulations/agent/src/{market,constants,observer}.py（只读取材） |
| 错误处理 | 补丁层失败→回退 v48 原生行为（fail-safe，不许崩） |
| 日志 | 无运行时日志（提交包），验证侧产物落本子树 |

## 需求条目
### R1 基底完整性 [P0]
- 内容：v48 基底字节中磁带/路由/反克隆抢卖/卖单槽位重排/终局清仓五区零改动；补丁只经窄缝注入。
- 验收方式：混合 main.py 对基底的 diff 审计=改动仅落在三补丁注入点；五区语义对照 reverse-eng digest 逐点确认。
### R2 中期卖出层（P1） [P0]
- 内容：中期卖单由三门卖出计划器语义接管（吸收表×投影×批次）；反克隆/终局清仓保留，冲突时 v48 优先。输入=每回合观测（价格/库存/资金）；输出=中期卖单；错误=计划器异常→回退剧本默认卖单。
- 验收方式：h2h 门（seated 通道 ≥16 局对 v48 互胜≥0.65）+ 面板门（孪生 d0 资金 ratio≥0.98）。
### R3 经济护栏（P2） [P0]
- 内容：双死价检测→否决剧本买畜/建棚步骤；触发阈值窄化并文档化；未触发=零动作。
- 验收方式：触发面覆盖测试（构造双死价局必触发）+ 正常局零影响证明（未触发局与纯 v48 行为一致）。
### R4 剧本健康监测（P3） [P0]
- 内容：里程碑偏离监测（d10-12 窗口资金/库存 vs 剧本预期）；偏离超阈→只调卖单时点，不动产线。
- 验收方式：同 R3 双测试（触发偏离局调整卖单/正常局零影响）。
### R5 确定性与装载 [P0]
- 内容：同 obs 同动作；官方 get_last_callable 装载语义通过；包确定性双跑逐字节一致。
- 验收方式：发射四件套（装载语义/双席自打 DONE/确定性/体积与身份链登记）。
### R6 门禁与转正 [P0]
- 内容：四门全绿才可探针；线上转正=收敛分≥600 且公共局 WR≥55%；否则回 v14.1。
- 验收方式：逐门数字台账（manifest）；探针读数记录入 docs/endgame_decision_tree.md §五。
### R7 探针交接 [P1]
- 内容：README 提交命令模板+描述文案（"public derivative with modifications (market/economic-guard layers)"）；提交由人工执行（蓝图 out_of_scope）。
- 验收方式：文档在场且命令可直接复制执行。


### R8 终局保果层（lead-protection，战后资产） [P0]
- 内容：d24+ 且领先差 ≥3k 形态启用保守卖时——前移/确保清仓成交以锁定胜势（领先时对手可低价倾倒反超，固定清仓脚本不看领先差，见分析 02 领先崩塌簇 14 局）。不触发形态行为与 v4b 逐字节一致。注入缝=卖单干预（P 家族先例），不改基底五区（718 清仓脚本本体不动，只在其决策点前后调整卖时/卖量）。领先差口径：对手资金若 obs 不暴露则以可观测代理（我方资金+库存估值 vs 对手产出代理）计算，精确口径实现期定并登记。错误：任何评估异常→回退 v4b 行为（fail-safe）。
- 验收方式：①重演门（硬前置，v3 卖干预共振前科）：14 局领先崩塌局孪生重演（seated 通道），**成功=重演终局 margin>0，≥7/14 才 PASS**；②等价面：非触发局（构造+真实回放采样 ≥8 局）与 v4b 动作流逐字节一致；③发射四门+patches 单测全绿。
- 立项形态（用户裁决 2026-09-25）：**战后资产**——只构建+离线验证，不上线不探针（零提交冻结 ba1b44c 不动）；09-30 前若跟踪对出验证错，应急优先现有字节互投而非本层。


### R9 结构重构·巨人路线（羊重仓线，战后资产） [P0]
- 内容：按巨人画像（statma 线：羊重仓至 ~17 头、羊毛收入占比 ~52%、SE 象限 d11、收入峰 ~18k@d14-17）以 M0 经济模型生成目标产线排程，映射为 v48 磁带产线事件手术（执行器/反应层/市场层骨架保留）；产 v6 构建族（含 P2 死价保险沿 v4b 形态）。**R1 基座冻结面豁免仅限 v6 新构建**（旧件 v4b/v5 与线上件零改动）。不上线（零提交冻结不变）。
- 验收方式（五线全过）：①h2h vs 纯 v48 ≥16 局互胜 ≥0.65；②巨人局 seated 对照：对 statma/fuxi/42 回放真值流各 ≥3 局打平或更好；③胜局回归集 ≥8 局不翻负；④发射四门；⑤经济面：收入峰 ≥12.7k 级且落 d14-17。
- 用户裁决（2026-09-23）：变体=羊重仓先行；方式=画像生成+磁带手术；验收=五线。

### R10 种子迟购截断层（layer S，orderbook-L1） [P0]
- 内容：在 round-30 orderbook 衍生版（V55 基座+layer D+番茄门，pkg sha 2838cc66）之上追加尾部附加层 layer S：每回合对基座返回动作的 market 订单表做**纯减法过滤**——step≥648（d27 起）的 BUY_SEED 订单，若按磁带/计划口径该种子无法在季末（step 718）前完成一次"种下→首收"（首收期≈2 天≈48 步，以磁带未来 PLANT 机会判断、非钟点一刀切），则删除该订单；其余订单与槽位顺序不动。**零误杀不变量（用户铁令 2026-09-23：精准第一，禁止过度截断买少）**：删除某 BUY_SEED 订单的充要条件=删除后"现有库存种子+保留订单"仍能覆盖磁带未来**全部**可完成种收的 PLANT 机会（逐品项计）；任何拿不准（机会判断依赖不确定状态、磁带解析失败、边界拿捏不准）→ **保留订单**（宁买勿漏——多买一颗种子最坏损失其售价，误杀一颗有效种子损失整茬收成）。输入=基座 action + obs（step/库存/种子持有）；输出=过滤后 action；错误=层内任何异常→返回基座原动作（fail-safe，不许崩）。产物全落 `kaggle_simulations/orderbook_l1_derivative/`（`orderbook_derivative/` 原件零改动）；提交描述文案 "public derivative with seed-truncation layer"。
- 验收方式（四门全绿才发射，门不过维持 verbatim 版在飞）：
  ① h2h 门：seated 通道双席位对 orderbook 原版 ≥16 局互胜 ≥0.55（h2h_evidence.json 同格式台账）；
  ② 谱系强度门：对 v48 纯件/v4b/hybrid-v2 各 ≥8 局无翻负（对照 48-0 基线，允许平、不允许负）；
  ③ 等价面+精准性门：26 局线上局集（results/2026-09-23-round30-read.json）seated 重演——(a) **反应面+结果面双判据（2026-09-24 口径修订，原严格逐字节口径废止）**：全部差异步 ≥648 且差异形态限于 {BUY_SEED 增/删、SELL 单集合变化}（基座对截断的自身经济反应：回买/少卖），且逐局终局资金 l1≥verbatim（结果面非负）；(a') 原严格口径留档为 RED 诊断模式；(b) **子集判据（零误杀的可观察形态）**：逐局逐品项"被截断购种量 ≤ 原版该局终局未种下的种子量"，模式甲类局（终局剩种 ≈$0-30）截断额 ≈0、模式甲 $1,350 级有效采购全额保留——归零的是**迟购浪费**（$3,400 级），不是 d27+ 采购总额；(c) 构造用例三件：未来仍有 PLANT 机会的种子不截、无机会的截、s671 边界单仅当磁带确无后续种植机会才截；
  ④ 发射四门：官方 last-callable 装载语义（新入口链 _cxd_agent→layer S 包装）、双席自打 DONE+单步时长 <1s、确定性双跑逐字节一致、体积与 sha256 身份链登记（manifest 同 round-30 格式）。
- 发射与终榜对（用户裁决 2026-09-23）：门全绿即发 round-31（提交由人工执行，README 命令模板更新）；终榜对={round-29 v48 衍生, orderbook-L1}（挤掉 verbatim 版）；每候选 ≤2 次提交、Error 即停；09-28 后不新发。
