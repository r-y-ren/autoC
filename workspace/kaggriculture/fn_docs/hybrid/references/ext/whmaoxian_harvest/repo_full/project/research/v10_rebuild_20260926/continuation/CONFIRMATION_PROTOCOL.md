# V10-R2 prospective acceptance protocol

The previous V9 and V10 releases remain immutable. This protocol is saved before
selecting one candidate and before running new confirmation worlds.

## Selection and separation
Use complete generation-4 and extended-development records to select one source.
Record its SHA-256 before confirmation. No tuning on confirmation outcomes.
Development may use four additional public programs, old references, local counter
policies and the eleven known online-loss traces. Keep those panels distinct.

## New confirmation
Use 48 new SHA-256-derived worlds and both seats. Compare the frozen candidate,
V9 and old V10 against six public programs: market_smart, fieldcraft, shoprouter,
aurax, marketshock and structured. The last two programs have no development
performance runs. Public programs can share code ancestry; six implementations
are NOT six independent algorithmic lineages and notebook titles are not ratings.
Also run candidate versus V9 and V10 on these worlds, separately from public gains.

All games must complete under the unmodified official game transitions. Candidate
macro paired win-point gain versus old V10 must have a positive world-bootstrap
95% lower bound, each public-program gain must be >= -0.05, and direct points versus
each old release must be >= 0.65. Inspect V9 comparison and lower-tail losses too.
Do not reinterpret a failed gate by removing opponents or unfavorable worlds.

Technical release checks require the official file-path runner, source/archive
hash equality, no stderr or nonzero error diagnostics, continuous isolated stdlib
replay, repeatability and next-game reset checks. Replay probes are diagnostic only;
no static-tape win rate may be converted into a 2800 rating claim. No automatic upload.

## Additional strength floor, declared before first confirmation game
In addition to the paired-improvement gates, the candidate must achieve at least
0.80 mean win points across the six equally weighted public implementations,
and at least 0.50 against each implementation, including the two unused ones.
This prevents promotion solely for fixing one weak matchup while remaining weak
against the newly introduced opponents. These floors do not calibrate a rating.
