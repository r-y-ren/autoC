## 本轮做了什么
按当前榜单对手重新评估，用了两套测试集：
1. R4.2 在线上实际打过的 186 局（9/29–9/30 的对手群）；
2. 排行榜第 300–700 名（2040–2260 分）中随机抽取的 25 支队伍，每队最近 4 局，共 100 局。做法是保留强队的录像，把它的对手换成我们的程序。

### 关键发现：重打结果里混有"商店运气"
- 环境每晚先按双方的每块空地抽随机数（决定是否长杂草），再抽下一家解锁的商店。
- 只要我方当晚空地数量不同，之后解锁的商店就可能不同，整局市场需求随之改变。
- 程序拿不到随机种子，所以这纯属运气，无法利用。

为排除这种干扰，重打工具新增"固定商店"模式：每晚强制使用原始对局里实际解锁的商店。

- 在普通重打里，"低价囤小麦"变体（价格 ≤32 时买到 30 份）看起来是 141 胜 45 负，大幅领先。
- 固定商店后，它只有 104 胜 82 负，比 R4.2 还差。之前的领先全部来自商店运气。
- 其他低价留麦变体最多多赢 2 局，属于噪声。

### 强队比我们强在哪（输局分析）
- 近距离输局：对手每局多卖约 4 份草莓、6 份牛奶，雇工和买地多花一些，属于产能上的小差距。
- 大比分输局：对手番茄、鸡蛋、胡萝卜各多卖 70–80 份，是另一套更强的农场规划。
- 强队普遍每局多倒卖 1200–3000 份小麦，但净收益约为 0，不是他们赢的原因。
- 这些差距都要改 R2 的农场路线才能追上，截止前做不到。

## 结论
本轮没有找到比 R4.2 更强的版本。R5 与 R4.2 强度相同（两个测试集上差 0–1 局），放在第二个名额的作用是：两个提交的线上分数各自独立波动，排名取较高者，多一次取得高分的机会。
