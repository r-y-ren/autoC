## 这次实际改变的内容

开局采用净买入 5 单位小麦，替代原有的买入再卖回组合，针对已经复现的“早期现金不足→雇工不齐→牲畜漏喂”断链修订。
对于主动抢先出售，先检查双方公开农场的生产布局是否足够接近。相似度达到 0.90 时才启用增强的库存压力策略和最长 36 回合的提前销售考察；否则保留旧 V10 的保守市场设置。原有生产体系、库存约束和收官保护继续保留。
新决策没有使用对手身份、提交 ID、此次测试世界的种子或隐藏仓库。新增公开对手代码没有打入提交包。
