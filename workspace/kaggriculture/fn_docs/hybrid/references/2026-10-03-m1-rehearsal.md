## 一、任务与设定

- **主任务**：下一拍市场价格预测。输入=16 拍公开状态窗口（9 品价格/库存偏差/推断净成交量 net_comm/城镇排水向量 + 商店数/双方金钱/时间相位，43 维），输出=t+1 拍 9 品价格增量。net_comm 由公开库存轨迹推断（`inv[s]−inv[s−1]+drain(s−1)`），线上可得、无泄漏；请求量 vs 推断 committed 逐格一致率 92.7%（残差=死单/$1 地板/截断）。
- **数据集**：26,527 局（全 720 步全有效）按 episode_id md5 哈希 8:1:1 切 **train 21,206 / val 2,701 / test 2,620**（同局不跨集；全量唯一 eid 校验零重复零泄漏）。窗口 704/局 → test 1,844,480 窗 / 16,954,020 格。
- **模型**：LSTM 2 层 hidden 192 + MLP 头（498,249 参数 <2M），Huber(delta/base)，bf16，窗口 16，RTX 4070 上 **2.36 分钟**（预算 24 分，early stop ep28/35）。loss 曲线：`fn_work/m1_rehearsal/runs/loss_curve.png`。
- **回放步进约定**（20 局实证校准）：`steps[t].action` 产生 `observation[t]`；`inv[t+1]=inv[t]+committed(action@t+1)−drain(t)`；`price[t]=market_price(inv[t])`（oracle 实测 MAE≈0.0007 复证）。语料混合引擎版本（module_version 1.32.2 与后续版在 CARROT/TOMATO/EGG hinge 支有差），故引擎先验用训练集标定 inv→price 映射而非硬编码公式。
- 备选任务（对手麦流强度）不单独建模，以 WHEAT 大变动格专项读数作代理。

**大变动格（|Δ|≥5，占 3.26%，预测器的真正价值区）：** persistence 12.05 / 查表 9.51 / 引擎先验 **9.22** / LSTM 12.03（≈persistence，零增量）/ oracle 0.63。

**分品摘要（MAE：pers / 查表 / LSTM）：** LSTM 在 CARROT(0.054)/TOMATO(0.105)/EGG(0.032)/MELON(0.428)/FERTILIZER(0.143) 持平或最优；但在 WHEAT(0.121/0.159/0.121)、STRAWBERRY(1.150/1.184/1.149)、MILK(1.479/1.635/1.478)、WOOL(1.420/1.838/1.421) 全部只是追平 persistence，而**引擎先验在 STRAWBERRY(0.698)/MILK(0.969)/WOOL(0.977)/WHEAT(0.102) 显著更强**——高 T 敏感牲畜品上结构先验>学习。WHEAT 专项（备选任务代理）：大变动格全法 6.85-6.93（oracle 0.001）——**对手麦流单拍强度在公开状态下基本不可预测**。

**失败案例（LSTM 误差 top）：** 3 例全是 t=264（第 11 日）MELON 暴跌（278→48/7，Δ≈−207~−230）。案例 A 无任何公开前兆（净成交全零、库存 −24）——同拍隐藏订单所致，**原理上不可预测**；案例 B/C（不同局、公开轨迹逐拍相同）崩盘已在进行中（5 拍内抛 30+54）而 LSTM 仍预测 ≈0——条件均值训练不追尾部的公式性缺陷；涉事队 Beisenbek Nurassyl [dsmlkz] 跨局执行确定性 MELON 第 11 日倾泻脚本（对 Victor Mercklé/fgwiebfaoish 等不同对手产生逐拍相同磁带）。

## 四、异常与限界（第③段）

1. **WSL 稳定性**：开工即遇空闲自灭（首连超时）；win 侧 `wsl.exe --exec sleep` 保活 3 小时 + nohup 分离 + ~2min 探活，训练/评测全程零中断。训练仅 2.36 min，保活远未压满。
2. **语料覆盖偏差**：top10 归档，921 队但 Majkel1337/SpaTaro/Crop Dusta/ymg_aq 等头部队占量最高（2084/1921/1790/1757 局）——对手分布非全体，低带对手行为欠采样；结论外推到全体对手需保留。
3. **引擎版本混布**：语料跨 1.32.2+，CARROT/TOMATO/EGG hinge 支 ±1-2 差 → 标定映射在这三品有版本歧义（oracle CARROT 1.51 而非 ~0）；不影响"价格=库存确定性函数"结论（94.5% 格 oracle nMAE=0）。
4. **表述限界（非不可性证明）**：单一表述（Huber 均值回归/498K 参数/16 拍窗/无对手身份条件）。方向命中 85.7% 说明方向信号存在，幅度标定与尾部追价是训练目标问题；但见下——即便解决，信息上限仍受同拍隐藏订单约束。

## 五、结论与 M2 建议（第④段）

**判定：形式判据过（LSTM>查表，显著），实质判据不过（LSTM≯persistence；价值区大变动格 LSTM 12.03 ≈ persistence 12.05，而引擎先验 9.22）。**

**建议：M2 不立项（就"端到端下一拍价格 BC 蒸馏产线化"而言）。** 理由：

1. 对查表的优势是空洞的：查表自身劣于平凡基线，LSTM 的全部 MAE 优势来自"在 88% 零变动格不受伤"，而非任何预判技能。DS_completation"查表>学习"命题在本域被证伪（查表<学习），但更强平凡基线（persistence/结构先验）>两者——**混合系第一块砖不需要神经网络**。
2. 价格=库存确定性函数（oracle 复证），我方产线已有解析定价（2026-09-28 引擎抽取）；预测器的唯一非冗余价值=对手流预判，而该信号在单拍粒度上：不可预知部分（同拍隐藏订单）原理性缺失，可预知部分（脚本化倾泻/进行中动量）用指纹/磁带规则提取比序列回归更准（t=264 MELON 倾泻即例）。
3. 经济价值区（大变动格）上结构先验（引擎公式+排水节律）已达 9.22 vs LSTM 12.03——任何未来学习件须先在本预演 harness 上**于大变动格打赢引擎先验+动量规则**再谈立项（harness 已就位：数据集/脚本/判据可复用）。

**可回收副产品（零额外成本）：** ① t=264 MELON 确定性倾泻脚本（Beisenbek 等队，跨局同磁带）=可直接入指纹库的行为签名（对我方 MELON 持仓/抄底时点有信息价值，是否利用归产线决策，本预演不动产线）；② 引擎先验（标定 inv→price 映射+排水节律 4/12）在 STRAWBERRY/MILK/WOOL/WHEAT 上比 LSTM 强 15-40%，若混合系需要"预测器"模块，**解析先验+规则应为其第一版**，神经件仅在 N 拍流强度/尾部分位数目标（quantile 或倾泻事件分类）+ 对手指纹条件化下重启预演。
