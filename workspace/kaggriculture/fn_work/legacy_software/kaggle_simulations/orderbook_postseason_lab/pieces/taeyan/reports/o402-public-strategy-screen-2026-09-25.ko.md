# o402 — 공개 노트북·디스커션 전수 수집과 미시도 전략 선별 (판단 자료)

작성: Claude, 2026-09-25. **이 문서는 결정이나 추천이 아니라 Codex 세션의 판단 근거다.** 후보별로 근거, 신뢰도, 가장 가까운 선행 실험, c414 포함 여부, 위험을 나열한다. 표의 "선별 참고 등급"(A/B/C)은 선별 에이전트의 의견일 뿐 승격·실행 순서가 아니다. 이 작업에서는 경기를 한 판도 돌리지 않았고, 에이전트 코드·리그 DB·제출도 바꾸지 않았다.

## 1. 수집 범위와 방법

- **노트북**: 대회 목록 614개를 모두 받았다. 리그 DB에 있던 264개에 더해 없던 350개를 `state/o402/notebooks/`에 따로 받았다(리그 DB는 건드리지 않음). 리그 DB의 검색 경유 노트북을 합쳐 모두 672개 참조를 요약했고, 본문이 같은 포크는 한 그룹으로 묶어 627그룹이 됐다. 리그 자체 업로드(`local/upload-*`) 28개는 공개 노트북이 아니라서 제외했다.
- **디스커션**: 209토픽 전문(2026-07-30~09-24, 첫 글과 모든 댓글). 공개 DiscussionsService API로 받았다.
- **추출**: 노트북 요약 28묶음과 디스커션 3부를 에이전트 17회로 읽었다. 결과는 `state/o402/extract/notebooks_*.md`, `new_*.md`, `discussions_part*.md`다. 디스커션에서는 355항목이 나왔다.
- **이력 색인**: `tried_index_A.md`(314개 ID: 교훈 문서, HANDOFF 최신·O 보관, 메모리, o401), `tried_index_B.md`(약 248개 ID: HANDOFF C 구간, 보고서 178개, 검토한 공개 노트북 약 115개).
- **선별**: 각 후보를 이력 색인과 대조하고, c414 디코드 소스(`state/o402/c414_decoded/`, 중첩 12층)를 grep해 이미 있는지 확인했다. 일부는 리그 DB에서 "코드가 한 가지만 다른 두 에이전트"의 직접 대결로 근거를 보강했다. 결과는 `extract/candidates_*.md` 네 개다.

## 2. 한계

- 추출과 선별은 에이전트의 판독(원문 발췌와 grep)이다. 수치 대부분은 저자 자체 패널(자기 계보나 구버전 상대)이고, 상당수가 7~8월 메타다.
- "c414에 포함/미포함"은 식별자·상수 grep 결과일 뿐 실행해서 확인한 것이 아니다.
- 리그 단일 변경 쌍의 직접 대결은 세계 4~10개짜리 소표본이다(305→308만 36세계). 공개 저자가 이겨서 공개한 포크라는 선택 편향도 있다.
- 같은 후보가 여러 파일에 다른 ID로 나올 수 있다. 아래 표에서 병합했다.

## 4. 선별 중 확인한 c414 구조 사실

- **루트**: t144에 첫 상점 2개로 한 번 정한다. 비YARN 49쌍은 EXP240 루트 101~128로 간다(105번 하나가 21쌍). YARN 15쌍은 루트 9, t648부터는 종료 루트 2다. 모든 루트가 멜론 12, 딸기 33, 밀 약 163, 토마토 0을 심고 땅은 d6·d11에 산다. 축군만 루트마다 다르다(105번 소/양/거위 8/6/3, 9번 6/11/0).
- **가장 안쪽 파일**은 공개 Metav4 v13(리그 104)에서 v13 자체 변경 몇 개를 뺀 것이다. 차이: `clamp_sells`, `V9_FERT_FIRST_DAY` 16 vs 14, `_OR2_SLOT_MARGIN` 50 vs 20, `_SR_HOURS/_SR_MARGIN` (22,23)/4 vs (21,22,23)/8, v13의 EXP283·R127·pre-guard·clone reorder. c414는 v13에 6승 4패이고, 4패는 두 세계(2-YARN)에서 양 좌석 모두 졌다.
- **시장 층**(바깥→안): `sell_impact_reorder` α0.25 → sale_advance(프리미엄 lookahead 10, 기본 7) → `adaptive_market` → `jaxa_frontload`(t144~) → `market_portfolio` v2(d6~) → v9 본체. near-mirror나 점수 차 게이트는 없다. 체시스 `front_run`은 꺼져 있다.
- **비료**는 어떤 선행 매도 층(`_sell_lead`, `FRONT_RUN_ITEMS`, `V9_RACE_ITEMS`, `SALE_ADVANCE_ITEMS`)에도 들어 있지 않다. R85는 d6~28에 모든 주문이 SELL인 턴에만 여유분을 맨 뒤에 붙인다.
- **중반 당근**(V9 CARROT, CARROT2 교체분)은 d24 전 매 턴 slot 0에서 전량 판다.
- **d29 종료 루트**는 step 696에 9명, 697에 2명을 고용한다($55+$89). c379는 step 700부터만 재계획한다.
- **실전 손실 분포**(c414 실전 패배 38개): 5개가 $100 미만, 7개가 $113 이하, 10개가 $250 미만.
