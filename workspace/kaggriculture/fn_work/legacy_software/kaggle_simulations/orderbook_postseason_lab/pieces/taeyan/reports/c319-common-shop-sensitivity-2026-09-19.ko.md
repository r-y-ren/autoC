# c319 — 작물 선택 효과의 미래 상점 경로 민감도

판정: c317 학습 실패를 미래 상점 경로 변화만으로 설명할 근거는 부족하다. 기존 실패 판정을 유지한다. 재학습·조건 튜닝·승격은 하지 않았다.

## 설계와 검증

c300의 행동 의존 상점 RNG, c313의 두 고정 세계, c317의 직접 선택 학습을 선행으로 확인했다. c317 동결 설정의 첫 8시드 전부에서 4실행 상대·양좌석·KEEP/2칸/전체 전환을 비교했다. 성패나 상점 변경 여부로 선별하지 않았다. 기존 pair_trace와 c313 실행기를 사용해 각 KEEP의 native 상점 경로만 고정했다. 상대는 실제로 반응하고, 잡초 처리와 정책은 유지했다. 상점 정답을 정책에 제공하지 않았다.

192/192게임 완료, 실행 전후 소스·엔진 해시 일치. KEEP 64/64의 양측 행동·최종 현금이 native와 동일했다. 원래 상점 경로가 동일했던 대안 24/24도 native를 재현했다. 모든 대안의 선택 시점·관측 특징·상태/행동 접두가 c317 원본과 동일했다. 양측 노출 오류와 관측 수정 0, 최대 결정 0.119초 미만.

## 결과

아래 값은 이 8개 개발 시드의 64조건 평균이다. c317 전체 32시드 결과를 대체하지 않는다.

- 2칸 전환: native own +1,165 / 상대 +815 / 마진 +350 / 승점 0. 고정 상점 own +580 / 상대 +130 / 마진 +450 / 승점 0. 마진 부호 반전 2/64, 원래 상점 변경 56/64.
- 전체 전환: native own +1,258 / 상대 +1,428 / 마진 −170 / 승점 −6.25%p. 고정 상점 own +1,944 / 상대 +1,944 / 마진 +0.44 / 승점 −3.125%p. 부호 반전 8/64, 원래 상점 변경 48/64.
- 고정 상점의 2칸 전환도 v9 상대 승점 +37.5%p지만 나머지 세 소스는 각각 −12.5%p다. 특정 상대에 편중된 효과가 남는다.
- 미래 결과를 본 사후 oracle 승점은 native와 고정 상점 모두 +10.9375%p다. 실행 가능한 선택기 성능이 아니다.
- 마진의 조건 간 표준편차는 2칸 1,211→1,068, 전체 7,418→7,080이다. 조건당 한 미래 경로만 사용했으므로 추정량의 분산 감소나 무편향성을 증명하지 않는다.

고정 상점 원장에서는 2칸 전환이 토마토 +10u/매출 +740, 딸기 −16u/매출 −312였다. 전체 전환은 토마토 +64u/매출 +4,511, 딸기 −102u/매출 −3,359였다. 전체 전환으로 우리 현금이 늘어도 상대 현금도 거의 같은 크기로 늘었다. 생산량이나 own 증가만으로 승리에 가까워지지 않는 기존 외부효과가 확인된다. `feed_wheat`는 밀 구매 전체로 순수 사료비가 아니다.

## 후속 판단

상점 고정은 기전 진단에 유용하지만 native 성능 검증을 대신할 수 없다. 같은 작물 전환 데이터의 모델·분량·가격 임계값 재튜닝은 중단한다. 다음 개입은 기존 강한 운영을 보존하면서 실제 상위권 패배의 다른 큰 손실 원인을 겨냥해야 한다. 기준 정책은 c312 공개 v9/4, 제출 후보는 없고 보호 blind 7240–7255는 미사용이다.
