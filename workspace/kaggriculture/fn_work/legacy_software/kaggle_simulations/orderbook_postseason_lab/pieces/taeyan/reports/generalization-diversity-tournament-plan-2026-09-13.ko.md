# 일반화 다양성 토너먼트 계획 — 2026-09-13

## 목적

현재 후보를 특정 손실 리플레이가 아니라 새로운 자연 seed와 여러 정책 계보에서
비교한다. 이 단계는 폭넓은 탐색 검사이며 제출 승격 검사가 아니다.

## 고정된 범위

- 후보 12개: c110, c111, c112~c120, public V38
- 후보 간 고유 66쌍, 새 seed 8개, 양쪽 좌석: 1,056경기
- 후보 12개 x 외부 상대 12개 x 새 seed 8개 x 양쪽 좌석: 2,304경기
- 합계: 3,360경기
- 기존 selection16과 holdout48은 사용하지 않는다.

## 외부 평가 분리

헤드라인은 V37, Kaito 계열, Moon 계열, Nagata, Rayk 반응형 스케줄러,
legacy trace 계열을 사용한다. 같은 계열의 여러 상대가 평균을 독점하지 않도록
계열별 결과에 같은 가중치를 준다.

Timed Six Cow는 내부 광범위 예외 fallback을 하네스가 관측할 수 없으므로
진단 전용이다. 세 합성 개막 상대도 실제 메타 빈도를 대표하지 않으므로 진단
전용이다. 네 상대의 결과는 헤드라인 순위에 들어가지 않는다.

## 사전 고정 순위 기준

1. 헤드라인 상대 계열 균형 승점률
2. 후보 라운드로빈 승점률
3. 헤드라인 하위 10% 평균 마진
4. 헤드라인 자기 최종 현금 평균

이 순위는 다음 장기 확인 대상으로 3~4개를 줄이는 데만 사용한다. 탐색 리더를
바로 제출하거나 champion으로 승격하지 않는다. 장기 확인에는 이 결과를 본 뒤
새로 생성하고 동결한 seed 블록을 사용한다.

## 실행과 복구

`run_diverse_tournament.ps1`은 경기별 저널을 남긴다. 정상 중단 뒤 같은 명령을
다시 실행하면 완료된 경기를 재사용한다. 소스, 하네스, 엔진 또는 계획이 바뀌면
기존 출력 디렉터리 재개를 거부한다. 모든 경기에서 양쪽 정책의 오류 계측과
시간을 검사하며 하나라도 불완전하면 분석을 완료 처리하지 않는다.
