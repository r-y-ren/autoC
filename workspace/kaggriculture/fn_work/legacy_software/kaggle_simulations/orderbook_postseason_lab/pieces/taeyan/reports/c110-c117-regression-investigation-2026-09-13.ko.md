이전 보고서에서 차이를 '주로 매칭/불확실성'으로 설명한 것은 근거보다 강한 해석이다.
가능한 설명 중 하나로 남겨두며 실제 퇴보 가능성을 기각하지 않는다.

## 검증이 실전 체급 상승을 입증하지 못한 이유

1. 3,360경기의 독립 시드는8개였다. 같은 조건을 여러 상대·좌석으로 반복한
   개수를 독립 일반화 증거로 확대할 수 없다.
2. 상대 정책 계열이 겹치고 일반 외부 패널이 전승으로 포화됐다. c117의 판매
   선점 개선은 유사 경제 구조 상대에게 유리해도 다른 생산 전략에 통할지는 별개다.
3. c117은 새로운 최종 확인 조건을 통과한 챔피언이 아니었다. 사용자 요청의
   중간 제출이었다. 로컬 우위에서 실제 상위권 우위로 승격할 근거가 부족했다.
4. 개별 패배를 본 뒤 덧붙인 기능이 다른 조건에 손해를 줄 가능성도 아직 있다.
   이를 추측으로 확정하지 않고 c110~c117의 변경 단계 비교로 조사한다.

## 구현한 후속 검증

`state/agent_experiments/live_regression_20260913/`에 다음을 준비했다.

- `collect_failures.py`: 공식 CLI 라이브러리로 날짜별 c110/c111/c117 공개 경기
  목록·전적·모든 패배 메타데이터를 저장한다. 리플레이는 c117 최신 최대20개 패배,
  c110/c111 각각 첫 패배와 최신2개 패배를 중복 제거해 수집한다. 이번9개 확보.
  같은 공개 리플레이가 이미 있으면 재사용하며 이전 스냅샷을 덮어쓰지 않는다.
- `run_regression.ps1 -Track baseline`: 공개상대3개×발견용16시드×양좌석=
  c110 신규96경기. 앞서 수행하는 c117의 동일96조건 원시 결과와 조합해
  c110 승→c117 패와 반대 전환을 명시한다. 같은 관련 계열3개라는 한계는 유지한다.
- `run_regression.ps1 -Track diagnostics`: 원본 패배9개×c110/c111/c112/c115/
  c116/c117 6개×상점 자연 생성/고정2모드=108개 진단. 먼저 원래 제출의 자연 생성
  9조건에서 **행동 해시·보상·상점 경로** 재현을 검사한다. 원본 정책이 어긋나면
  나머지99개 진단을 시작하지 않는다. 각 진단은 양쪽 원본 행동의 보상·상점 재현을
  선행한다. 후보 오류·내부 오류·1초 초과는 진단 실패로 처리한다.
- 원본 재생/고정 상대 결과는 반응형 엘리트 승률이 아니다. 상점 모드를 합산해
  승격하지 않는다. 오류가 난 결과를 조용히 제외하거나 자동 재시도하지 않는다.
- 파일/엔진 해시 동결, 별도 잠금/출력, 재개, 자식 작업당240초 제한,
  실패 시 미시작 작업 취소, 완료/실패 알림과 소리를 포함한다.

기존 공개상대3개 검증이 모두 완료돼야 후속 실행을 시작한다. 각 명령은2워커이며
두 창에서 함께 실행해도 합계4워커다. 이전 실행 중인 실험·원본 정책·제출물을
수정하지 않았다. Python AST와 PowerShell 구문 검사만 끝났고 정책 검증은 사용자
실행 대기다. 새 개발/선택/홀드아웃을 억지로 추가 소비하지 않는다.

## 다음 개선의 결정 규칙

- 동일 조건에서 c110은 이기고 c117은 지면 해당 퇴보부터 조사한다. 실전 전체
  우열로 확대하지 않고 특정 상대/상점 유형과 변경 시점을 확인한다.
- c111→c112는 배치 복구, c112→c115는 판매 예약12턴, c115→c116은 특정 초반
  상점 경로의 양 추가, c116→c117은 마지막 날 수확 변경을 분리한다.
- 모든 변경 단계가 같은 큰 후반 패배를 보이면, 수정 기능을 더 붙이거나 미세한
  문턱값 탐색을 계속하지 않는다. 부모의 생산/노동 계획이 현재 시장에 대응하지
  못하는 문제를 우선한다.
- 다음 경제 후보는 관측 가능한 현재 시장과 농장으로 남은 생산·비료·사료·운반
  가치와 추가 노동 비용을 계산해야 한다. 상대 ID, 시드, 미래 상점은 사용하지 않는다.
  사료 중단만 하고 기존 픽업/운반 계획을 남기는 수정도 피해야 한다.
- 실패만 모아 학습하면 또 과적합한다. 실패9개는 진단/회귀 자료로만 쓰고,
  개선된 후보는 관측하지 않은 시드와 별도 강한 반응형 상대에서 최종 확인한다.

아직 원인 기여도와 새 후보 우위를 입증하지 않았다. 이번 구현은 회귀 원인을
찾을 수 있도록 검증 체계를 보강한 것이며 새로운 제출은 하지 않았다.
