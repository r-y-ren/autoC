# 기존 밭의 남는 작업·비료 기회 검토

c605와 c606은 CPU 워커8개로 각각 저장된8경로를 분석했다. 추가 경기·후보 소스·등록·제출은 없다. 기준은 c602/local369다.

c605는 같은 자리의 실제 무효 작업과 소지 비료를 사용했을 때의 곡물 생산 가능성을 비교했다. 서로 중복되는 선택을 제외한 낙관적 현시세 견적은 경로당0~104였다. 미래 저장 기록을 진단 라벨로 사용한 값이므로 실제 이익이나 채택 근거가 아니다. 별도37경로의 연속 WATER→FERTILIZE 순서 확인에서도 해당 곡물 기회는 없었다.

c606은 현재 관측과 자기 일정만으로 일을 마친 기존 일꾼의 주변 밭 시비 동선을 제안했다. 추가 고용·구매는 허용하지 않았다. 8경로 중6개는 기회가 없고 나머지 견적도35/42였다. 한 제안은 기본 수확을4로 예측했으나 실제6이었다. 정적 일정에 빠진 동적 작업이 있어 예측을 확정 이익으로 볼 수 없다. 현재 소스5,752응답과 입력 불변은 확인했고 원본 경기 재대결은 하지 않았다.

효과가 작아 이 방향을 종료한다. 시비 문턱이나 빈 작업 범위를 계속 조정하지 않는다. 다음 c607은 이미 승인되어 제출된 c594·c596의 실제 경기19개를 전부 검토한다. 01:28UTC 각각9전9승/10전10승이지만, 다른 상대 표본이므로 기존 기준보다 강하다는 결론을 내리지 않는다. 토마토 추가행이 실제 작동했는지부터 확인하며 원래 FAIL 판정은 보존한다.
