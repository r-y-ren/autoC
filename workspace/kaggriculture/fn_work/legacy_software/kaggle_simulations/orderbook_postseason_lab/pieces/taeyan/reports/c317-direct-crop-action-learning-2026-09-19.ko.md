# c317 — 생산 선택의 실제 승패 효과를 직접 학습

판정: **사전 학습 gate FAIL. 독립 확인·제출로 진행하지 않는다.** 원본/KEEP 동일성16게임과 학습용 native768게임을 완료했다. 현재 운영 기록은 HANDOFF.md에만 남긴다.

## 선행과 달라지는 점

c309는 d6에 전체 경로8개를 선택했고8시드·31관측 벡터에서 OOF 승점−4.6875%p였다. c310에서 결정을 미룰 수 있었던 경로의 선택 여력은 한 세계에 집중됐다. c313은 딸기 레인을 토마토로 바꿀 때 마지막 생산물의 수확을 복구했으나, 두 개발세계에서 전환 자체는 손해였다. c315/c316의 상대 공급 예측도 단순 대조를 일관되게 이기지 못했다.

이번에는 공급량의 예측 정확도 대신 **실제 실행한 생산 선택의 최종 승점 차**를 지도학습한다. 선택 시점은 d11의 첫 유효 딸기 씨앗 구매 직전으로 늦다. 상점 순서, 양쪽 공개 농장과 현재 시장, 자기 private를 관측한다.32개 독립 시드에서 모든 선택을 실행해 결과를 얻는다. 이름이나 부모만 바꾼 재실험이 아니며, c313의 두 가격점에 맞춘 임계값도 만들지 않는다.

선택지는 기존 실행계약의 KEEP,2칸 소규모 전환,13칸 전체 tranche 전환이다.13은 기존 c177이 지원하는13칸 작업 묶음으로 결과를 보기 전에 고정했으며 수량 grid search가 아니다. 두 전환 모두 c313 수명 수확 수정과 c179 V219 투자 호환을 사용한다. 실제 씨앗/현금/배치 실패도 정책 결과에 포함한다. 추가 토지나 고용 프로그램은 넣지 않는다.

## 고정 설계

- 모든 선택의 결정 직전 상태·자기 행동 접두·특징이 같아야 한다. 결정이 발생하지 않으면 전체 행동·보상이 같아야 한다. 동일 seed도 행동에 따라 미래 상점이 바뀔 수 있으므로 국소 수익 인과 분석과 구분한다.

- 대조: KEEP, fold 학습 부분에서만 고른 최선 고정 선택, 결과를 전부 본 사후 oracle. oracle은 선택 공간 진단이며 정책이 아니다.
