# c151 결과와 c152 상점 확장 후보

## c151 결과

128/128경기가 완료됐고 전부 720 states, 양측 DONE, 719회 호출, 내부 오류 0으로 통과했다.
동일한 64개 조건에서 c151은 c146 대비 승점 -3, 마진 -4,332, 자기 현금 -2,278이었다.
c146은 20승 2패 42무, c151은 16승 4패 44무였다.

c151은 1,200개 인증 경로를 모두 가치 기준에서 거절해 당근 전환이 0회였다.
행동이 달라진 6조건은 모두 시드 640603013의 관련 라우터 상대와 양쪽 자리였다.
이 시드의 최종 상점은 PET_CAFE 2개와 FARMERS_MARKET 1개를 포함한다.
c146은 경기당 2회 전환, 7개 수확 요청으로 자기 현금 +381, 경기 마진 +722를 만들었다.
c151은 이 전환을 제거했다. 따라서 c151은 폐기하고 제출하지 않는다.

## c152 설계

c152는 c146의 고수요 정책을 byte-guarded 부모에서 그대로 유지한다.
기존 하루 당근 수요 25 이상 조건에서는 c146과 동일한 공급·가격·비용 계산을 수행한다.
단위 검사에서 같은 고수요 입력의 행동, 요청 수, 예상 이익이 일치했다.

추가는 기존 문턱 아래에서만 일어난다.

- 공식 소비 tick으로 현재 step부터 인증된 수확 직전까지 계산한다.
- c146의 공개 당근 작물 + 32개 공급 스트레스와 기존 계획을 유지한다.
- 현재 자기 창고 재고는 수확 시점의 확정 공급으로 중복 계산하지 않는다.
- 예정 밀 3개는 전액 기회비용, 경로상 추가 가능량 2개는 25% 위험 프리미엄으로 계산한다.
- c146의 경로, 현금, 주문, 용량, 종자 확인, 수확, 급식 보완 계약을 유지한다.
- 저수요 신규 요청은 `carrot_rotation_shop_expansion_requests`로 따로 기록한다.

메커니즘 검사 7개가 통과했다. c152 SHA-256은
`785529ac46ca6731b8901836bab48a1eb647203e9a1b7c9395495a6f7c6ac2fa`다.
실전 개선은 아직 확인되지 않았다.

## 준비된 검증

기존 c151 캠페인의 c146 64개 결과는 원래 job과 출력 SHA-256을 모두 동결해 재사용한다.
c152만 같은 8시드, c129/c150/c146/nagata, 양쪽 자리에서 64경기 실행한다.
8 workers이며 기존 측정 처리량으로 약 1~3분, 보수적으로 2~5분을 예상한다.

```powershell
& 'H:\dev\kaggle-data\kaggriculture-strategy-meta\state\agent_experiments\c152_shop_expansion_probe_20260914\run.ps1'
```

진행률, 완료/전체, 캐시, 경과 시간, 처리량, ETA와 성공/실패 알림음을 표시한다.
중단 후 동일 명령으로 검증된 결과만 재사용한다. 별도 Kaggriculture 작업이 실행 중이면 거절한다.
통과하더라도 재사용 개발 시드 결과이므로 강한 독립 상대와 미사용 시드 검증 전에는 승격하지 않는다.
