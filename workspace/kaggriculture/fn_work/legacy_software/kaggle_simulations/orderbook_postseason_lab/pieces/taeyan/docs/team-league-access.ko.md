# 팀 전용 원격 접속

같은 Kaggle 팀원 4명이 닉네임·비밀번호로 로컬 리그를 함께 쓰는 방법이다.

```text
팀원 브라우저 ─(HTTPS 터널)→ 팀 게이트웨이 127.0.0.1:8792 (로그인) → 리그 서버 127.0.0.1:8791 (이 PC 전용)
```

- 리그 서버는 계속 이 PC(127.0.0.1)에서만 열린다. 외부에는 게이트웨이 포트만 터널로 연결한다.
- 이 PC에서 `http://127.0.0.1:8791`로 여는 기존 대시보드는 로그인 없이 그대로 쓴다. 접속자 표시에는 `로컬(이 PC)`로 나온다.
- 코드: `src/kaggriculture_meta/league_gateway.py`(로그인·세션·권한·전달), `tools/league_gateway.py`(실행), `tools/start-team-league.ps1`(서버+게이트웨이 시작).

## 1. 계정 만들기

관리자가 원하는 때에 PowerShell에서 만든다. Git Bash에서는 비밀번호 입력이 가려지지 않을 수 있다.

```powershell
.venv\Scripts\python.exe tools\league_gateway.py user add Taeyang --role admin
.venv\Scripts\python.exe tools\league_gateway.py user add 팀원닉네임
```

- 비밀번호는 화면에 표시되지 않고 두 번 입력한다. 8자 이상.
- 닉네임은 한글·영문·숫자와 `.` `_` `-`로 1~32자. 영문 대소문자는 구분하지 않는다.
- 관리 명령: `user list`, `user passwd <닉네임>`, `user role <닉네임> admin|member`, `user remove <닉네임>`.
- 계정 파일은 `state/public_league/team_users.json`(PBKDF2 해시, git 제외)이다. 실행 중인 게이트웨이에 2초 안에 반영된다. 비밀번호를 바꾸거나 계정을 지우면 그 사람의 기존 로그인은 바로 끊긴다.
- 파이프 입력은 `--password-stdin`으로 받는다. PowerShell이 붙이는 BOM은 제거한다.

## 2. 실행

```powershell
powershell -ExecutionPolicy Bypass -File tools\start-team-league.ps1 -Restart -Tunnel
```

- `-Tunnel`은 Cloudflare 퀵터널도 켠다. 계정·도메인·공유기 설정이 필요 없다. 주소(`https://…trycloudflare.com`)를 출력하고 `state/public_league/team_url.txt`에 저장한다. 터널이 이미 떠 있으면 저장된 주소를 그대로 보여 준다.
- 퀵터널 주소는 켜 둔 동안 유지되지만, 터널을 다시 켜면(PC 재부팅 등) 새 주소가 나온다. 그때 팀원에게 새 주소를 알린다.
- PC를 재부팅하면 리그 서버·게이트웨이·터널이 모두 꺼진다. 위 명령을 다시 실행한다(`-Restart` 없이도 된다).
- cloudflared는 설치 없이 `state/public_league/bin/cloudflared.exe`(공식 GitHub 배포본 2026.9.1, Cloudflare 서명 확인)를 쓴다. 로그는 `state/public_league/cloudflared.log`에 남는다.

- 리그 서버를 항상 켜짐 모드로 띄운다. 브라우저 탭을 닫아도 꺼지지 않는다. 그다음 게이트웨이를 시작한다.
- `-Restart`는 이미 떠 있는 서버를 연속 대결 정지 → 재시작 → 연속 대결 재개 순서로 다시 띄운다. 코드 업데이트를 반영할 때 쓴다. 집중 측정 중이었다면 정지되므로 화면에서 다시 시작한다.
- 이미 떠 있으면 새로 띄우지 않는다. 계정이 하나도 없으면 시작하지 않는다.
- `public-league.html`/`public-league.vbs`로 켠 서버는 마지막 로컬 탭을 닫으면 꺼지는 모드다. 팀원 접속을 유지하려면 위 스크립트를 쓴다.

## 3. 팀원에게 주소 열기

게이트웨이 `http://127.0.0.1:8792`만 연결한다. 리그 서버 8791을 직접 연결하면 로그인이 없으므로 연결하지 않는다.

- **Cloudflare Tunnel**(2026-09-23 현재 사용: 퀵터널, `start-team-league.ps1 -Tunnel`)
  - 임시 주소(도메인 불필요, 실행할 때마다 주소가 바뀜): `cloudflared tunnel --url http://127.0.0.1:8792`
  - 고정 주소(Cloudflare에 등록한 도메인 필요): named tunnel의 ingress를 `service: http://127.0.0.1:8792`로 둔다.
  - HTTPS가 자동이고 공유기 포트포워딩·공인 IP 노출이 없다. 게이트웨이는 `X-Forwarded-Proto: https`를 보고 쿠키에 `Secure`를 붙인다.
  - Cloudflare는 응답을 100초까지만 기다린다. 오래 걸리는 노트북 추가는 화면에 오류가 떠도 서버에서 계속 진행되므로 잠시 뒤 새로고침한다.
- **Tailscale**: 팀원도 Tailscale을 설치해야 하지만 인터넷에 공개되지 않는다. `tailscale serve`로 8792를 tailnet에 연결한다.

## 4. 권한

| 기능 | 관리자(admin) | 팀원(member) |
|---|---|---|
| 순위·전적 조회, 코드 받기 | 가능 | 가능 |
| 모델 등록, 노트북 추가, 지금 수집 | 가능 | 가능 |
| 집중 측정, 연속 대결 시작·중지 | 가능 | 가능 |
| 자동 수집 ON/OFF, 수집 주기, 대결 워커 수 | 가능 | 불가(버튼 비활성, 게이트웨이도 403) |

자동 수집 설정은 이 PC의 Windows 예약 작업을 바꾸므로 관리자만 쓴다.

## 5. 화면 기능

- **접속 중**: 대시보드 탭을 열어 둔 사람의 닉네임과 탭 수. 30초 넘게 신호가 없으면 노란 점, 90초가 지나면 목록에서 빠진다.
- **모델 등록**: 화면 아무 곳에 파일을 끌어다 놓으면 등록 창이 열리고 파일이 선택된다. 등록 창의 점선 영역을 눌러 고를 수도 있다. 등록자는 로그인 닉네임으로 기록되고, 모델 이름을 비우면 `닉네임 · 파일 이름`이 된다. 완전히 같은 실행 파일은 기존 전적을 공유하며 처음 등록한 사람을 유지한다.
- **누가 돌리는지**: 연속 대결·집중 측정을 시작한 사람이 진행 표시에 `시작 닉네임`으로 나온다.
- **상대 노트북별 전적**: 전적 보기에서 기본으로 열린다. 상대별 유효 경기 수, W-L-T, 승점률과 95% 구간, 평균 마진, 평균 현금을 보여 준다. 실행 파일이 같은 노트북들은 한 줄로 묶어 목록으로 표시한다. 머리글을 누르면 정렬되고, `경기 보기`는 그 상대와의 경기만 보여 준다.
- **코드 받기**: 순위표의 `코드`나 전적 화면의 `코드 받기`로 실제 실행 파일을 받는다. 단일 파일은 `.py`, 부속 파일이 있으면 `.tar.gz`다.

## 6. 주의

- 대회 규칙 6a에 따라 대회 기간(최종 제출 마감 2026-09-30 23:59 UTC)에는 같은 Kaggle 팀끼리만 비공개 코드를 공유할 수 있다. 다른 팀 사람에게 계정을 주지 않는다.
- 등록된 코드는 이 PC에서 실행 검사와 대전을 한다. 믿을 수 있는 팀원에게만 계정을 주고 비밀번호를 길게 정한다.
- 로그인 시도 횟수 제한은 owner 요청으로 기본 꺼져 있다(2026-09-23). 다시 켜려면 게이트웨이를 `serve --login-limit 5`처럼 실행한다(10분 창). 로그인과 변경 요청은 `state/public_league/team_gateway_audit.jsonl`에 남는다. 5초마다 오는 접속 신호는 기록하지 않는다.
- 로그인 유지 기간은 기본 7일(`serve --session-days`)이다. 게이트웨이를 재시작하면 모두 로그아웃되고, 열려 있던 대시보드는 다음 요청 때 로그인 화면으로 이동한다.
- 같은 기계의 다른 프로그램은 리그 서버(8791)에 직접 요청할 수 있다. 게이트웨이는 외부 접속만 보호한다.
