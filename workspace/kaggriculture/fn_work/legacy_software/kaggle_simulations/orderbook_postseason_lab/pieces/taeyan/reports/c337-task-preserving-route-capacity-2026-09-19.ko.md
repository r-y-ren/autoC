# c337 — 필수 작업을 보존한 경로 재배치의 여유

판정: 조사한 v9 경로에서는 단순 이동 압축으로 생산량을 크게 늘릴 근거가 약하다. 새 배차 후보는 만들지 않는다. **기존 작업 자체와 생산 달력을 바꾸는 공동 계획의 가능성은 이번 계산 밖**이다. 전면 플래너의 불가능성이나 전체 농장 경로의 최적성을 주장하지 않는다.

## 선행 시도와 범위

o004/o233은 구매·고용·필드 작업을 약한 플래너로 인계해 기존 생산을 잃었다. c321–323은 기존 방문 경로를 고정한 작물 일정 합성으로 개선하지 못했다. c334의 공동 시비·급수는 실제 실행됐지만 추가 고용·입력 비용을 포함한 마진이 음수였다. c170은 새 일꾼의 단일 시비 방문 배정기이며, 현재 일꾼의 여러 작업을 유지하는 최단 경로 하한 계산기는 아니었다.

이번에는 기존 c330/c336에서 원본 소스·720상태·원장을 검증한 12경기를 재사용했다. 리플레이·원장 SHA와 원장 재현/잔차 표시를 확인했다. 원본을 다시 시뮬레이션하지 않았다. 신규 대결 0건, 정책 변경 0건.

## 같은 일꾼 안에서의 재정렬

d11–28의 필드 사건을 일꾼·날짜별로 나누었다. 가축 작업, PICKUP, DROP 등은 고정 경계로 남기고, 그 사이 이동·PASS·작물 작업 구간만 조사했다. 구간의 시작/종료 위치, 담당 일꾼, 작업 목록을 유지했다. 각 타일에 적어도 한 번 방문하는 최단 Manhattan 경로를 Held–Karp DP로 정확히 계산했다.

작업 선후 관계·시각별 씨앗/비료 공급·다른 일꾼 간 간섭을 무시하므로 최단 이동은 낙관적인 하한이고, 기존 이동과의 차이는 **이 제한된 변경 범위에서만** 절감 상한이다. 실제 실행 계획이 아니다. 원래 성공하지 못한 작물 명령도 작업 목록에 남아 있을 수 있다.

- 7,356구간 중 이동 절감 상한이 양수인 구간 186개.
- d11–28 전체를 합쳐 경기당 최대 평균 33.33이동 절감. 이것을 하루 절감량으로 읽지 않는다.
- c334 추가 관리일 d18·d19는 각각 12경기 모두 절감 상한 0.
- PASS는 d18 평균 8.92, d19 17.5일꾼-턴이지만 여러 위치/시각에 흩어진 양이다. 바로 사용할 수 있는 추가 작업 수가 아니다.

## 두 일꾼 사이의 재배정

d18·d19에 h0–3 사이 시작해서 h23까지 작물 전용 구간이 있는 일꾼 쌍을 모두 조사했다. 각각의 시작/끝 위치는 보존하고, 두 일꾼의 전체 방문 타일을 자유롭게 나누어 합계 최단 이동을 구했다. 서비스 시간·개별 작업량·입력 제약은 제거했다. 그만큼 실제보다 유리한 이동 하한이다.

처음에는 타일의 작업을 한 일꾼에게 묶으면서 작업량 제한도 적용했다. 원래 두 사람이 한 타일을 나눠 처리할 수 있으므로, 이것은 제한된 재배정 탐색이지 일반적인 하한이 아니었다. 전략 결과를 내기 전에 이 오류를 확인했다. v1 파일/결과는 보존하고 v2에서 개별 작업량 제한을 제거했다. 독립적인 순열 전수열거 1,024개가 단일 경로 DP와 전체 부분집합 비용표에 모두 일치했다.

초기 타일 수 제한으로 빠진 39쌍도 동일한 수정 방법으로 별도 계약을 남기고 전부 계산했다. 최대 17타일, 누락 0. 중복 계산을 줄이기 위해 동일한 문제는 한 번만 풀고 해당 사례들에 연결했다. 최대 12 CPU워커, 동시에 하나의 분석만 실행했다.

- 전체 123쌍: 절감 상한 0인 쌍 107, 2이동 12, 4이동 4.
- d18의 99쌍: 평균 0.40이동, 최대 4.
- d19의 24쌍: 모두 0.
- 서로 일꾼이 겹치는 쌍의 절감량을 합산하지 않는다. 끝 위치를 풀거나 세 명 이상을 동시에 재배정하는 경우까지 이 결과로 제한하지 않는다.

## 다음 행동에 주는 의미

이 경로는 이미 같은 작업을 처리하는 이동 면에서 촘촘하다. 단순 배차 개선이 c334의 추가 고용을 없애 주리라고 가정해서 다시 후보를 만들지 않는다. d19의 기존 PASS가 충분히 연결되는지까지 검증한 것은 아니므로 “추가 작업은 절대 불가능”이라고도 결론내리지 않는다.

다음 연구는 **어떤 생산/관리 작업을 포기하고 어떤 생산 묶음으로 대체할지**를 포함해야 한다. 단순 경로 재정렬, 고정 방문의 작물 치환, 더 많은 고용을 각각 반복하는 접근은 우선순위를 낮춘다. 현재 관측에서 선택 가능한 생산 묶음과 기존 가축·자금·판매 계약을 함께 넘겨받는 방식의 기존 도구를 찾아, 경제적으로 다른 대안을 실제 게임에 연결하는 것이 다음 미해결 과제다. 아직 그 후보를 구현하거나 우세를 검증하지 않았다.
