# c316 — 자료 범위 확장으로 미래 공급 예측을 다시 검증

판정: **사전 예측 gate FAIL. 정책 적용·같은 표본 튜닝을 하지 않는다.** 자료 확장은 옛 모델보다 오차를 줄였지만, 공개 농장 입력의 추가 가치가 두 품목에 걸쳐 유지되지는 않았다. 전략 개선이나 승률 개선 실험은 아니다.

## 선행 시도와 재시도 근거

c315는 d11 관측에서 상대의 이후 토마토·딸기 시장 유입량을 예측했다. 첫12경기에서는 단순 대조보다 좋았지만, 설정을 고정한 추가8경기에서는 두 품목 모두 시장/상점만 모델보다 오차가 커졌다. 구현 오류가 확인돼 실패한 것이 아니므로 같은25경기에서 모델을 조정하지 않는다.

기존 수집 자료를 찾으니 이전 평가 버전을 양쪽 모두 제외한179경기·71제출버전이 남았다.59팀이며 가장 많이 등장하는 제출버전도40경기다. 기존25경기는 모두 Majkel 한 버전과 연결돼 있었다. **자료 범위가 실제로 달라진다**는 점만 재시도 근거로 삼는다. 여러 제출이 같은 코드를 쓸 수 있으므로 버전 수를 독립 계보 수로 해석하지 않는다.

새 수집기·엔진·특징 생성기를 만들지 않았다. 기존 `fetch_current_elite`, `replay_accounting`, 격리 `launch`, c308 특징, c315 label 추출을 재사용하고 c316 스크립트는 동결·검증·학습 순서를 연결한다.

## 실행 전 고정

- 학습: 위179경기 양쪽 관점358행. 양측 공개 농장·현재 시장·현재까지 열린 상점·관측자 자신의 private만 입력. 상대 private·제출ID·결과·미래 상점은 입력하지 않는다.
- 목표: d11 시작부터 d19/23/27까지 상대의 `SELL(price>1) - BUY_PRODUCT`. $1 판매는 엔진상 시장재고에 들어가지 않으므로 제외한다. 수확량이나 수익 예측과는 다른 목표다.
- 학습 설정: c315와 같은 RF64/depth4/leaf4/seed315, target별 모델6개. 중앙값·시장/상점만·공개농장 포함을 비교한다. 모델/특징/threshold 탐색 없음.
- 평가: 동결 v9 제출56269928 API 기록에서 상대 당시 점수2750 이상, 학습 및 이전 평가20경기에 없는 상대 제출버전별 최신1경기, 최신순24개. 결과값으로 고르지 않았다. 선정과 기준을 label 평가 전에 저장했다.
- primary: d27 두 품목 모두 새 공개농장 모델의 MAE가 새 중앙값·새 시장만·옛 c315 공개농장 모델보다 작아야 다음 검토. 같은24경기에서 옛 모델도 평가해 자료 확장의 효과를 비교한다. episode bootstrap 구간도 함께 제시한다.
- 평가모델은 학습 후 해시를 동결한다. 같은 결과를 보고 모델/파라미터를 변경하지 않는다. 모델 정확도 gate는 전략 승격 gate가 아니다.

## 검증과 자료 한계

공식 엔진1.32.7·원장 소스 해시가 맞는 기존 검증33경기를 재사용했다. 나머지146경기는 격리 subprocess12워커로 전체 상태와 양측 현금을 재현했다. 추가146/146통과,146개 원장 작업 구간111초. 관측 CPU 사용률86–91%여서 워커를 줄이지 않았다. 이는 모델 성능이 아닌 실행 건전성 검사다.

EpisodeId·서버 좌석 index·API 보상과 replay 최종 보상을 교차 확인한다. 학습/평가 사이 episode·seed·양측 제출버전 비중복을 검사한다. 기존 수집기 index가 API 배열 위치를 좌석으로 쓰므로 모델용 좌석은 명시적 API index를 별도로 사용한다.

평가24경기는09-17의 역사 기록이다. 학습 자료는09-17~19이므로 **시간순 전진 검증이 아니다**. 당시2750+ 모집단이며 이전3000+ 평가와 난도가 같다고 주장하지 않는다. 같은 v9 관측자에 대한 전이이며 private 최상위 정책의 반사실적 반응을 학습했다는 증거도 아니다. 이전20평가는 이미 관측된 개발 자료로 보존하며 이번 선택에 재사용하지 않는다.
