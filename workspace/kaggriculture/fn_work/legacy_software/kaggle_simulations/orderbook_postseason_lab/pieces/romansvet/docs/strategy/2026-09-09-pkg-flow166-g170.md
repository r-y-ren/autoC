## Switch / flag check

The package vendors `policy.py`, `brain.py`, `plan.py` and `runtime.py` from the
source tree (`cmp` clean against `arms-next/src` for all four), so the packaged
planner *is* the judge's planner.

The judge invokes (`S/loss12/run.sh`, mirroring `S/lossflip/run.sh`):

    KAGG3_TOWN_SCHEDULE=S/band2100p/town_schedules.json \
    python S/drainpin/on2b.py "OPEN_PUMP_ON=True" --theta … --games 1 \
      --workers 8 --seed-base 777001 --seed-per-opponent --opponents <12 tapes>

`OPEN_PUMP_ON` is **already `True` at line 1173 of `plan.py`**, so the judge's one
forced switch re-asserts the shipped default and the package needs no edit to
match it. No other planner constant is forced, and `KAGG3_TOWN_SCHEDULE` is an
engine-side town pin (applied by `town_inject` before `_vendored_imports` clears
the `KAGG3_*` namespace), not a planner switch.

Against the LIVE package the only plan-constant deltas are the two new
`FORWARD_ADMIT_DAYS = 3` / `FORWARD_ADMIT_ON = False` names; every other
module-level switch default is unchanged. `main.py` differs from the LIVE one by
exactly the four lines that add `opp_t_day` / `opp_t_yield` to the `PolicyObs`.

### One latent drift, inert today

`package_submission.MAIN` is a hand-copy of `runtime.Runtime.act` and has fallen
one edit behind it: the runtime applies the hour-1 patch

    if P.open_pump_tell_armed(day, hour):
        self.plan = P.open_pump_tell_keep0(self.plan, day, hour, parse.parse_market(obs)[0])

and the packaged `main.py` does not. `open_pump_tell_armed` requires
`OPEN_PUMP_TELL_KEEP0_ON`, which is `False` (plan.py:1276), so the patch is a
no-op and the two paths agree today. If that switch is ever promoted, the package
would silently ship without it — worth folding into `MAIN` at that point.
The other `runtime.make_agent` extra, the `opening.from_env` wrapper, is
deliberately absent from an OFF build and is a no-op with `KAGG3_OPENING` unset.

## Equivalence: packaged agent vs the judge's coins

`eval_vs_baselines.py --me <tar.gz>` unpacks the archive and seats its `main.py`
as our seat, under `_vendored_imports` — which hides the working tree's `kagg3`
modules, path entries and `KAGG3_*` environment for the length of the game. So
this is the packaged image playing, exactly as Kaggle would load it.

`--seed-per-opponent` draws seed `rng(777001 + 1000003*(i+1))` off the **list

## Self-test

The packaged `main.py` has no `__main__` smoke — by design: `agent` must be the
last callable in the module namespace. The repo's smoke is
`tests/test_submission_runs.py`, which costs nine engine games and builds from
`artifacts/theta.npy` (a different theta), so it was not run under tonight's
two-game budget. Three of its four assertions were covered by cheaper means:
the AST forbidden-import gate ran inside the build and passed (a grep of the
unpacked tree finds no jax/torch/tensorflow import), the byte-reproducibility
assertion was checked directly, and its `test_archive_is_self_contained`
condition is precisely what `_vendored_imports` enforced during the equivalence
game above — which scored 99,612, not the 3,000 a silently-broken archive returns.
