## Data and definitions
- 433 completed live episodes (self-play validation dropped): vrp3 56527550 233 (181-52), vrp5 56542089 188 (126-62), vrp7 56572961 12 (11-1).
  Replays fetched with `Accept-Encoding: gzip` (2.2 MB / 3 s instead of 32 MB / 26 s), cached in `~/stage_gapcensus1/S/gapcensus1/gz/`.
- Snapshot = DUSK (last observation of day d, hour 23) for tiles; DAWN (hour 0) for cash and seed stock; NOON for hands.
- **Owned** = tile not `"LOCKED"`. **Crop-capable** = owned and not a COOP/PASTURE structure (a structure must be DUG before planting).
  **EMPTY** = crop-capable tile carrying nothing: `None` or `WEED` (weed = dead crop from 2 dry days / decay, or a random weed spawn).
  Ripe-unharvested = plant with yield > 0 and age >= max_yield_day (non-ongoing) or >= first_yield_day (ongoing); decaying = step >= max_lifespan_step.
  Empty pens (structure without animal) counted separately. Distance = Manhattan distance to the nearest of the 4 shed-access tiles.
- `S/gapcensus1/tiles.csv`: one row per ep/seat/day, 100-char `codes` (row-major y*10+x: `#` locked, `.` empty, `w` weed, `g` growing,
  `r` ripe, `d` decaying, `A` pen with animal, `p` empty pen) + `crops` (W C T S M / c s g). `seatday.csv` = dawn cash, seeds, hands, hires, quads.
  `games.tsv` = per-game counts. Scripts: `census.py` (2 remote workers), `agg.py`; full output `agg.txt`.
