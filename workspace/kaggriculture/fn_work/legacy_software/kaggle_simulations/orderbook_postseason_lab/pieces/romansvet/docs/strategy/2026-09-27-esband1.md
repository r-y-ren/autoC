## 1. Design
- **Legs:**
  - BAND = the 142 tape seats of `S/bandleg1/boards_all.json` (orig seat).
  - V56 guard = LIVE250 dev 0-19 (manifest seat, vs reacting V56).
- **Fitness** of a candidate on a seat set, paired against the base (shipped g30 on the same seat):
  `F = Σ_f share_f · mean_{seats in f} [ W_FLIP·(win_c − win_0) + (m_c − m_0)/1000 ]`
  - Family shares = vrp10's live band mix over 46 games: MELON 26/46 = **0.565** (the up-weight: 51/142 = 36 % of the leg), V 16/46 = 0.348,
    ZERO 4/46 = 0.087, OTHER 0 (3 seats, no live weight).
- **W_FLIP arithmetic:**
  - The unit is 1,000 coins of paired margin, so "1 flip ≈ 1,500 margin" gives W_FLIP = 1,500 / 1,000 = **1.5**.
  - So a seat that flips scores the same as a seat that gains +1,500 without flipping.
  - This is half the old PEN 3,000, which made one flip outweigh ~2 seats of +1.5k.
  - Scale check: on the base, 21 of 142 band seats sit within ±1,500 of zero (34 within ±3,000; median |m| 6,666). The flippable shell is thin, so margin must still count.
- **Batch:**
  - Each generation trains on a stratified 71-seat half (per family, shuffled once with rng 2027, alternating A/B per generation).
    - A = V41 / MELON26 / ZERO3 / OTHER1; B = V40 / MELON25 / ZERO4 / OTHER2.
  - Why 71 and not 142: the full band would be 16 cands × 142 = 2,272 eps ≈ 1.9 h at the measured 2.8 s/ep wall on 2 procs, over the 90-min cap.
  - PAIRS 8 → 16 antithetic candidates. The centre is not re-run while it equals the base (its F is 0 by construction).
  - Update = centred ranks, as in ESWORK.
- **Sigma:** the 09-25 keep set `run2/sigma.npy` = [2, 2, 2, 2, 0, 1.03, 0, 0, 0, 0] (gene 4 inert, 6-9 frozen). sig_mult starts at 1.0.
  The ESSIGMA1 schedule applies after 3 rejects, with the TRAINFIX3 cap ×2 and floor ×0.5.
- **Accept:** the step candidate is evaluated on the FULL band 142 plus dev 0-19. It is accepted when all four hold:
  - `F_full > best`;
  - band Δtheirs t < 2 (gift-free);
  - band net flips ≥ 0;
  - dev20 net ≥ 0 (the V56 guard must not fall).
  An accepted candidate with band net ≥ +1 is written to `run3/cands/cand_gNNN.{npy,json}`.
- **Generation cost:**
  - Training: 1,136 eps (114 jobs of 10). Acceptance: 162 eps.
  - A 10-episode job takes 56 s on one proc, so 1,298 eps ≈ **61 min** of steady state on 2 procs.
  - The g1 log prints a conservative ETA of ~125 min because its s/ep is esbase's figure, which includes the compile. The logged s/ep self-corrects after g1.
