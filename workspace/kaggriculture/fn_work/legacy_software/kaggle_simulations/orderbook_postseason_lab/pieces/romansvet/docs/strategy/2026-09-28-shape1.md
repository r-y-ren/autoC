## 1. The guards (`agent/main.py` = S/capaudit1/agent/main.py + `shape_ovl.py`; env-switched, default off)
**Idle unit:** a unit whose command after GUARD/CARE equals the model's own decoded command and is PASS or a move. `BCB_HARV_IDLE=pass` narrows this to PASS only.

**Order:** units run GUARD -> CARE -> HARV -> FLOCK -> TOM; the market runs cap -> land -> CREW -> FLOCK -> TOM.

- **HARV** (`BCB_HARV=1` ripe-only, `=2` ripe+fert), d10-29.
  - An idle unit on a ripe, unclaimed tile HARVESTs. Ripe uses GUARD's rule: a crop with yield > 0 that is mature, or an animal with yield >= 3.
  - Other idle units walk to the nearest ripe tile that no unit is harvesting or routed to.
  - Level 2 adds two rules: an idle unit carrying FERTILIZER fertilises the unfertilised plant it stands on, or walks to one (strawberry/tomato first); an idle unit on an animal tile with fertilizer_available collects it.
- **CREW** (`BCB_CREW=median|p75`), d1-29 h0-h2: if farmer + hands + this step's HIRE orders are below the teacher's crew for the day, it adds HIRE orders up to that crew. Each added hire must be covered by cash at the Fibonacci hire price, after the step's BUY_LAND.
- **FLOCK** (`BCB_FLOCK=median`):
  - **Market, d2-9 h1-20:** it buys one GOOSE per step while geese (tiles + shed + carried + ordered) are below the teacher's median for the day. Cash must be >= 300 after the step's committed buys, land and a 100 reserve.
  - **Units, d2-12:** an idle unit carrying a goose PLACEs it in the nearest free coop, or BUILD_COOPs on the nearest empty tile. The nearest idle unit fetches shed geese that nobody carries.
- **TOM** (`BCB_TOM=p75`):
  - **Market, d8-12 h<=18:** it orders the tomato-seed deficit, where the deficit = teacher tomato tiles - (our tomato tiles + seed stock + order), clipped to cash.
  - **Units, d8-14:** idle units plant the stocked tomato seed on the nearest empty tiles.
