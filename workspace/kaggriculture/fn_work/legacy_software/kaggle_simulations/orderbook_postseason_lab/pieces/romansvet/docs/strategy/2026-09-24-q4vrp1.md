## 2. Design (`Q4_VRP_ON`, default OFF)
`plan.py` knobs `Q4_VRP_ON`, `Q4_VRP_DAY` (window start D), `Q4_VRP_LAST`=20, `Q4_VRP_RESERVE` (R), `Q4_VRP_FUND`
("true" | "visible"), `Q4_VRP_RELEASE` (set per dawn by the runtime). In `_derive`: from D to LAST, with nquad == 3, buy
Q4 when `money + release >= land_gap + R` (bypasses the valuation veto, like Q4PROG1); the released coins pay the land
first (`purse = money - land_gap + min(release, land_gap)`), nothing else sees them. Runtime (`runtime.Runtime.act`, and
`S/simgap1/ourseat.play2` for the sim, per board/seat as a traced scalar) sets `release = min(bank, 4000)` at dawn in the
window and takes it off the bank on the day the plan carries BUY_LAND; the shadow stays for everything else. Q4 is planted
by the planner's normal crop choice (the prospective tiles enter `free_slot` / `wants_land`); VRP mode ii unchanged.
"visible" = release 0 (visible purse only). Because the visible purse already covers Q4, **both fundings buy Q4 on 100 %
of boards** at nearly the same day; the visible cells do NOT reproduce the old never-buy behaviour (the bypassed veto does
that), they differ from "true" only by the ~100-300 coin release.
