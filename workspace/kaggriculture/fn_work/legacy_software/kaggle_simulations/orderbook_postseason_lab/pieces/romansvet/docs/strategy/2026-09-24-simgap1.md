## 2. Fixes (sim side only; the agent is untouched)
1. **Runtime layer in the sim** (`S/simgap1/ourseat.py`, mode **guard**): `make_dawn_raw` = the SIMV56 dawn returning the planner's RAW
   market rows (guards write into the planner's slot layout; `render` compacts afterwards, as in the engine); the host keeps our seat's
   day plan as numpy, and each turn calls the SAME `agent.overflow.guard / guard_v2 / guard_v3` on `build_obs(our seat)` with a
   per-day `pending` list, then `render.turn_action` → tape encoder → our seat's rows (`make_turn2`: per-seat host-row override).
   The day plan is still the jnp `build_day` with the traced head (sampling heads / log-probs keep working for trainers).
   Mode **exec** (reference): the engine's `runtime.Runtime` itself drives our seat (any runtime-only switch, greedy numpy head only).
2. **Floor cross** (`src/kagg3/sim/market.py`): a `lax.while_loop` replays the engine lockstep round by round for a cross whose sale
   quote is at the floor (seller `P(inv)`, buyer `P(inv-1)`, buyer dropped when it cannot pay), remainder walks solo. Only fires in
   that regime; every other path is byte-identical.
