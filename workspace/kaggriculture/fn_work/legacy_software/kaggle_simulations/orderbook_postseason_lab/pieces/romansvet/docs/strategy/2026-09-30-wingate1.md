# WINGATE1 - the common upload gate (BRAINSTORM8 round 1, 2026-09-30 10:03-15:10Z)

**Purpose.** The 15:00Z selection gate needs one tool that reads every stream's paired rows the same way: the astra
brainstorm7 "Common final gate" (docs/strategy/2026-09-30-brainstorm7-summary.md section 2). A frozen candidate is compared with the frozen live PFS agent on the same boards and seats. The tool reports:
- the paired WIN-SCORE gain (win 1, tie 0.5, loss 0);
- a 95 % bootstrap interval, resampled by board/tape;
- the per-family weights, fixed before any results;
- the V / family / own / unit / runtime guards.

**Tool:** `S/wingate1/gate.py` (committed with this doc). `gate.py PRESET ...` prints one candidate. `gate.py --table PRESET ...` writes `S/wingate1/CANDIDATES.md` and `S/wingate1/out/<preset>.txt`. `S/wingate1/refresh.sh` fetches the remote rows read-only (`fetch.sh`) and rebuilds the table.

## 1. Definitions (fixed at 10:10Z, before any candidate was read)
- **Adapters, one per row format already produced:**
  - `tape`: jsonl rows `{ep, seat, rew, sim_ours, sim_opp, sal, nerr, p99|tp99}`. Streams: RSTUNE1R, P48SWEEP1R, PQ4TAPE1R, SWITCHSWEEP1R, PANELPREP1 and HYBRID2.
  - `vcsv`: S/vband1 `vr.py` csv plus the `_st.jsonl` sales ledger. Used for the V56 m40/v21 reads of every stream.
  - `taperl`: TAPERL1/2 `env.py` rows `{ours, theirs, live}`.
  - **Stochastic heads** are read with `seeds=[...]`: per board, the mean over the seeds. Win score is averaged, so no seed gets selected.
- **OFF** is the PFS control for the same board and seat, in this order:
  1. the stream's own same-tree OFF rows;
  2. the anchor PFS sim rows (PANELPREP1 `ctl_rstune` / `pfs_ctlrest`, exact to live);
  3. the live record.
  PQ4 115319134 is the known non-exact game. It changes margin only, never win score.
- **Families and weights** (live band mix, memory project-gate2.md): V .59, MELON .19, P48 .12, PQ4 .06, other .04.
  - V56 sets are V.
  - A tape row is PQ4 if its episode is on the PQ4 bank list (`S/pq4tape1r/pq4eps.txt`, signature classifier); otherwise it takes its set family.
  - OTH is split by the rival's d2h0 melon tiles (`S/p48loss1r/games.json` `mel`): more than 0 is MELON, otherwise other. On the 56 OTH games that gives 40 MELON and 16 other; 38 MELON remain after the 2 P48-list games.
  - Families that were not read, or were read on fewer than 10 games, are renormalised out, and the COVERAGE guard fails.
- **Unique games:** each (episode, seat) counts once. The row comes from the first set that lists it (V, then reactive P48, then PQ4, then OTH), so 18/23 PQ4 and 2/56 OTH games count once inside P48.
- **Interval:** percentile bootstrap, 10,000 resamples of unique games stratified by family.
- **Advisory:** a one-sided sign-flip randomisation p over the same weights (see section 2).
- **Validity:**
  - A row whose replayed rival ends below 50 % of the control rival's money is a broken tape and is dropped (JC1 minimum; the drops are printed).
  - HYBRID2 `H2_SKIP` rows for unfired seats are truncated, so ON = OFF there by construction.
  - `*_faith` presets add the h2sum unit rule: rival units within 5 % of live.
- **Guards:**
  - G1: V56 m40 W >= 37/40 and paired win score not lower.
  - G2: v21 W >= 12/21 and not lower. On a partial read, G1/G2 FAIL only when the result is already lost.
  - G3: no family down more than 5 points.
  - G4: own >= 0 on every set.
  - G5: d15-17 strawberry units >= control.
  - G6: d18-29 milk+wool+egg units >= control.
  - G7: zero runtime errors.
  - G8: OFF byte-identical (offid rows).
  - G9: apply p99 < 0.65 s, taken as the 95th percentile of per-game p99, because the PFS control itself reaches a 0.67 s maximum under load.
  - G10: all 5 families read.
  - WIN: weighted-gain 95 % LB > 0.
  - A guard with no evidence prints N/A and counts as not passed. The verdict is UPLOAD-WORTHY only if every guard PASSes.

**Caveats:**
- The weights and guards are exactly astra's gate; G5/G6 use a strict mean >= 0 with no noise band.
- With fewer than about 20 changed games, the percentile LB under-covers (placebo coverage 0.875). Use the sign-flip p.
- Taped sets inherit tape validity. Broken tapes (rival < 50 % of control money) are dropped. HYBRID2 also has faithful-only presets.
- EVESTOCK1 appended three presets into `S/wingate1/gate.py` (additive, kept).


## 4. Files
- `S/wingate1/gate.py`: the tool, adapters and presets.
- `fetch.sh`: read-only ssh tar of the stage_r/{rsfix1, hybrid2, taperl2, panelprep1} res folders.
- `refresh.sh` + `loop.sh` + `autoline.py`: refresh every 15 min until 15:05Z.
- `presets.txt`: the table list. It globs stream specs: STACK1, STACK2, SCALEGRID1, CONFIRM1, RSFIX2, EVESTOCK1.
- `CANDIDATES.md`, `out/*.txt`, `checkpoint.txt`.

**Using it from another stream:** write a spec json with the same keys as a preset (absolute paths), then run `gate.py --spec x.json`. STACK1, STACK2, SCALEGRID1 and CONFIRM1 already do this.
