# ESHEADCL1 -- closed-loop ES on head_940's day-windowed output offsets (TRAINREVIEW1 experiment 2, "ESHEAD-CL")

2026-09-29 11:42-15:45Z, time-boxed training stream. Dir `S/esheadcl1`. Master src 8d670dad (vrp20 = PFS + head_940), unmodified.

## What was new

- **Fitness vs the REACTING rival.** Every candidate played the closed-loop judge (REACTCLONE1 fast env, JUDGERIVAL1 `g0capsfix` rival on the JUDGEGPU1 GPU1 server).
  - Fitness = mean paired own coins vs PFS on the same games, minus 1.0 x max(0, (PFS margin - 1,000) - candidate margin).
  - Nothing had optimised the head against a reacting rival before. flow267/268 used tapes and head_940 self-play.
- **Genes = output offsets at the decode quantum, by day window.** The prior ESHEAD searched logit biases on b3.

## Gene block

- `S/esheadcl1/residual_head.py` = master `core/residual_head.py` + an optional `dwin` float32[W, 18] / `dwin_d0` float32[W] pair in `numpy_fn`.
  - On a dawn with day >= `dwin_d0[0]`, each slot's greedy action index moves by `dwin[w, s]` and is clipped to the slot's range.
  - `w` = the last window that has started.
  - Without `dwin` the function is the shipped one, line for line. A zero `dwin` gave 200/200 identical decodes (unit check) and 12/12 identical game rows (below).
- Windows d1-4 / d5-9 / d10-14 / d15-19 / d20-29 (d0 untouched: the head cannot act there).
- Groups per window (10):
  - plant WHEAT / CARROT / TOMATO / STRAWBERRY / MELON (d_plant slot, +-1 step = +-1 tile of the day's ask);
  - animal GOOSE / COW / SHEEP (d_animal, +-1 animal);
  - hire (d_hire, +-1 hand);
  - hold (the 9 sale-hold slots together, one gene: -1 = hold x0.5, -2 = x0; + is clipped, the head's no-op is x1).
- Gene value = continuous, rounded to an integer step (`np.rint`) when the candidate npz is written.
- Candidates = head_940 arrays + `dwin` + `dwin_d0` in `S/esheadcl1/params/*.npz`. head_940 / residual_head.npz / theta7659 were never touched.

## Harness

- `eshcl_rc.py`: a one-shot import hook wraps `eval_vs_baselines.arm_residual`. After the tree body arms head_940 as shipped, it replaces `plan.RESIDUAL_FN` with the candidate's `numpy_fn`.
  - `S/judgerival1/rcr.py` and `rc.py` then run unchanged via runpy.
  - At exit it writes a hook json: armed, dawn calls, dawns whose override differs from the plain head, per slot.
- `wloop.sh`: 3 remote job-queue workers, nice 19 + ionice idle, CPU, rival forward on the shared GPU1 server.
  - Each started through the load < 12 gate and `flock -o gpu_launch.lock` + sleep 90.
  - One job = one candidate x 12 games in one batch (N 12), ~200 s.
- `es.py`: the driver. `run.sh`: stage + launch.
- **Identity.** A zero-offset candidate reproduced the PFS g0capsfix baseline rows (S/judgerival1/res/g0capsfix/pfs.csv) on 12/12 games (m40[34:40] x 2 seats). 360 dawn calls, 0 changed.

- **Every block is live at the one-step quantum.** d20-29 is nearly dead (65 coins per game, 8/24 rows moved). The pre-registered rule dropped it, since the time box fits <= 40 dims at >= 2 x dims.
- **So dims = 40** (4 windows x 10 groups): 6 generations x 16 = 96 candidates, >= 2 x 40.
- **In d1-9 both directions of a move cost own coins** (-4.7k / -2.2k and -4.2k / -2.8k). PFS + head_940 sits at a local optimum there.
- **Sigma 0.5, not 0.7.** A gene only acts once it rounds to +-1, so sigma sets the share of genes that move:
  - 0.7 moves ~48 % (~19 of 40); 0.5 moves ~32 % (~13).
  - With every d1-9 move costing ~1k, one good move drowns among 19.
  - 3 gen-0 jobs at 0.7 were killed by literal pid and never scored.

## ES

- (mu 4, lambda 16) with 8 antithetic pairs around the centre.
- Common boards per generation: m40[6g : 6g+6] x 2 seats = 12 g per candidate, vs g0capsfix.
- Centre = mean of the top-4 genes.
- Every generation also re-reads the incumbent on the new boards (and the centre, once it rounds to a non-zero body).
- Incumbent = replaced only by a candidate >= +1k own over the incumbent on the same 12 games, with higher fitness.
- PFS wins 9-12 of each generation's 12 games vs g0capsfix (110/120 over gens 0-9); candidates won 8-12. With so few losses to flip, own coins carried almost all the signal.
