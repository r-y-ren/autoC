walked the shared melon curve before that fixed line; the reacting clone did not withhold a unit.

our early non-melon mix removes competing non-melon output and hands the reacting rival that value;
any melon-price damage is overwhelmed by this non-melon transfer. HOLD=2 is exactly the matching
day-12 cell, so stacking the dump changes no conclusion.
