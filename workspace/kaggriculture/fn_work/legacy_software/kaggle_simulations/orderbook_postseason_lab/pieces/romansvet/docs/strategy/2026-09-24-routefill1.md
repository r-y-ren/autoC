## 1. Design
Dawn, after `build_day`: the VRP solves the planner's task set with the same crew (mode i). Spare = idle unit-turns on the
solved routes (after each unit's start: waits + after-finish). Candidate tiles = owned EMPTY (or WEED, DIG first) tiles no
planner/frozen stop touches, not an access tile, nearest the shed first. Each fill = one stop (PLANT + same-day WATER: the
planting day counts as unwatered, E:222/783) inserted by the solver's cheapest insertion; admitted while (a) the insertion
is feasible, (b) the ledger's load on every later day of the planting's life (TEND turns/fill/day, +1 on harvest day)
stays <= FRAC x today's gross spare, (c) <= CAP. Then relocate/2-opt + spawn fixed point; if the day fails, the fills are
dropped and the same-crew solution is kept. Seeds: dawn pool minus the planner's own PLANTs; the shortfall bumps the
planner's own BUY_SEED row of the crop (hour 1 on every d10+ day: hour 0 is 10/10 HIRE rows) or appends one after the last
used slot (lockstep order kept). Later days' water/harvest are the planner's own (it tends every plant). Modes: i_fill =
fills, crew kept; hybrid = fills then mode ii drops; ii_fill = mode ii drops then fills into the minimum crew.
