# SEATFIX -- the feed omits `index` when it is 0: full toolkit audit

2026-09-16.  Branch `seatfix`.  Trigger: `docs/strategy/2026-09-16-nbintel2.md` --
the credential-free `ListEpisodes` feed serialises `episodes[].agents[]` with proto3
default-omission, so the **seat-0 entry carries no `index` key at all**.  A reader that
defaults a missing `index` to 1 reads our own market row / reward / rating as the
opponent's.  `S/nbintel2/classsplit.py` was written with the right default; the rest of
the toolkit had never been audited.  This is that audit.

## Result: no defective reader on disk, and no banked number moved

Every `index` read in `S/`, `scripts/`, `src/` already defaulted to 0
(`git log -S'get("index", 1)'` over all history: no hit).  The rest of the toolkit
never reads `index` at all -- it takes the seat from the agent's **position** in the
`agents` list, which is a different mechanism that happens to agree:

list position == `index` on **598 / 598** agent entries in every feed json on disk, and
feed list order == the replay's `info.TeamNames` order on **227 / 227** cached replays
with a feed row (one row differs only in the opponent's *display name* -- that team
renamed itself between snapshots; seat 0 matched in both).

Banked seats re-derived from the feed with the new helper:

| banked set | rows with a seat | agree with feed `index` | mismatch |
|---|---|---|---|
| `S/v45leg/boards.csv` (V45LEG) | 30 | 30 | 0 |
| `S/v45leg2/boards.csv` (V45LEG2) | 44 | 44 | 0 |

`S/band180/boards.csv` carries no seat column (its tapes are cut upstream).
**Banked numbers affected: none** -- V45LEG / V45LEG2 board selection, TOP5NOW and the
POPSHIFT ratings all stand as published; no engine leg was re-run.

## What changed

* **`S/kaggle/seat.py`** (new): `agent_index(agent)` -- the single place the
  "missing == 0" default lives -- plus `our_agent`/`opp_agent`/`our_seat`/`opp_seat`
  (`sub` may be one id or several; `opp_*` is None on a self-play VALIDATION episode).
* The four `index` readers import it; the expression is identical
  (`int(a.get("index", 0) or 0)`), so the refactor is behaviour-preserving.
* **`tests/test_feed_seat.py`**: fixture episodes with our seat 0 (`index` omitted) and
  our seat 1, both seat layouts of the rating column, the validation self-play case, and
  a **static guard** that fails if any `.py` under `S/`, `scripts/`, `src/`, `tests/`
  ever reads a feed `index` with a default other than 0.
