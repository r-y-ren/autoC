## Design (answers RLREVIEW1: σ 1e-3 never crossed a rounding gate; nobody touched d0-1/hires/land; opponents were open loop)
* **Fitness = real engine, live file agents that react.** Our seat = shipped tree (LE.SWITCHES + head_940 + theta7659) + candidate
  overrides; opponent = a `S/espool1/bank/<label>/main.py` snapshot (POOL1 keep=1, 36 agents, md5s in `bank_md5.txt`, + v56/v57/v15stack).
  Paired vs the SHIPPED genome on common (family, LIVE250 dev idx 0..99, seat orig|flip) triples, 8/gen, fresh each gen;
  F = mean win flip + 0.1·mean clip(Δmargin, ±5k)/5k; mean Δtheirs > +300/game = infeasible. Ship baseline cached (deterministic engine).
* **Families (POOL1 finding: all 34 losses of the shipped stack vs top-12 are the ahmedberatozer V-series).** 87.5 % of triples from
  trainV (V-series v25/v31/v34/v38/v41/v53/v55 + 2 V clones + v56 + v57), 12.5 % from 24 non-V; held out: v39 + v15stack (V) + 2 non-V.
* **Mutations that move something** (`layout.txt`): 9 integer genes (±1/±2 steps, antithetic mirror), 27 switch bits (flip p 0.02),
  head_940 b3 Gaussian σ 0.7 (p 0.5). Elitist racing: 12 mutants of the centre + 2 elites re-evaluated each gen; centre moves to an
  archive candidate with ≥ 24 paired games, F − se > 0, F > F(centre).
* Engine rules (POOL1): actTimeout 600 in every `make()`; a seat < 5,000 = VOID. One fresh process per game (spawn, max_tasks_per_child 1)
  so no module/sys.modules state leaks between candidates or opponents.
