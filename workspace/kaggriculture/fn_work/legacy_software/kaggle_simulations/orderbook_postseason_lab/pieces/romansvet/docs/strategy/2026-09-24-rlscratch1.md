## 0. Design (written before launch)
* **Init** = `head.init_params(seed)` (the path head_940's lineage started from): random trunk, `w3 = 0`, `b3 = ZERO_BIAS 4.0` on each
  slot's no-op → greedy u0 = the frozen planner alone (no residual), sampling ≈ 0.2 off-no-op noise. (flow234_scr was a THETA ES
  run, not a head; there is no earlier scratch head on VRP code.)
* **Trainer** `S/rlscratch1/ppo_mix.py` = one PPO update over TWO rollout sources, same head/feature contract:
  (a) **sim V56**: `ppo_v57.play` exact shipped seat (guard mode + VRP, SAFETY off, shop CRN), 16 games/update from the RLV57 panel
  (96 fresh seeds, alternating seat; head_940 greedy baseline reused from `rlv57_a/panel_base.npy`);
  (b) **engine pool**: RLPOOL1 `rollout.play` (real kaggle_environments, shipped switch string, actTimeout 600, void < 5,000) vs ALL 37
  POOL1 keep=1 agents + live V56 `main.py` (38 opponents, train on all — pool held-out legs are no longer held). Engine panel = 192
  fixed (fresh seed, seat, opponent) triples: every agent ×2 (76) + 116 weighted 60 % V-series (ahmedberatozer + forks, V56) /
  40 % poolcheck1 top-12 non-V → mass ≈ V-series 46 %, top-12 non-V 30 %, rest 24 %. head_940 GREEDY baseline per triple (engine,
  same seed/seat/opp), queued first on the engine workers, lazily awaited; sampled games wait until their triple's baseline exists.
  Engine games are async (3 workers, drained after each sim batch; games older than 3 updates dropped). ~30-60 s/game/core.
* **Reward** (both sources) `r = (win − win0) + clip((ours − ours0) − 1.5 (theirs − theirs0), ±3000)/3000`, batch-normalised;
  GAE λ 0.95 γ 1 on the head's value.
* **PPO**: lr 3e-4 → 1e-4 linear over 200 updates, clip 0.2, ent 0.001 (×10 if entropy < 9.0), KL-stop 0.01, 4 epochs × 4 minibatches,
  grad clip 0.5. Checkpoint every 10 updates (+ u0 = init). Gate every 10-20 updates: `S/rlv57/gate.sh dev` semantics (V56 dev100
  exact sim, break off, paired vs head_940 `dev_h940ns.tsv`); promote legs only at dev net ≥ +2.
* **Speed budget**: sim 16 games ≈ 60-110 s + engine drain; remote box shared with knobvrp1 (7 procs on 8 cores at launch) → expect
  ~2-3 min/update ≈ 50-70 updates in 3 h, ≈ 16 sim + 3-6 engine games per update. ONE arm (GPU0); a second arm would halve host CPU.
