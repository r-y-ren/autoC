## v8 换轨首夜实验记录（W1/W2/W3，2026-08-30 深夜）
- **W1 种子供给 buy-to-cap + 钱包缩放**：真实修复（我方麦田 16→0 衰减的根因是 `seeds<6→买12` 只能供 2.4 种/天 + money≥150 整单拒绝 vs 中局现金 4-116）；探针 s103 从 v7.2 的负局翻 +28k，WATER 690/692 执行近乎完美，小麦收割 98-129→145u。
- **W2 草莓 18→12**：现金曲线健康化（d20 8.5k→19k），探针两格均胜。
- **消融裁决（vs v7.2，各 176 局）：W1+W2 = -433.8k NOT MERGEABLE**。逐对手：expansionist -245k / baseline -92k / monster -87k（**联合拥堵**：四小麦系对手合计 -442k）；奶牛系全正（self_feed +46k / scale +33k / cow_baron +22k）。
- **W3 无争夺门**（对手麦田 ≤10 且价 ≥30 才拓宽）：小麦系对位修复（expansionist -245→-131k、monster -87→-29k、template 转正）但 **scale_ranch +33k→-124k**（SCALE 模式配额被误关）+ baseline 仍 -136k → **-497.5k NOT MERGEABLE，连续两次熔断**。
