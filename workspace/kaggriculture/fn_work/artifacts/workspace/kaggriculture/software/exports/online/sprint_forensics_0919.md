## 3. 因果链（本地涨、线上跌的机制）

1. **结构性断点一：四层切换（v12.2，603）**——care 操作 217→168、外购饲料 198→77、峰值畜群 13→8。畜群塌陷与后来本地抓到的 PLACE 站误判已完成 bug（买入牲畜永不安置）吻合：**v12.2 带着该 bug 上线**（修复在 v13.0 才落地，从未以修复形态重新提交）。四层切换时已知的本地 -7~-12% 效率债（闲工人 PASS +32%、HARVEST -50%、FERTILIZE -83%）在线上表现为 care/饲料/畜群三塌。
2. **结构性断点二：小麦化换轨（v13.5→v13.7，532-550）**——plant19/herd20/seed21 三连发把在田结构从"均衡高价混合"（麦17/莓18/瓜9/萝11）改为"麦底仓独大"（麦34/莓9-11/萝0）。**当前分段的赢家结构是草莓 20-31 + 瓜 12-18 的均衡混合**（对手参照行），且外购饲料量是我方 10-40 倍——赢家用买饲料换畜群产出（奶/毛日收是 d12 现金桥），我方畜群 16 头却饿着养。
3. **d12 现金缺口全代未解**：我方各代 89-1,406 vs 对手 6.8k-15.6k——round-15 发现的结构差在所有后续候选中依然存在。
4. **组内分层对照（胜负不变式）**：同代内赢局与输局的我方结构几乎相同（v13.6 赢局 WHEA 34.0 vs 输局 33.8；v9.2 草莓 18.0/18.0）——**结构由候选代际决定，代际结构错则胜负只随对手波动**。v10.3 的输局独有信号：畜群只建到 10（赢局 14.4）、care 178（赢局 236）——畜群建不起来就输。
5. **本地 quickwin 为何全程绿**：自对局镜像里"麦底仓+大畜群"赢旧结构；但线上对手池惩罚高价线缺失。这是分布偏移的标准形态，且这次有了机制解释。

## 4. 结论与下一刀的含义

- **保底锚 v9.2 + v10.3 获现况数据背书**（man-final 维持）。
- v1.5 P0 开局减档已被本地灾难诊断否决（-30.74%，quickwin_p0disaster）；本报告进一步表明 09-04 基于 round-20/21 回放的小麦化解读**过度外推**——v1.5 B/C 包在接线前须按本报告重估。
- 下一刀的证据指向：**在保留的底盘上恢复 v10.3 经济域**——作物均衡配比（草莓/瓜/萝卜线复活、麦底仓回 17-20）+ care 强度回 220+ + 外购饲料量级上探 + 畜群建成鲁棒性（v10.3 输局模式）。这与计划轴 ②（求解器效率债：care/施肥优先级）高度重叠——效率债的修复本身就是 care 强度恢复的载体。

## 5. 边界与诚实声明

- 评分随对局漂移，单点分数非终态；胜率样本 8-37 局，Wilson 区间宽（v10.3 的 66.7% 在 n=12 下 95% CI ≈ [35%, 88%]），但方向与跨代结构证据一致。
- 对手席统计受各 ref 匹配档位混杂（v12.2 的对手最强）——跨组对手对比只作量级参照（饲料 10-40 倍差在任何档位都成立）。
- 本报告不构成任何"本地改动即可涨分"的预测；一切改动以线上公共局为唯一裁决轴（2026-09-02 战役裁定不变）。
