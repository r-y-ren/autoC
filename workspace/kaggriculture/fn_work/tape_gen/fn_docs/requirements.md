# 需求文档：磁带生成管线（tape_gen）

## 根本目的
把 v48 未随包发布的"计划层生成管线"（轨迹挖掘→路由库→变体→真实对手池选择）用我们的基建（逐位孪生+全量语料+seated 评估器）重建出来。成功=M1 生成件 seated 对纯 v48 互胜 ≥0.45（证明搜索生成路线成立）；M2 五线全过（成品）。

## 环境与技术栈决策
| 项 | 决策 |
|---|---|
| 管线运行时 | Python 3.14 本机；离线分析可用任意已装库（numpy 等） |
| 评估器 | 数字孪生（fn_work/legacy_software kaggle_simulations agent planner twin 通道）+ seated 真实对手流 |
| 最终产物 | v48 执行外壳 + 生成 RouteLibrary + 选定反射层配置；stdlib-only/离线/确定性 |
| 参考 | island-ga-moat-0920（本地 MIT 全管线）+ v48 深读档（fn_docs/hybrid/results/2026-09-23-v48-coordination-deepread/） |
| 日志 | 消融账本 JSONL（每选择留痕） |

## 术语表
| 术语 | 定义 |
|---|---|
| 磁带/路由 | 719 步整季动作数组（单位动作+市场单） |
| 骨干 | 库中被最多变体共享前缀的走位脚本 |
| 克隆席 | 与 v48 家族动作流 1-51 步逐字节一致的席位（挖掘时剔除） |
| 市场编辑变体 | farmer 流逐字保留、仅市场单被编辑的变体（v48 自用技巧） |
| 消融树 | 反射层开关/阈值配置的组合空间；稀疏枝=启用模块数少 |
| seated 适应度 | 候选件注入我席对真实对手回放流的整季重演胜率/边际 |
| M1/M2 | 追平线（互胜≥0.45）/五线全过线 |

## 需求条目
### R1 轨迹挖掘器 [P0]
- 内容：语料（round27/28 回放+领先崩塌 14 局+r26/r27 缓存若有；双席全收）→ 逐席动作流库（JSONL+元数据：席位/对手/结果/边际/克隆旗）。克隆过滤=对 v48 家族 1-51 步逐字节一致判定（先例 track-C）。
- 验收方式：确定性（同语料同输出）；克隆过滤的召回/精度抽查 ≥10 局人工核对清单；语料哈希入账本。
### R2 路由库构造器 [P0]
- 内容：挖掘流→嵌缀树路由库（骨干选举+商店事件分叉+共享前缀约束）；输出格式兼容 v48 执行机制（RouteLibrary 载入即回放）。
- 验收方式：任一库内路由经 v48 回放器逐步回放=源轨迹动作逐字节一致；分叉步与事件对齐报告。
### R3 市场编辑变体器 [P0]
- 内容：骨干 farmer 流保留、市场单编辑（时点/量/帽算子集）生成变体；算子文档化。
- 验收方式：变体 farmer 流与骨干逐字节一致断言；市场单差分账本。
### R4 反射层配置搜索器 [P0]
- 内容：配置空间=v48 自带反射层开关/阈值（含编译未启用的 market_maker/MPC/终局强改）+新增保险层（死价护栏等）；消融树搜索带**稀疏惩罚**（启用模块数计入代价）。
- 验收方式：空间定义文档+账本；稀疏优先可证（同适应度取更稀疏枝）。
### R5 holdout 选择器 [P0]
- 内容：适应度=seated 对真实对手流（训练/留出局集分离，留出≥30%且与挖掘集不相交的对手）；选择只在留出集上裁决。
- 验收方式：分离可复现（种子+局单）；最终件附留出集逐局边际表。
### R6 组装与门禁 [P0]
- 内容：选定库+配置→v48 外壳重打包（换 RouteLibrary 与配置字节）→发射四门→seated 评估。M1 判据=对纯 v48 互胜 ≥0.45；M2=五线（h2h≥0.65/巨人 seated×3/胜局回归 8 局/四门/经济面 12.7k@d14-17）。
- 验收方式：M1/M2 逐线数字；失败如实分档（管线不成 vs 未到五线）。
### R7 确定性与账本 [P0]
- 内容：全管线种子化；语料/中间件/选择全哈希入消融账本。
- 验收方式：双跑逐字节一致（管线产物）；账本 schema 校验。
