## 判据 c 的失败结构（诚实分解）

1. **结构性 3 局（塌方胜局 110683437 -55.6 / 110695554 -27.4 / 110696787 -25.5）**：d0-d1 投影器原生锚（identity，sell=1.0）直接胜出 → 轨迹逐位=纯 v13.8（与 d0 反事实 base 完全一致），而这 3 局线上 DTSP v2 靠早期 C1×1.25 激进扩张取胜。守成支点（b 判据 5/9 挽回的同源机制）与这 3 局直接冲突——**动支点（identity 投影口径/τ/d0-d2 开窗豁免）是蓝图级变更，须协调者裁决**。
2. **残余 4 局小幅主动损伤（-8.0/-9.2/-9.1/-36.5）**：中局 C1×1.25 家族内的日程/钱包档选择抖动（1 日地平线对地价支付时点不可辨）。已落地三项机构修复（见下）后幅度收窄，未清零。

## 复裁过程中定位并修复的选择机构缺陷（各有实测损伤反证）

1. **rollout 比较集**：v2 残留实现=投影最优+枚举序前 K（键序，非投影序——与 runtime 模块头"投影 top-K"文档不符）；v3 修复=投影排序 top-K 且 identity 恒在比较集。
2. **等值兄弟的字典序默认**：投影器对钱包档不可见、对非绑定容量下的日程档不敏感 → J 等值兄弟按 ASCII 序中签 LOOSE（-39.8k 灾难注入）与 L+4（-27.9%~-42.0% 主动损伤）。修复=键编码保守默认（LQ0 钱包 STANDARD 先、L0/H0 原生日程锚先、N 负档先于 P 正档）。
3. **rollout 改判 τ 闸**：rollout 覆盖投影最优需决定性边际（>τ×|proj_best|；法证终稿 §4"拒收"语义）——非决定性改判=支付时点伪影驱动的选择抖动。
