# DTSP v3.1 压力自适应折扣标定与复裁摘要（2026-09-20）

- 实验：悲观折扣从全局常数 0.75 改为对手压力函数 `disc = 1-(1-0.75)×s`，`s = max(s_herd, s_quads)`（畜群/象限产能基座，obs 全公开）；`s_herd=clamp(opp_herd/H_REF)`、`s_quads=clamp((opp_quads-1)/2)`；资金差信号**预登记关闭**（22 局逐日轨迹实测：囤钱型弱对手 110683437/110698875/110692292 与巨人相对资金 8.8x-117x 交叠不可区分——资金是"未再投资"信号，非"倾销能力"信号）。
- 顺手项（K2 钱包档可见性）：投影器评分级纳入 liquidity 轴——非 STANDARD 档计划按"模型现金轨迹跌破 STANDARD 地板的 $·日面积×0.3"记流动性风险罚分（无罚分轨迹上计量、季末一次扣除，无逐日复利）。

- 标定协议：预登记网格（C0a=v14.2 语义锚 / C0b=仅修 trim / C1-C8={gated|open}×{H8|H12}×{LIQ 0|0.3}）× smoke 6 局（110699710/110687913/110841464 + 110683437/110696787/110790899）选参 → official 一次终裁。选参规则与 tie-break ②方向修正记录见 `v31_pressure_calibration/v31_calibration.json`（`reselection_note`：修正后选中 C8_open_H12_L3；rollout 未重跑）。
