## 0. 头号发现：ep110699710"全变体同值"异常的定位与改判——无探针 bug，是真实的"换脑错配"塌陷

**现象**：中途注入矩阵中 ep110699710（vs Umkaaa，truth 67,069）三个注入黎明全变体同值

   **覆盖生效而行为不变**，即旋钮在该局轨迹上从不绑定。

   **d16 全部饿死归零**，此后 0 头到终局——终局 15,828 = 纯作物经济。
4. **对照实验排除"重启伪影"**：把 v13.8 从 d0 自走到 d6，再以全新命名空间冷启动接续**它自己的**

   同一 agent 在 DTSP v2 早期分叉造出的 d6 态上饲喂链塌陷，是**状态依赖的真实策略失败**。

  （110681129 对手 peak_head=0、110691193=0——**开局即无动物线的对手**）。

  13 败总和 **-259,386**，其中 3 崩局（≤-45k）合计 **-141,074**、vs 对手 ≥85k 的 9 局合计 **-244,253**

## 4. v3 架构建议：杠杆轴并入 PlanSpec 计划空间，投影器+孪生 rollout 逐黎明选

**核心论点（三条件全部实测成立）**：

1. **各局最优杠杆不同**：d0 口径逐局最优 = base×5 / V_WALLET×3 / V_COMB×1（中途口径
   base×5 / V_WALLET×2 / V_WALLET0×1 / V_COMB×1）——**单一全局杠杆不存在**（V_COMB 旗舰在两种
   口径均 FAIL：1/9 与 3/9）。
2. **固定组合是高方差赌注**：V_COMB 对 13 胜局 4 局损伤 >5%（最深 -48.0k）、对 9 败局 3 局损伤
   >9.5k——手写"何时开组合"的规则等于把投影器的误选风险硬编码。
3. **"换脑错配"是最大单局风险**：110699710 证明错误决策链的组合可以在单局损失 51k 级
   （DTSP 早期 + v13.8 接管 = 15.8k vs 任何一路连续打满 ≥67k）。

因此 v3 不应在 src 写任何新全局规则，而应把本轮验证的杠杆**作为计划空间的新轴**并入
`planner/plans.py` 的 PlanSpec，沿用 DTSP 原生哲学：**enumerate → 投影器排序（trimmed_mean
@pess0.75 对手面）→ 孪生 rollout 终审 → 逐黎明采纳**。

## 6. 未解问题

1. **V_COMB 成分归因缺失**：110687913 的 +14.8k（d0）在 land/wallet/pace 三轴间未消融

2. **V_WALLET 单轴胜局回归未测**：组合的胜局损伤不能归因钱包轴；K2 上线前置门。
3. **非自适应对手偏差未定量**：两口径共用"对手=回放固定动作"；我方改道越成功对手被挤压越重
   （其终局被低估、我方挽回偏乐观）。需对手重规划（孪生双席策略）rollout 才能消除——
   工程量与 overage 预算约束待评估。
4. **孪生终审的线上预算**：逐黎明对 top-k 候选跑全季 rollout 的耗时（单 rollout 实测 8-18s 量级，
   线上 actTimeout=1s / overage 总预算 60s）决定了只有"投影 top-1 复核"或"降载短季投影"可行，
   需要专项设计（P3 runtime 现有 min_projector_budget_s 机制可复用）。
5. **26 局 first-mismatch 日分布未跑**：本轮由 d6 注入=d0 base 逐位相等反推 7/9 局首分叉=d6 黎明、

   基线数据。
