## 6. 立得的结构结论

1. **别动骨架**：4羊+10牛+15棚+3象限+d10 雇 11 是全网收敛解，我方与其零差。结构手术（加羊/买SE/转鹅）期望收益为方差而非均值（38/82 巨人可用，但 44/82 巨人不靠它）。
2. **d0 羊-only 纯净窗**（首羊毛 6/羊 顶格）：磁带 d0 那头奶牛每局偷走 ~1.5-2k；牛推到 d5-d7 与 SW 窗同步即可（中位赢家正是如此）。
3. **d6/d10/d29 三大出清窗打满**：d6 羊毛 24 单、d10 西瓜44 单+早奶奶、d29 清仓 8.3k——这三窗合计差 ≈ +4k/局，恰是 d10 锁定与终局差的主体。
4. **饲料自给**：外饲依赖 0.48→0.33 可省 ~800/局（赢家用 d5-9 小麦茬自给，磁带 d13-14 集中抢购）。
5. **中段收入率**：同产能下赢家日收入稳定 +8-12%（卖时+雇工后置），是"锁定 d10"后缺口持续放大的主因；终局现金转化率 0.735→0.786（死库存 -2.8k）。
