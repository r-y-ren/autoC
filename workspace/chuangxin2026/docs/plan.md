## 0. 电梯演讲

**禾策 = 给小农户的"经营决策大脑"**：把农产品价格、产量、气象的时序预测和种养结构、现金流、卖出时机的量化决策，装进一个可解释的 AI 助手。它不替农民种地（那是无人农机的事），它回答农民最亏钱的三件事——**种什么、养多少、何时卖**。

- 参赛定位：中国国际大学生创新大赛（2026）高教主赛道 **"人工智能+"类 · 本科生创意组**
- 一句话差异化：市面上的"AI+农业"金奖项目在做**机器换人**（无人农机，如 2025 金奖"知耘"），我们做**决策换脑**（经营决策软件闭环）——互补，不撞车。

## 1. 背景与痛点

### 1.1 真实痛点（定性，走访后回填实证）

小农户与家庭农场的经营决策高度依赖经验直觉，三个典型决策缺口：

1. **种什么/养多少**：跟风种植导致"价跌—弃种—短缺—价涨"周期性波动，缺乏基于行情与自身资源禀赋的结构优化工具；
2. **何时卖**：收获季集中上市压价，缺乏"存 vs 卖"的时机决策支持（价格预测+存储成本约束）；
3. **现金流排布**：农资投入在前、收入在后，季节性资金断裂是规模扩张的头号杀手，缺乏现金流推演工具。

【待补充：走访 1-2 个真实经营主体/校内农业基地，把上述定性痛点替换为访谈实证——blueprint 人工项 man-interview】

### 1.2 为什么是现在（技术可行性）

- 时序预测近年突破（检索增强残差修正、在线适应、概率扩散预测）使"小数据+分布漂移"场景的可用预测成为可能——正是农产品行情的特点（KB-2：arxiv-2609.03937 / 02093 / 02068，2026-09-04 入库）；
- LLM 的叙事与知识整合能力 + 确定性量化内核的门控架构（KB-2：arxiv-2609.04159 等），让"可解释、不幻觉"的经营建议 agent 首次工程可行；
- 团队已有完整的"农场经营智能体"自研实战：在一个含种植规划、畜群经济、现金流调度、市场价格机制的仿真环境中，完成 20 轮生产迭代，通过线上对局数据画像校准策略（方法论资产，自 kaggriculture 项目经验迁移）。

## 2. 产品与技术方案

### 2.1 产品形态（原型 v1）

Web 看板 + 三层引擎，一键启动：

```
┌──────────────────────────────────────────────┐
│ 决策看板（建议卡片：种什么/养多少/何时卖+依据链）  │
├──────────────────────────────────────────────┤
│ 决策代理层：量化内核(优化器) + LLM 建议编排(门控) │
│   ├── RAG 知识库（农时/农技/补贴政策问答）        │
│   └── 计划一致性防护（防建议-执行漂移）           │
├──────────────────────────────────────────────┤
│ 预测引擎层：价格/产量/气象 多品类时序预测         │
│   └── 输出概率区间（非单点）+ 可解释归因          │
├──────────────────────────────────────────────┤
│ 经营仿真层：种养结构/现金流/市场行情离散事件仿真   │
│   └── 免泄漏在线评测协议（全链路验证规范）         │
└──────────────────────────────────────────────┘
```

### 2.2 关键技术选型（全部有 KB 卡片依据，禁凭印象）

| 模块 | 选型 | 依据卡片 | 差异化逻辑 |
|---|---|---|---|
| 经营仿真 | 自研离散事件仿真（团队战役方法论复用） | arxiv-2609.01126（评测协议） | 仿真先行：无需等真实数据接入即可验证决策全链路 |
| 时序预测 | 检索残差修正 + 在线频域提示 + 扩散概率区间 | arxiv-2609.03937 / 02093 / 02068 | 分布漂移鲁棒 + 区间输出：支撑"何时卖"而非展示预测 |
| 决策代理 | 量化内核优化器 + 门控 LLM 编排 | arxiv-2609.04159 / 03340 / 03383 / 03923 | LLM 只做叙事与编排、被确定性内核门控——可解释、可审计 |
| 知识库 | 轻量 RAG | _surveys/RAG族 | 农技/政策问答增强建议可信度 |

### 2.3 评测方案（先钉标准再开发）

- 预测：公开数据集（农产品批发价格/气象，采集后于战役 references/ 登记来源）回测，MAPE 与 90% 区间覆盖率对比 naive/季节性基线；协议采用免泄漏在线评测（01126），防"未来信息"渗入；
- 决策：仿真环境 A/B——决策代理 vs 经验规则基线，对比期末净资产与现金流断裂次数【待实测：metrics.json】；
- 可解释性：每条建议强制携带"依据链"（预测区间 + 知识引用 + 约束条件），人工评审通过率作为指标【待实测】。

## 3. 创新点（对应"项目创新"维度，权重 30）

1. **仿真前置的决策系统开发范式**：把"经营决策"变成可仿真、可评测、可迭代的闭环——借鉴金奖项目知耘的"数字孪生开发方法学"叙事（winners/2025-zhiyun-tongji 技术拆解节），但我们数字化的是**经营账本**而非农机作业；
2. **"区间+依据链"的可解释建议**：预测输出概率区间、建议输出依据链，正面回应评审对"AI 幻觉/黑箱"的质疑（架构层引用 SENTINEL-RL 的门控范式）；
3. **面向小数据与漂移的预测引擎**：农产品行情恰是"品类多、单品类数据少、分布随政策/气候漂移"——检索增强残差修正免重训适配，是通用大模型方案做不到的轻量部署（RTX 4070 笔记本可跑，边缘场景可迁移）。

## 4. 产业价值与商业模式（对应"产业价值"维度，权重 25；创意组=服务模式验证）

- 目标用户：家庭农场、种养大户、合作社（新型农业经营主体）；切入场景：季度种植结构决策 + 收获季卖出时机；
- 价值主张：决策失误成本的一小部分（一次跟风错种的市场损失远超软件年费）；
- 服务模式（创意组阶段）：原型免费 → 校内/本地农业基地试点 → 访谈迭代；商业化路径（创意组不做注册，仅作规划章节陈述）：SaaS 订阅 + 农技服务包 + 与农资/收购渠道的分发合作；
- 市场锚点：【待补充：目标区域农业经营主体数量与结构——需权威统计源，走访后回填；本稿不引未核实数字】。

## 7. 风险与合规

1. **时间窗**：报名截止 9-25 12 时，截止后成员/组别/名称不可改——W1 内完成组队是全计划关键路径；
2. **同质竞争**："AI+农业"是获奖热区（2024 金奖智绘农稷、2025 金奖知耘，均同济）——差异化钉死"决策大脑 vs 无人农机"，软件闭环、零硬件成本；
3. **资产复用合规**：团队既往项目经验可合法复用（自己的成果），但参赛项目在问题定义（真实经营决策 vs 博弈对局）、技术核心（预测+决策助手 vs 博弈 agent）、落地场景（真实经营主体 vs 竞赛天梯）三层均有实质差异，并显式排除"直接包装既往参赛作品"；
4. **资格红线**：创意组=通知发布前未工商注册+全员全日制在校（cy-innovation-2026 条目参赛条件节）；往年总决赛获奖项目不得报名；
5. **数据合规**：只使用公开数据集与获授权的访谈数据，来源全部登记。
