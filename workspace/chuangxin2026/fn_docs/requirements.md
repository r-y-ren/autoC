## 根本目的

STITP（大学生创新创业训练计划，原称科技创新训练计划）导师课题《无人机通信链路电磁干扰测试平台》的实施载体：实验室受控环境下把"无人机通信链路受干扰会坏到什么程度"做成可重复、可量化、一键出报告的测评台。成功五条：①一键闭环（注入→测量→报告）；②带真值标注数据集；③AI 分六样式+无干扰（如实报数）；④全部数字可溯源复现；⑤**模块化——设备后到=加插件而非重构**。

## 术语表

| 术语 | 精确定义 |
|---|---|
| 样式 | 干扰波形六类：单音(CW)/扫频/线性调频(chirp)/带限噪声/部分频带/脉冲（分类学=IEEE COMST 2022 综述） |
| 步进/失效电平 | GB 42590-2023 §5.11：干扰电平自被测链路发射功率 −5dB 起、5dB 一档至失效判据成立，记录该档 |
| 失效判据 | PER 持续 ≥10% 达 sustain_s，或断连 ≥disconnect_s（场景卡可调） |
| JSR（干信比） | 干扰与有用信号功率比（dB）；标称值=发射端标定表，实测值=监测通道估计 |
| 传导等效 | 屏蔽盒/受控环境内近场耦合测量（EN 300 328 注 4 认可口径） |
| DUT | 被测对象：一期=自建 ESP32 WiFi 链路 + NRF24 链路（均 2.4GHz） |
| 真值标注 | 每段 SigMF 录制自动携带的样式/功率档/时间窗标签（场景执行器写入） |
| 分组 CV | 按录制组（而非样本段）划分训练/测试（防段级泄漏，arXiv:2607.01025） |
| scenario | 单一输入入口的 YAML 场景卡：样式×频率×功率阶梯×判据×安全顶×记录开关 |
| 三元曲线 | 标准产出三图：PER-vs-JSR / 吞吐时延-vs-JSR / 失效事件时间线 |
| 插件（新） | 模块化硬约束的实现形态：**仪表后端 / 被测链路 / 干扰样式**三类插槽，新增=注册新实现，禁止改场景格式与执行器主体 |
| 合成数据模式 | 无硬件时以假链路流+可播录制的演示路径（UI 演示与开发冒烟共用） |

## 需求条目

### R1 六类干扰样式生成引擎 [P0]
- 内容：参数化生成六类样式（复基带 IQ→射频）；输入=场景注入段；输出=发射+样式元数据+SigMF 录制；错误=参数越界/设备失联→立即停发。样式集=插件注册表（新样式=注册新构建器）。
- 验收方式：`gen --scenario <冒烟卡> --dry-run` 输出波形参数表退出码 0；短时 `--run` 落 SigMF 且 annotations 含样式/功率/时间窗；目视核验瀑布图与样式定义一致（inspectrum，谁看/看什么/什么算对）。

### R2 功率标定与步进 [P0]
- 内容：软件增益细档×衰减器粗档的注入功率标定表；输出 calibration.json+单调性检查（相邻档偏差≤1dB 告警）；JSR 标称/实测双列记录。
- 验收方式：`calibrate` 产 calibration.json 并打印单调性检查结果；【待实测】首版偏差如实记录入报告。

### R3 被测双链路采集（真实+合成源） [P0]
- 内容：ESP32 WiFi（PER/重传/RSSI）与 NRF24（ARC_CNT/PLOS_CNT 丢包统计，无 RSSI）固件+上位机采集；串口 JSON 行 1Hz；合成源=同接口假链路（无硬件全链路可跑）。DUT=插件接口（新链路=新实现）。
- 验收方式：空跑 5 分钟两链路 PER=本底值且样本连续；拔一条链路另一条继续+gap 事件入日志；合成源与真实源同接口（接口测试双跑通过）。

### R4 三路统一采集与时间对齐 [P0]
- 内容：DUT-KPI∥监测谱∥注入事件汇流，统一主机单调钟时间戳（目标对齐≤50ms【待实测】）；产物=kpi.csv+events.jsonl+monitor.csv，时间轴覆盖率≥99%。
- 验收方式：`record --dur 60` 三路文件行数一致率≥99%；注入事件时刻±50ms 内 KPI 出现可见变化或明确无变化结论（写入报告）。

### R5 国标步进执行器 [P0]
- 内容：读场景→标定→−5dB 起 5dB 步进至失效判据→记失效电平→三元曲线+报告；断点续跑；无干扰对照不误报。执行器主体与仪表后端解耦（后端=插件）。
- 验收方式：`run --scenario gb42590 噪声卡` 产失效电平表+三元曲线≥3 张+report.md；对照卡跑完报告"未失效"。

### R6 SigMF 真值数据集 [P0]
- 内容：全部录制 SigMF v1.2.0 归档+自动真值标注；按录制分组产 dataset_index.json（分组 CV 的划分单位；对外可发布）。
- 验收方式：`dataset --check runs/` 全部录制校验通过且索引 group 字段非空。

### R7 AI 干扰样式识别 [P0]
- 内容：谱图分类（六样式+无干扰七类）；分组 CV 评测；训练经 /toolbox 远程算力（本地 CPU 降级）；混淆矩阵+Macro-F1 入报告——性能数字**只如实记录不设通过门**（内部参考目标 0.85，不阻塞）。
- 验收方式：`train --data <数据集>` 端到端产模型+分组 CV 报告；`predict --model --sigmf` 输出预测与真值并列。

### R8 一键演示与自动报告 [P0]
- 内容：一条命令（=UI 演示按钮同底层）串起短场景+小样本推理+报告；报告含场景/标定表/三元曲线/失效电平/识别样例+固定仪器局限声明；数字全部本 run 实测可溯源。
- 验收方式：`demo --quick` 一条命令退出码 0，report.md 生成且内嵌图有效；抽查任一数字可溯源到本 run 产物。

### R9 插件式扩展层 [P0]（模块化硬约束的落点）
- 内容：三类插槽——①仪表后端（干扰源/分析仪抽象；B210 首个实现，未来 SCPI 仪表=PyVISA 新实现同接口）②被测链路（真实/合成同接口）③干扰样式（注册表）；**新增任何一类设备/样式=注册新实现，场景格式与执行器主体零改动**。
- 验收方式：mock 后端跑通同一场景卡（证明执行器不感知具体仪表）；接口测试覆盖三类插槽的注册与替换。

### R10 Web 操控台 [P0]
- 内容：本地服务+浏览器单页：驾驶舱（样式选卡/功率滑杆/开始-暂停-**急停**——急停=立即停发射的安全键，设备失联也触发）+实时曲线仪表盘+场景卡片一键测+历史对比+报告在线查看导出；WS 实时推送；后端异常→全局告警+自动急停。
- 验收方式：`ui --selftest` 无头自检（服务起/健康检查/WS 心跳/急停生效）通过；人工判据=浏览器按演示剧本全程零命令行（谁看/看什么/什么算对：队员从开浏览器到出报告只用鼠标）。

### R11 SITL 链路退化注入预研 [P1]
- 内容：实测 PER-功率台阶→ArduPilot SITL 丢包/时延注入（姊妹项目《安航云盾》联动，单向输出）；产出联调脚本与记录。
- 验收方式：`sitl_bridge --profile <run>` 在 SITL 日志产生与注入台阶对应的链路质量变化（联调截图入 run 目录）。

### R12 2D 示意动画（非重点，不阻塞验收） [P1]
- 内容：链路光带变色/断裂、干扰波纹等 2D 动画随实测数据驱动；功能完整性优先，**有余力再做，验收不设动画硬项**。
- 验收方式：若实现——演示模式下动画状态与 KPI 数值联动一致（人工判据三要素）；未实现不影响 R10 验收。

## 非功能约束

| 约束 | 判据（Q7 确认） |
|---|---|
| 样式切换 | ≤2s（软件路径）【待实测】 |
| KPI 采集周期 | ≤1s/样本；失效事件时间分辨率≤50ms【待实测】 |
| 单国标场景时长 | 自动完成≤10min 量级 |
| 发射安全 | 增益硬顶 0dB（场景可调低不可调高）；仅屏蔽盒/受控环境；异常先停发 |
| **可扩展性（硬）** | 新仪表/新被测链路/新样式=插件注册接入；**禁止**改场景格式与执行器主体（"设备到齐=添加而非重构"） |
| 可复现 | 同场景+同标定表重跑，三元曲线趋势一致【待实测后入 metrics】 |
