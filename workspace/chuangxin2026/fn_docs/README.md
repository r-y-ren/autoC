# 无人机链路抗干扰测评台（STITP 课题一期）

> 面向队友的非技术说明。技术细节与全部出处见《前沿技术与实现方案补充》（../docs/前沿技术与实现方案补充.md）与 requirements.md。

## 这个东西是干什么的

我们自己搭两条小型无线链路（一块 ESP32 跑 WiFi、一块 NRF24 跑数传），当作"无人机的通信链路"的替身。然后用一台软件无线电设备（USRP B210）按设定好的方式朝它们发干扰，同时全程记录链路表现变差的过程。最后自动出一份报告：什么样的干扰、多强的干扰会让链路掉到什么程度。

一句话：给"无人机通信怕不怕干扰"这件事，做一台可重复、可量化、**鼠标点点就能操作**的测试机。

## 工作流程（从开机到报告，全程不碰命令行）

1. **准备**：把 ESP32 和 NRF24 用 USB 线接到主机；B210 接上 USB3；天线按固定位置摆进金属屏蔽盒。
2. **打开操控台**：双击启动图标（或一条启动命令），浏览器自动打开操控台页面——之后全程只用鼠标。
3. **选场景**：在"场景卡片"页点一张卡（比如"国标·噪声干扰"），或者自己拖滑杆调：干扰样式、起始功率、每档加多少、每档持续多久。
4. **开始测试**：点"开始"。页面上实时看到——无人机图形旁边两条链路光带从绿变黄变红、干扰波纹一圈圈扩散、下方仪表盘曲线实时往下掉。
5. **自动出报告**：跑完后在"报告中心"点开本次结果：三张曲线图、失效电平表、AI 识别结论，一键导出。历史结果可以两两对比。
6. **急停大按钮**：任何时候点红色急停，干扰立即停止（设备掉线也会自动急停）。

## 项目功能（一期承诺）

- **六种干扰样式**：单音、扫频、线性调频（chirp）、带限噪声、部分频带、脉冲——覆盖国标 GB 42590-2023 §5.11 要求的"噪声/单音/多音"及其扩展。
- **两条被测链路**：ESP32 WiFi 链路 + NRF24 数传链路，各带丢包/信号统计上报。
- **国标步进协议**：干扰功率从被测链路发射功率 -5dB 起步、每 5dB 一档加到链路失效，自动记录失效电平（国标测法）。
- **Web 操控台**：驾驶舱式操控（样式选卡/功率滑杆/开始-暂停-急停）+ 实时仪表盘 + 场景卡片一键测 + 报告中心；浏览器打开就用，演示零代码。
- **2D 示意动画**：无人机图形、链路光带变色断裂、干扰波纹扩散——全部跟着真实测量数据动，不是装饰动画；无硬件时可用"演示模式"播放合成数据。
- **全程留痕**：所有射频录制按 SigMF 开放格式存档，带完整标签，可复现、可对外发布。
- **AI 干扰识别**：谱图分类模型识别干扰样式，训练用 4070 笔记本远程算力。
