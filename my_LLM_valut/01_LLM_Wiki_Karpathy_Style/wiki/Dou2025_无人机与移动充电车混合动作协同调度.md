# Dou2025 无人机与移动充电车混合动作协同调度

## 单行摘要
论文面向单无人机持续观测与移动充电车协作场景，将“是否飞往下一个 PoI/是否去充电点”与“观察时长/充电时长”的离散-连续联合决策建模为混合动作强化学习问题，并提出 HaDMC 进行协同调度。

## 题目驱动研究框架
- 研究场景：无人机连续观测多个 PoI，移动充电车为其提供途中补能。
- 研究对象：执行观测任务的无人机、移动充电车、PoI、充电点和仓库。
- 核心问题：无人机与充电车都要做离散与连续耦合决策，传统 RL 很难直接处理异构主体的混合动作空间，如何学习高效协同调度策略。
- 标题承诺的方法：hybrid-action deep reinforcement learning。
- 期望效果：在保证无人机不中断工作的前提下，以尽可能短的总时间获得更高观测效用。
- 标题与正文的偏差：标题突出 scheduling，但正文真正的技术亮点是 latent action + action decoder + mutual learning 的混合动作表示学习。

## Algorithm Design 快照
论文针对无人机执行连续观测任务且依赖移动充电车补能的场景，研究如何同时决定无人机是否继续飞向下一个 PoI 或前往充电点、观察多久，以及充电车去哪个充电点并为无人机充电多久。该问题本质上由两个异构主体共同执行离散-连续混合动作，且动作间强依赖。为此，作者先把系统建模为多阶段决策过程，再提出 HaDMC：用潜在连续动作表示原始混合动作，通过 embedding table 与 AAE 组成的 action decoder 分别恢复离散与连续动作，并用 mutual learning 学习无人机与充电车动作之间的耦合，从而生成高效的 drone-charger schedule。

## 图1系统框架草案
- 系统实体：无人机、移动充电车、PoI、充电点、仓库。
- 任务/数据流：无人机按顺序访问 PoI 并观察；当电量不足时飞往某充电点与充电车会合；充电车同时规划自身移动和充电时间。
- 控制/优化变量：无人机离散动作、观察时长、充电车离散动作、充电时长。
- 约束来源：电池容量、飞行能耗、观察时间上下界、充电速率、充电点可达性。
- 画图提醒：图里应同时画“无人机闭环路线”和“充电车闭环路线”，否则双主体协同关系会被弱化。

## System Model
- 系统包含一架执行观测任务的无人机和一辆移动充电车，二者都从仓库出发并最终返回仓库。
- 无人机需要按预定顺序访问所有 PoI，每个 PoI 的观测时长存在最小和最大阈值，对应不同观测效用。
- 只有在指定充电点，无人机才能与移动充电车会合并补能，因此“飞去哪里”和“充多久”都影响全局计划质量。
- 论文把无人机与充电车的联合决策表示成异构 hybrid actions：无人机既要决定是否飞向下一个 PoI，也要决定观测时间；充电车既要决定去哪个充电点，也要决定充电时长。

## Algorithm Design 详解
- 第一步是构建多阶段决策模型：状态包括无人机、充电车、PoI 和充电点状态，目标最大化观测效用与总时间的比值。
- 第二步是定义混合动作空间：无人机动作和充电车动作都同时包含离散部分与连续部分。
- 第三步是设计 HaDMC：策略网络先输出潜在连续动作，再通过 action decoder 恢复原始 hybrid actions。
- 第四步是训练 action decoder：embedding table 将潜在向量映射为离散动作，AAE 将潜在向量映射为连续动作，并借 mutual learning 保留离散-连续、无人机-充电车之间的依赖关系。
- 第五步是训练 latent policy：在经验回放和噪声探索下优化整体策略，最终生成时间效率更高的 drone-charger schedule。

## Introduction 写作素材
- 无人机持续作业的瓶颈往往不是感知本身，而是补能和作业决策如何耦合。
- 当系统既包含“去哪儿”这样的离散选择，又包含“停多久”这样的连续控制时，传统单一动作空间方法容易失效。
- 如果充电主体本身也在移动，调度问题就从单主体路径规划升级为双主体协同规划。
- 这篇论文很适合支撑“持续作业无人机系统中的补能协同与混合动作决策”这一写作入口。

## Related Work 写作素材
- 与传统数据采集路径规划相比，本文把移动充电车显式纳入同一调度框架。
- 与纯离散或纯连续强化学习方法相比，本文聚焦异构主体的混合动作联合学习。
- 与只考虑静态充电站的工作相比，本文强调充电主体自身也需要移动决策。
