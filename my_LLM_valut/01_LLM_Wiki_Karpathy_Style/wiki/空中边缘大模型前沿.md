# 空中边缘大模型前沿

## 当前前沿
当前语料显示，空中边缘大模型前沿已经从最早的“边云模型协同”扩展成四条并行分支：[[Zhang2025_空中边缘大模型的边云协同演化]] 代表系统级模型演化，[[Chen2025_TypeFly低时延大模型无人机规划]] 代表低时延具身规划，[[Zhou2025_LLM增强Q学习的多并行无人机调度]] 代表 LLM 作为优化辅助器，而 [[Sun2024_ASAP无人机群全空域自主协同计算]] 则提供了空中协同 AI 执行底座。

## 四条主线
### 1. 系统级边云模型协同
- 重点是边缘小模型与云端大模型如何分工。
- 通信对象从任务数据扩展到特征、残差数据与模型更新。
- 代表页面：[[边云模型协同]]、[[Zhang2025_空中边缘大模型的边云协同演化]]。

### 2. 低时延具身规划
- 重点是自然语言任务如何快速转成无人机动作或技能调用。
- 关键指标从完成时间扩展到首动作时延、重规划速度与执行可靠性。
- 代表页面：[[大语言模型驱动无人机规划]]、[[Chen2025_TypeFly低时延大模型无人机规划]]。

### 3. LLM 作为优化辅助器
- 重点不再是让 LLM 直接控制无人机，而是让它生成启发式或结构化中间变量，辅助经典优化与强化学习。
- 这条分支更适合调度、路径规划和组合优化问题。
- 代表页面：[[LLM增强Q学习]]、[[Zhou2025_LLM增强Q学习的多并行无人机调度]]。

### 4. 空中协同 AI 执行底座
- 大模型能力要真正落地，还需要群体空中计算平台支撑推理执行与重调度。
- 这使“前沿 AI”不再只是模型问题，也变成系统平台问题。
- 代表页面：[[空中自主协同计算]]、[[Sun2024_ASAP无人机群全空域自主协同计算]]。

## 对现有研究主线的冲击
- [[任务卸载]]将不再只关心 CPU、带宽和功率，而要同时考虑模型更新、启发式调用与推理链条。
- [[资源分配]]会从“分资源”扩展为“分任务 + 分模型 + 分数据流”。
- [[空中计算]]会进一步从网络系统问题演化成 AI 系统问题。
- [[多无人机协同]]会越来越需要兼顾具身执行、推理协作和调度辅助。
