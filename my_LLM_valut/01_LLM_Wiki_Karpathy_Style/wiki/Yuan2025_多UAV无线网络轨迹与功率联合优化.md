# Yuan2025 多 UAV 无线网络轨迹与功率联合优化

## 单行摘要
论文提出通信增强的多智能体强化学习算法 CATEN，通过信息共享机制与多头注意力 critic 联合优化多 UAV-ABS 的轨迹和功率分配。

## 题目驱动研究框架
- 研究场景：多个 UAV 作为空中基站为地面用户提供通信覆盖服务。
- 研究对象：多 UAV-ABS、地面用户、协同通信控制策略。
- 核心问题：在动态环境中，多个 UAV 如何在局部信息不足的情况下协同决定轨迹和发射功率，以兼顾 QoS 覆盖和能耗。
- 标题承诺的方法：communication-based multi-agent deep reinforcement learning。
- 期望效果：提高满足 QoS 约束的用户数量，同时降低 UAV 系统能耗。
- 标题与正文的偏差：标题强调“轨迹 + 功率 + 通信型 MARL”，正文真正的重点还包括经验检索更新机制和多头注意力 critic，它们决定了通信不是附属条件，而是算法本体的一部分。

## Algorithm Design 快照
论文面向多 UAV 作为空中基站协同服务地面用户的通信场景，研究轨迹规划与功率分配的联合控制问题。其难点在于多智能体之间存在强耦合，单个 UAV 很难仅凭局部观测做出高质量决策，同时系统又必须在提高 QoS 覆盖和降低能耗之间平衡。为此，论文提出 CATEN 框架，在 CTDE 范式下把轨迹和功率作为联合动作输出，并设计通信学习机制来筛选和更新跨 UAV 经验，再用多头注意力 critic 捕捉不同协同特征。最终目标是在动态环境中提升多 UAV 的协同行为质量与鲁棒性。

## 图1系统框架草案
- 系统实体：多个 UAV-ABS、多个地面用户、空中协同控制器。
- 任务/数据流：每个 UAV 根据局部观测和跨 UAV 共享信息决定下一时隙位置与功率，地面用户接收空中通信服务。
- 控制/优化变量：各 UAV 轨迹、发射功率、跨智能体通信内容与注意力权重。
- 约束来源：飞行能量、时间槽长度、用户 QoS 约束、总带宽/功率限制、环境动态性。
- 画图提醒：画图时应把“信息共享模块”单独画出来，否则这篇论文会被误读成普通的 MADRL 轨迹优化工作。

## System Model
- 系统包含 N 个 UAV-ABS 和 M 个地面用户，在连续时隙内完成一轮协同服务 episode。
- 论文分别建模了 UAV 的移动过程、通信链路和能量消耗，因此轨迹与功率是天然耦合的双重控制变量。
- 目标函数不是单一吞吐最大化，而是“尽可能多的用户满足 QoS”与“尽可能低的 UAV 能量消耗”之间的多目标平衡。
- 与单智能体建模不同，这里环境状态包含跨 UAV 依赖，因此系统本质上是一个强耦合的多智能体协同控制问题。

## Algorithm Design 详解
- 第一步是 Markov game 建模：把每个 UAV 看成智能体，在 CTDE 范式下学习联合策略。
- 第二步是通信机制设计：CATEN 通过 encoder-retrieve-update 流程组织跨 UAV 经验共享，过滤冗余信息并强化有效协同信号。
- 第三步是多头注意力 critic：critic 网络使用多头注意力分别聚焦不同维度的协作特征，从而更好地评估联合动作质量。
- 第四步是联合输出动作：actor 同时给出轨迹与功率策略，使“移动到哪里”和“以多大功率服务谁”成为同一决策回路的一部分。

## Introduction 写作素材
- 当地面基站无法充分覆盖或环境高度动态时，UAV-ABS 是提升通信弹性的自然选择。
- 真正困难的不只是给单 UAV 找最优轨迹，而是让多个 UAV 在不完全信息条件下形成有效协同。
- 如果没有合适的信息共享机制，多智能体 RL 很容易陷入局部决策、冗余通信和能耗过高的问题。
- 这篇论文非常适合支撑“为什么多 UAV 通信场景必须把通信机制内生化到算法里”的论证。

## Related Work 写作素材
- 与传统解析优化方法相比，本文更关注高动态场景中的在线协同行为生成。
- 与普通 MADRL 方法相比，本文不是简单共享状态，而是显式设计了经验检索与注意力筛选机制。
- 与单目标通信覆盖工作相比，本文同时处理 QoS 满足数量和系统能耗，因此更接近工程部署目标。
