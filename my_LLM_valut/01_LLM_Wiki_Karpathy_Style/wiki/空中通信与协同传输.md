## 研究判断
- UAV 已经从“空中中继”扩展为接入机制、传播环境、内容共享规则和语义通信流程的共同参与者。
- Batch_02 的关键增量有三个：[[边缘缓存]] 和 [[信息中心网络（ICN）]] 让通信主线开始吸收内容中心路由；[[多模态语义通信]] 把“传比特”推进到“传任务相关语义”；[[蜂窝连接无人机通信]] 则在动态目标跟踪场景中继续强化在线能量与干扰控制。
- Batch_04 进一步补了一条很现实的链：在基础设施稀缺、山地遮挡严重的搜索救援里，通信链路质量和轨迹适应能力会被一起重写，这让 LoRa 弱基础设施通信正式进入主网络。
- Batch_05 的关键增量有四个：对称性先验开始进入大规模通信覆盖控制、个性化联邦学习被用于抗干扰策略共享、图强化学习推进多用户安全通信、协同安全中继与低空经济灾后通信把群体协同网络重新拉回主线。
- Batch_06 则把这条主线继续向下扎深：[[Gossip广播协议]] 说明协议级决策已经进入学习优化视野，[[虚拟网络功能（VNF）]] 让 UAV 网络从“会连”走向“会算”，[[数字孪生元宇宙]] 与 [[语义通信激励机制]] 则把语义同步和价值分配带进了空中通信系统。
- Batch_07 则把“安全治理型通信”正式补齐：从 [[友好干扰]] 到 [[安全波束赋形]]，从 [[跨域认证]] 到链上带宽交易与 [[安全量子联邦学习]]，再到 [[虚假数据注入攻击（FDI）]] 防护和 [[加固数字孪生]] 物流分发，通信主线开始同时承担保密、认证、激励、韧性和控制安全五种角色。
- Batch_08 则把这条主线继续向“传播控制 + 内容组织 + 光学安全”三端扩展：[[移动用户跟踪]] 与 `SAGIN-ISAC` 绑定，[[主机-内容中心融合路由（IHCR）]] 和 [[内容缓存]] 让空中网络真正吸收内容中心范式，[[UAV-RIS协同通信]]、[[波束预测]] 与 [[UAV-NOMA覆盖]] 把传播控制写得更细，而 [[光学可重构智能表面（ORIS）]] 与 [[量子密钥分发（QKD）]] 则把安全链路推进到了光学与量子层。
- Batch_09 进一步把这条主线推向“服务连续性 + 运动可信性”：[[Li2025_DroneMA基于移动性对齐的无人机AI欺骗检测]] 说明通信身份鉴别开始利用运动一致性，[[Zhou2024_UAV移动性与可靠性保障空地通信联合优化]] 把可靠性约束与运动控制写成统一问题，[[Rizvi2025_面向韧性运行的无人机间服务干扰监测]] 则让服务级干扰监测进入空中网络运行层。
- Batch_10 则把这条主线继续拉向“真实空地物理链路与供能基础设施”：[[Panahi2024_激光与可再生能源协同供能的UAV通信成本优化]] 让能量采购成本进入通信系统，[[Ren2025_AeroEcho面向农业物联网的空中激励回散通信]] 把 UAV 变成移动激励基础设施，[[Zhang2025_基于定向性感知链路模型的UAV-LoRa高效数据采集]] 则通过实地测量直接重写了 LoRa 空地链路模型。

- Batch_12 让这条主线继续向“传播控制 + 内容组织 + 供能链路 + 边缘协同”扩展：协作波束形成、编码缓存、WPT/WPCN、RIS-MCS 以及 THz-IRS 卸载开始在同一批语料中出现。

- 这意味着空中通信研究不再只围绕频谱效率，而是在同时吸收网络级接入组织、感知精度、语义有效性、供能现实和在线控制能力。
