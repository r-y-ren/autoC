# Sun2025_面向地面移动用户的空中可靠协同通信

## 单行摘要
论文面向移动地面用户的空中协同通信，利用 AAV swarm 形成虚拟天线阵列并引入记忆型随机游走用户模型，再用 `EMOPPO-VLH` 在总速率与飞行能耗之间学习 Pareto 策略集。

## 题目驱动研究框架
- 研究场景：干扰存在、用户移动且链路时变的空地协同通信网络。
- 研究对象：多个 AAV、非关联 BS、单个移动地面用户。
- 核心问题：协作波束形成虽然能扩展链路距离，但 AAV 移动与激励权重会带来显著额外能耗。
- 标题承诺的方法：aerial reliable collaborative communications via evolutionary MORL。
- 期望效果：在不同用户偏好下给出一组可选的可靠通信策略，而不是单点权衡解。

## Algorithm Design 快照
作者先让多个 AAV 构成 UVAA 虚拟阵列，通过协作波束形成增强远距离通信能力；再将移动用户轨迹用带记忆的 Gaussian-Markov 模型写入环境，使问题从静态波束控制变成长期多目标决策。为应对高维连续动作与动态环境，论文提出 `EMOPPO-VLH`，把向量值函数、LSTM 和记忆型任务选择机制组合起来，输出多组非支配策略。

## 图1系统框架草案
- 实体：AAV swarm、移动用户、非关联 BS 干扰源。
- 决策：AAV 水平/垂直机动、阵列激励权重。
- 目标：最大总可达速率、最小飞行能耗。
- 画图提醒：把“移动用户 + 干扰 BS + 虚拟阵列”三者同时画出，能体现问题张力。

## System Model
- 多个 AAV 在 3D 空间形成虚拟阵列，并通过阵列增益向移动用户发射信号。
- 系统显式考虑非关联 BS 干扰和时变信道，因此可靠通信不是纯 LoS 传播问题。
- 用户移动模型采用带记忆的随机游走，更接近真实移动终端。
- 决策变量既包括 AAV 位移，也包括阵列激励电流权重，因此波束与路径完全耦合。

## Algorithm Design 详解
- 第一步：建立 CB-enabled AAV reliable communications system，并给出长期双目标优化问题。
- 第二步：把问题重写成 multi-objective MDP。
- 第三步：提出 `EMOPPO-VLH`，在 PPO 基础上扩展向量值函数与多任务搜索。
- 第四步：加入 LSTM 捕捉用户移动与时变信道的时间依赖。
- 第五步：通过 hyper-sphere task selection 提高 Pareto 集覆盖度。

## Introduction 写作素材
- 当 UAV 不再服务静态终端，而是面对持续移动用户时，协作波束形成就会转化成长期控制问题。
- 这类问题天然存在“通信可靠性 vs 飞行能耗”的冲突，因此适合用 Pareto 策略集而非单一最优解。

## Related Work 写作素材

- 与单目标 DRL 不同，本文保留了多目标非支配策略集。
