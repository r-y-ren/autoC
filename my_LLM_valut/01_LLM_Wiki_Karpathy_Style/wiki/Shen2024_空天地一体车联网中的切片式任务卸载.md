# Shen2024 空天地一体车联网中的切片式任务卸载

## 单行摘要
论文面向空天地一体车联网，提出“切片窗口自适应 + 资源切片 + DDQN 调度”的闭环任务卸载框架，以提升长期任务完成数并兼顾控制开销。

## 题目驱动研究框架
- 研究场景：SAGIN 车联网中的异构基站协同卸载。
- 研究对象：卫星、地面基站、无人机基站、车辆任务流、MEC 控制器。
- 核心问题：如何在高动态业务负载下，为时延敏感和时延容忍任务同时提供差异化 QoS。
- 标题承诺的方法：slicing-based task offloading。
- 期望效果：提升任务完成率并降低任务失败率与切片控制开销。
- 标题与正文的偏差：正文不只是在“切片上做卸载”，而是把切片窗口划分、资源切片和小时间尺度调度写成一个闭环控制框架。

## Algorithm Design 快照
论文研究空天地一体车联网中的异构基站协同任务卸载问题，目标是在车流波动与任务类型差异并存的情况下，为时延敏感和时延容忍业务提供稳定服务。难点在于切片窗口长度、无线与计算资源切分以及窗口内任务调度彼此耦合，且任务流随交通状态不断变化。为此，作者提出服务导向的 RAN 切片框架：在大时间尺度上先自适应调整切片窗口并做资源切片，在小时间尺度上由 DDQN 完成任务调度，从而最大化长期任务完成数并平衡 QoS 与控制信令开销。

## 图1系统框架草案
- 系统实体：卫星、地面 BS、无人机 BS、车辆、MEC 控制器。
- 任务/数据流：车辆产生不同 QoS 需求任务，控制器周期性划分切片窗口并切分通信/计算资源，窗口内部执行任务调度。
- 控制/优化变量：切片窗口长度、各切片资源份额、窗口内任务调度策略。
- 约束来源：任务截止期、异构基站覆盖与能力、业务波动、控制信令开销。
- 画图提醒：图中要突出“窗口到来时重新配置资源，窗口内部 DDQN 调度”的双层闭环。

## System Model
- 系统由卫星、地面基站和无人机基站共同组成异构接入层，服务高速车辆任务。
- 任务被分为时延敏感与时延容忍两类，并通过队列模型刻画其到达与完成过程。
- 切片框架同时调节无线频谱和计算资源，使不同业务切片获得差异化保障。
- 切片窗口作为系统控制周期，是连接长期负载波动与短期调度决策的关键建模对象。

## Algorithm Design 详解
- 大时间尺度：根据任务流波动自适应确定切片窗口长度，避免固定周期控制在高峰期失灵。
- 中间层：在每个切片窗口开始时，由控制器完成资源切片，把异构基站能力在不同业务间重新分配。
- 小时间尺度：窗口内部使用 DDQN 完成任务调度，学习不同任务和链路状态下的动作选择。
- 方法价值：本文把[[网络切片]]正式接入 UAV/SAGIN 卸载主线，使“服务隔离与控制开销”成为卸载研究的一部分，而不是独立运维问题。

## Introduction 写作素材
- 在车联网里，仅靠静态资源分配难以应对交通高峰、任务异质性和 UAV 覆盖变化。
- 网络切片不应只被当成网络运维工具，它会直接决定任务卸载的完成率和服务时延。
- 这篇论文适合用于说明“UAV 卸载系统正在从单任务最优转向服务级别组织”。

## Related Work 写作素材
- 与传统 SAGIN 卸载工作相比，本文把切片窗口自适应作为显式决策变量。
- 与只做资源切片的工作相比，本文进一步把 DDQN 调度放入切片内部形成闭环。
- 与仅靠静态切片策略的基线相比，本文强调在工作负载波动下动态平衡 QoS 与信令开销。
