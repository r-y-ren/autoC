# Xu2025_信任增强的安全量子联邦学习激励

## 单行摘要
论文面向 UAV 辅助无线网络中的量子联邦学习，联合设计贝叶斯信任评估与 `Stackelberg + DQN` 激励机制，以抑制恶意和自私 QECD 对模型精度与收敛速度的破坏。

## 题目驱动研究框架
- 研究场景：UAV-assisted wireless networks 中的 QFL。
- 研究对象：UAV、量子边缘计算设备 `QECDs`、本地模型与全局模型。
- 核心问题：恶意或自私 QECD 会提供低质量更新，并削弱训练积极性与收敛效率。
- 标题承诺的方法：trust-enhanced game incentive。
- 期望效果：提升 QFL 的模型精度、训练速度和参与合作度。

## Algorithm Design 快照
这篇论文把 QFL 中的“安全”和“参与意愿”分开处理。第一层是贝叶斯信任评估，用历史行为和互评信息筛掉低可信 QECD；第二层是 Stackelberg 激励，让 UAV 用 `DQN` 学出动态支付策略，诱导剩余高质量节点提供更高训练贡献。

## 图1系统框架草案
- 训练层：QECD 基于私有数据做本地量子模型训练。
- 聚合层：UAV 汇聚局部模型更新全局模型。
- 信任层：贝叶斯推断同时结合直接评价与互相推荐信息。
- 激励层：UAV 通过 DQN 学习支付策略，QECD 决定贡献强度。
- 目标层：提高模型精度与收敛速度。

## System Model
### 1. QFL 协同训练模型
- QECD 依靠量子计算能力完成本地训练。
- UAV 收集局部模型参数并完成全局聚合。

### 2. 安全威胁模型
- 恶意 QECD 可能上传虚假更新或低质量更新。
- 自私 QECD 因资源消耗顾虑而降低参与积极性。

### 3. 决策变量
- UAV 支付策略。
- QECD 训练贡献度。
- 信任阈值与可信参与集合。

## Algorithm Design 详解
### 1. 贝叶斯信任评估
- 结合直接评价和互评推荐动态更新 QECD 信任值。
- 通过信任阈值过滤低质量参与方。

### 2. Stackelberg 激励机制
- UAV 作为领导者设定奖励。
- QECD 根据奖励和代价决定训练贡献度。
- 用 backward induction 证明 Stackelberg equilibrium 存在。

### 3. DQN 动态支付学习
- 在动态网络中，UAV 无需事先掌握 QECD 参数。
- 使用 `DQN` 通过经验回放学习最优支付决策。

## 实验证据卡片
- 验证类型：`simulation`
- 数据来源：合成 QFL 训练与通信场景
- 平台与软件：`MATLAB`、`MATLAB support package for quantum computing`
- 方法组件：`Bayesian trust assessment`、`DQN`、`Stackelberg game`
- 场景设置：`2` 架 UAV，QECD 分布在每架 UAV `300 m` 半径内，UAV 高度 `200 m`
- 评测指标：信任演化、UAV/QECD 效用、QFL 精度、DQN 收敛性
- 对比对象：无信任激励、随机支付、固定支付
- 开源情况：未说明
- 复现判断：`medium`
- 缺失信息：未公开代码、量子仿真脚本和数据任务定义

## Introduction 写作素材
- QFL 把量子边缘算力引入 UAV 网络，但也同时把“恶意更新 + 资源自私”问题放大了。
- 单独做信任评估或单独做支付激励都不足以保证高质量训练。
- 这篇论文适合支撑“可信协同学习需要安全筛选和动态激励双机制”的引言逻辑。

## Related Work 写作素材
- 现有 FL/UAV 研究更常关注资源优化与通信效率。
- 现有 QFL 研究多关注量子加速和隐私，却较少把设备可信度与激励机制联动考虑。
- 本文把信任建模、博弈激励和深度强化学习整合起来，适合作为安全协同学习分支的重要入口。
