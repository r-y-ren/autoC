# Kang2024 基于深度强化学习的自主多无人机竞速

## 单行摘要
论文通过局部感知、多目标奖励塑形和 sim-to-real 训练，把多无人机竞速从仿真迁移到真实户外竞速场景。

## 题目驱动研究框架
- 研究场景：复杂赛道中的高速多无人机竞速。
- 研究对象：竞速无人机、局部传感器观测、奖励塑形、真实物理飞行平台。
- 核心问题：在缺乏全局赛道信息时，如何让多架无人机学会高速、敏捷且安全的竞速策略。
- 标题承诺的方法：autonomous multi-drone racing based on deep reinforcement learning。
- 期望效果：实现低计算时延、强适应性且可迁移到真实环境的竞速控制。
- 标题与正文的偏差：正文最重要的增量是“局部观测 + sim-to-real + 真实竞速验证”的完整闭环。

## Algorithm Design 快照
论文针对自主多无人机竞速中“需要快速飞行、存在强交互、又难以依赖全局赛道信息”的问题，设计了一组面向竞速技能的奖励函数，包括穿门、超车、安全间距、越界惩罚等，并使用基于 PPO 的独立策略学习框架训练竞速策略。训练过程中，作者在仿真环境中加入竞速无人机的动态响应特性、并行采样和随机初始化机制，同时通过 sim-to-real 设计把策略迁移到真实户外平台。最终方法在仿真对抗和真实户外竞速中都优于依赖全局轨道信息的基线方法。

## 图1系统框架草案
- 系统实体：多架竞速无人机、局部传感器、虚拟/真实赛道门、地面终端。
- 任务/数据流：无人机根据局部观测生成控制动作，在赛道中完成穿门、超车和避碰。
- 控制/优化变量：姿态控制、速度调节、局部路径选择、奖励权重。
- 约束来源：无人机动力学、最小安全距离、赛道边界、实时控制时延。
- 画图提醒：图里建议并列显示“仿真训练平台、物理模拟器、真实竞速平台”三层迁移链条。

## System Model
- 系统不依赖全局赛道和全局边界信息，只使用无人机本地可见的赛道局部特征。
- 训练环境中显式加入竞速无人机的动态响应特性，使策略更接近真实控制对象。
- 奖励函数同时编码速度、超车、安全和边界遵守等多个竞速技能目标。
- sim-to-real 迁移通过物理模拟器和真实硬件平台进行中间校验。

## Algorithm Design 详解
- 第一步构建多无人机竞速马尔可夫博弈与局部观测状态空间。
- 第二步设计安全、超车、穿门和边界惩罚等奖励函数，实现技能引导。
- 第三步采用 IPPO 结合并行采样和随机初始化训练竞速策略。
- 第四步使用 sim-to-real 机制和真实平台做户外竞速验证。

## Introduction 写作素材
- 高速多无人机控制是比常规巡航更极端的实时决策场景，能放大局部感知和控制延迟问题。
- 真正可部署的多机策略不能依赖完整赛道地图和全局边界信息。
- 这篇论文适合支撑“控制策略必须从仿真性能走向真实迁移能力”的写作论点。
