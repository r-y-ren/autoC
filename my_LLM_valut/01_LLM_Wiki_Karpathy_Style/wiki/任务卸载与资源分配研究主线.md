# 任务卸载与资源分配研究主线

## 主线概览
当前语料中的卸载研究已经从“局部过载缓解”扩展为“分层空中平台、服务组织、供能耦合、动态连续性、安全可靠性与机制设计共同驱动的系统工程问题”。

## 八段演化
### 1. 弹性补充算力阶段
- [[Dai2024_车联网中的UAV辅助任务卸载]] 将 UAV 作为 RSU 的弹性外部算力。
- 这一阶段的典型问题是“谁来接住地面热点过载”。

### 2. 多UAV协同与时延保障阶段
- [[Huang2024_多UAV车载边缘计算动态任务卸载]] 把统计时延和队列保障引入多 UAV 卸载。
- [[Bai2024_多UAV边云协同时延感知任务卸载]] 把边缘集群与远端云协同纳入统一卸载框架。
- 这一阶段的典型问题是“如何在多节点协同下维持 SLA 与低时延”。

### 3. 服务组织与切片阶段
- [[Shen2024_空天地一体车联网中的切片式任务卸载]] 把切片窗口、资源切片和任务调度并入同一闭环控制。
- [[Wei2024_带部署优化的UAV辅助无线网络分层切片]] 把切片组织继续推进到资源切分与 UAV 部署协同的双时间尺度优化。
- [[Li2025_灾后医疗救援的UAV辅助微服务MEC架构]] 则从微服务视角重写灾后医疗救援中的服务组织和空中边缘能力编排。
- [[Ning2024_差异化服务的多UAV轨迹优化]] 进一步把服务等级、服务提供商和轨迹-卸载控制绑定起来。
- [[Cong2024_ParallEdge计算移动并行的5G6G边缘计算]] 改变了传统“先移动后计算”的服务时序。
- [[Wu2024_面向计算流最大化的多UAV网络设计]] 则把 [[虚拟网络功能（VNF）]] 放置、空中骨干组网和流路由统一起来。
- [[Zhao2025_UAV-MEC中的内容缓存服务放置与任务卸载联合优化]] 则进一步把内容请求、服务请求和任务卸载放到同一 `QoE` 目标下。
- 这一阶段的典型问题是“系统能力如何被组织成可服务、可重配置的结构”。

### 4. 体验导向、多目标与供能耦合阶段
- [[Gao2024_面向服务体验的缓存使能UAV辅助MEC协同计算]] 用 [[服务体验比（SER）]] 引入体验导向指标。
- [[He2024_UAV辅助MEC服务质量体验最大化的在线联合优化]] 用 Lyapunov 在线框架把 [[服务质量体验（QoE）]] 拉入联合优化目标。
- [[Sun2024_多UAV辅助MEC多目标优化]] 把时延、能耗和卸载任务总数统一到多目标优化框架中。
- [[Wang2024_无线供能元宇宙中的多设备多UAV联合调度]] 则把补能过程、设备调度和多 UAV 轨迹显式耦合起来。
- [[Song2024_空地协同MEC中的AoI与能耗权衡学习]] 则说明在 HAP-UAV 协同 MEC 中，AoI 与能耗应被看作可切换偏好的 Pareto 目标，而非固定权重和。
- [[Song2024_基于多目标强化学习的无线充电UAV辅助MEC轨迹优化]] 进一步把 HAP 激光补能与多目标轨迹控制接进 UAV-assisted MEC。
- 这一阶段的典型问题是“系统最优是否真正对应用户体验、能量可持续性和任务完成规模”。

### 5. 联合控制与双时间尺度阶段
- [[Chen2025_Lyapunov辅助DRL的轨迹与资源联合优化]] 把轨迹、通信和计算资源纳入统一控制。
- [[Sun2024_TJCCT双时间尺度UAV辅助MEC联合优化]] 显式区分快慢时间尺度。
- [[Sun2025_JC5A空中MEC辅助工业CPS服务时延最小化]] 在 [[工业网络物理系统（ICPS）]] 中把服务缓存、通信计算资源和轨迹控制统一到 `JC5A` 框架。
- [[Wang2025_PPO驱动的多UAV_MEC联合定位与计算卸载]] 把 UAV 定位与卸载放到同一决策中。
- [[Yang2024_巡检系统中蜂窝连接UAV-MEC的能效传输策略]] 则把巡检访问顺序、段间传输和 MEC 资源组织写成业务驱动的联合控制问题。
- [[Wang2024_双目标蚁群优化的UAV辅助MEC轨迹与卸载规划]] 则把多 UAV 访问路径与 multi-stage task offloading 直接耦合起来。
- [[Wang2024_USV辅助MEC中的UAV目标跟踪与计算卸载]] 进一步把目标跟踪、USV 协同和边缘卸载放进同一跨域系统。
- 这一阶段的典型问题是“跨层变量如何在不同时间尺度和不同平台之间协同更新”。

### 6. 分层空中平台与跨域扩展阶段
- [[Qin2022_物联网空中计算中的多智能体卸载]] 以 UE-LEO-Cloud 三层 SMEC 架构把 DAG 任务依赖写进空中计算卸载。
- [[Jia2025_UAV与HAP协同空中MEC的分布鲁棒优化]] 把 HAP 引入空中 MEC 并用 DRO 处理 CSI 误差。
- [[Nabi2025_UAV与HAP协同层次化空中计算联合卸载]] 把 GU-UAV-HAP 三层协同写成层次化空中计算平台。
- [[Chen2025_空天地一体LEO卫星边缘计算多用户卸载]]、[[Tun2025_THz辅助空天地一体网络中的UAV部署与资源分配]] 与 [[Zhang2025_量子辅助SATIN在线任务卸载与资源分配]] 则把卸载主线继续推向 [[空天地一体网络（SAGIN）]] 和星空地跨域调度。
- 这一阶段的典型问题是“谁负责灵活接入，谁负责稳定算力与回传，以及跨域网络如何在线求解”。

### 7. 机制设计、联邦协作与动态连续性阶段
- [[Chen2025_博弈论驱动的UAV辅助边缘计算卸载与资源定价]]、[[Wang2024_区块链集成UAV_MEC的资源定价与分配]] 把定价与激励显式带入系统。
- [[Singh2024_基于稳定匹配的UAV辅助WBAN联邦学习收益最大化]] 把联邦学习数据收集、PRB 分配与收益分成统一建模。
- [[Wang2025_动态UAV_MEC网络中的任务卸载与迁移优化]] 进一步把 [[任务迁移]] 写成独立决策层。
- [[Zhou2025_用户偏好导向的UAV辅助MEC服务缓存与任务卸载]] 则把用户偏好、服务缓存与任务卸载耦合起来，说明连续服务已经开始由需求侧分布塑形。
- [[Zhao2025_轨迹卸载缓存与迁移联合优化的UAV辅助MEC]] 则把 [[任务缓存]] 与迁移一起纳入 Lyapunov 在线框架。
- [[Zhao2025_动态环境中的多UAV协同任务调度]] 说明当任务依赖、用户移动和 UAV 协同部署同时变化时，调度本身会重新成为主问题。
- 这一阶段的典型问题是“服务如何在动态用户、动态价格、动态信道和动态收益关系下持续运行”。

### 8. 安全、可靠性与大规模扩展阶段
- [[Li2024_智能窃听对抗下的UAV辅助MEC安全卸载与资源分配]] 把智能窃听者写入对抗式卸载框架。
- [[Shao2024_抗干扰UAV辅助MEC资源管理]] 说明 jammer、信道选择和 CPU-带宽协同已经进入主问题内部。
- [[Zhang2024_动态用户多UAV_MEC安全通信中的卸载与轨迹优化]] 说明物理层安全已经进入联合卸载主问题。
- [[Zhao2025_移动合谋窃听下的UAV辅助MEC安全传输与计算]] 进一步把移动合谋窃听、干扰波束和实时计算调度一起拉进安全卸载框架。
- [[Zhou2025_可靠性最优的UAV辅助移动边缘计算]] 把随机 LoS/NLoS 转移与任务可靠性写成系统级目标。
- [[Gao2025_面向大规模部分可观测UAV辅助MEC的迁移学习联合轨迹卸载]]、[[Li2025_Anchor协同UAV-MEC的动态CoMP卸载建模]] 与 [[Wang2024_异构联邦强化学习的UAV_MEC分布式导航]] 则继续推进大规模、协同和异构扩展。
- 这一阶段的典型问题是“系统在不确定、对抗和大规模条件下是否还能保持可服务”。

### 9. THz-IRS 卸载与无线供能动态通信补充
- [[Wu2025_IOPO面向THz多UAV-MEC的IRS辅助卸载优化]] 在 THz 多 UAV MEC 中用两阶段深度学习联合优化卸载矩阵与 IRS 相位。
- [[Zhao2024_多UAV辅助无线供能动态通信的分层强化学习设计]] 用双阈值节点类型更新和双层 MAHDRL 统一处理 WET/WDC 动态通信。
- 这一补充阶段的典型问题是“当 IRS、THz 传播和无线供能节点状态一起进入系统后，卸载和调度如何保持可计算、可训练和可部署”。

## 当前判断
- 卸载主线已经不再等于“选择哪台服务器”，而是扩展为“如何组织服务、维持连续性并管理多层能力”。
- Batch_02 带来的最关键增量有四个：[[无线供能移动边缘计算]] 进入联合调度、[[稳定匹配]] 被用于联邦学习收益组织、[[量子辅助优化]] 开始进入 SATIN 在线求解、[[可靠性感知卸载]] 进一步从成功率视角重写目标函数。
- Batch_03 的关键增量有三个：[[任务缓存]] 正式进入 UAV-MEC 主问题、[[THz辅助空天地一体网络]] 把部署与跨域资源联动起来、HAP 的角色扩展到补能支撑层。
- Batch_04 的关键增量有三个：多阶段路径-卸载耦合开始独立成形、异构联邦强化学习把导航与知识共享接进 UAV-MEC、USV 参与让空海协同目标跟踪成为新的卸载场景。
- Batch_05 的关键增量有三个：[[差异化服务]] 让服务组织开始直接塑形卸载策略、[[Qin2022_物联网空中计算中的多智能体卸载]] 把 LEO-SMEC 与 DAG 依赖接入主线、[[Shao2024_抗干扰UAV辅助MEC资源管理]] 则说明抗干扰资源管理已经不再是外围通信问题。
- Batch_06 的关键增量有两个：[[虚拟网络功能（VNF）]] 让空中可计算网络设计开始进入主线，[[Zhao2025_动态环境中的多UAV协同任务调度]] 则把“协同部署 + 动态匹配”重新推到连续调度核心位置。
- Batch_07 的关键增量是把安全卸载推进到“移动合谋窃听 + 实时计算调度”层：[[Zhao2025_移动合谋窃听下的UAV辅助MEC安全传输与计算]] 说明安全问题已经不只改变传输链路，还会直接重写 UAV、远程设备和 BS 之间的计算组织逻辑。
- Batch_08 的关键增量有两个：[[Zhao2025_UAV-MEC中的内容缓存服务放置与任务卸载联合优化]] 让缓存、服务放置和卸载真正合流到统一服务系统目标，[[Yang2024_巡检系统中蜂窝连接UAV-MEC的能效传输策略]] 则提醒我们业务访问顺序本身就是决定卸载能耗的重要控制变量。
- Batch_09 的关键增量有三个：[[微服务MEC架构]] 与 [[层次化网络切片]] 让服务组织层继续变厚，[[Sun2025_JC5A空中MEC辅助工业CPS服务时延最小化]] 把工业闭环服务控制直接接进主线，[[Zhou2025_用户偏好导向的UAV辅助MEC服务缓存与任务卸载]] 则让需求侧偏好开始反向塑造缓存与卸载联合设计。
- Batch_10 的关键增量有一个：[[Song2024_空地协同MEC中的AoI与能耗权衡学习]] 明确说明，当系统目标包含信息新鲜度时，卸载与轨迹控制需要转向 Pareto 策略集而不是单点最优。

- Batch_12 的关键增量是把 `THz + IRS` 与 `WPT/WPCN` 继续接入主线，说明卸载问题正在从经典 MEC 调度进一步扩展到传播控制和能源状态共同塑造的在线系统。

- 这条主线也越来越明显地吸收安全、机制设计与平台组织问题，说明后续写综述时不能只按算法类型分节。
