# 大语言模型驱动无人机规划

## 定义
[[大语言模型驱动无人机规划]]指利用 `LLM / VLM / MLLM` 理解任务描述、约束和上下文，并将其转化为无人机可执行的动作计划、技能调用序列，或者为调度优化生成高价值启发式。

## 为什么重要
- 它让无人机系统从“预定义控制逻辑”转向“自然语言与高层知识驱动的任务组织”。
- 在复杂任务、多步骤条件推理、人机协作和大规模调度中都可能发挥作用。
- 真正的难点不只在规划能力，还在首动作时延、执行可靠性、重规划能力和启发式稳定性。

## 当前语料中的代表论文
- [[Chen2025_TypeFly低时延大模型无人机规划]]：通过 `MiniSpec`、stream interpreting 和 probe 降低 LLM 规划延迟。
- [[Zhang2025_空中边缘大模型的边云协同演化]]：从系统层讨论大模型在空中边缘中的协同部署。
- [[Zhou2025_LLM增强Q学习的多并行无人机调度]]：展示 LLM 也可以作为强化学习与调度优化的启发式生成器，而不是直接输出控制动作。

## 关键研究对象
- 任务描述到动作计划或调度启发的翻译
- token 效率与中间表示压缩
- 首动作时延、流式执行与在线重规划
- 作为 controller 的 LLM 与作为 optimizer assistant 的 LLM 之间的角色区分

## 研究判断
当前语料表明，大模型进入无人机系统至少存在两条路线：一条是直接做自然语言到动作计划的具身规划，另一条是为经典调度和强化学习生成结构化启发式。两者都很重要，但系统瓶颈不同，前者更看重实时执行链路，后者更看重大规模搜索效率与稳定性。
