# Xu2025_区块链赋能的安全带宽分配博弈激励

## 单行摘要
论文针对不可信 UAV 辅助无线网络中的带宽交易问题，提出区块链监督的安全带宽分配框架，并用 `Stackelberg` 博弈联合决定 UAV 的带宽定价与用户的带宽请求。

## 题目驱动研究框架
- 研究场景：地面基础设施受损或过载时的 UAV-assisted wireless networks。
- 研究对象：UAV、移动用户、区块链账本与智能合约。
- 核心问题：有限带宽资源要在不可信环境中安全、公平且高效地分配。
- 标题承诺的方法：blockchain-empowered game theoretical incentive。
- 期望效果：同时提升安全性、效率与带宽分配公平性。

## Algorithm Design 快照
这篇论文的核心不是单独做价格博弈，而是先搭一层“可信交易外壳”。作者用区块链不可篡改账本记录交易和恶意行为，用智能合约处理自动支付和惩罚，再在此基础上把 UAV 与用户之间的带宽交互建模成 Stackelberg 博弈。

## 图1系统框架草案
- 服务层：UAV 为移动用户提供无线带宽服务。
- 治理层：区块链记录交易与恶意行为。
- 合约层：智能合约自动执行押金、结算与惩罚。
- 共识层：基于信誉的 `DPoS` 维护账本有效性。
- 决策层：UAV 定价，用户按价格请求带宽。

## System Model
### 1. 参与实体
- UAV 作为带宽服务提供者。
- 移动用户作为带宽请求者。
- 区块链系统负责记录交易和恶意行为。

### 2. 威胁与激励模型
- 存在拒付、伪装、数据篡改等恶意行为风险。
- 需要自动支付和可追责机制维持长期合作。

### 3. 优化目标
- 提高 UAV 和用户双方效用。
- 在安全、效率和公平之间实现平衡。

## Algorithm Design 详解
### 1. 区块链带宽分配框架
- 智能合约负责初始化、交易、恶意行为记录和最终结算。
- 区块链让历史交易和恶意行为信息不可篡改。

### 2. 信誉驱动共识
- 使用带信誉约束的 `DPoS` 维持账本可信与高效。
- 尽量避免恶意实体主导决策流程。

### 3. Stackelberg 激励机制
- UAV 作为领导者决定带宽价格。
- 用户作为跟随者根据价格选择带宽请求量。
- 通过 backward induction 求取 Stackelberg equilibrium。

## Introduction 写作素材
- 在基础设施损坏或热点拥塞场景中，UAV 带宽供给必须面对“不可信交易”而不仅是“资源稀缺”。
- 若没有自动支付和恶意行为记录机制，传统带宽定价模型很难长期运行。
- 这篇论文适合支撑“空中资源分配必须同时具备激励与治理”的论述。

## Related Work 写作素材
- 以往安全带宽分配常依赖协作干扰、信誉或拍卖，但较少把自动支付和恶意行为追踪纳入统一机制。
- 相比静态博弈，这篇论文更强调动态网络下的价格-请求互动。
- 它也是区块链从“身份认证”进一步走向“资源交易治理”的代表案例。
