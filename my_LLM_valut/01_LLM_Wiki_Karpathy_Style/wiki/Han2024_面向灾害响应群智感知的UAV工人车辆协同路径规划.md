# Han2024 面向灾害响应群智感知的 UAV、工人、车辆协同路径规划

## 单行摘要
论文提出异构多智能体路径规划算法 MANF-RL-RP，在灾害响应群智感知中联合调度 UAV、工人和车辆。

## 题目驱动研究框架
- 研究场景：灾害区域中需要快速获得现场最新信息的群智感知任务。
- 研究对象：UAV、地面工人、车辆等异构代理，以及分布在灾区的感知任务点。
- 核心问题：不同代理机动能力、速度、续航和可达性差异明显，如何协同规划路线以提升任务完成率。
- 标题承诺的方法：collaborative route planning of UAVs, workers, and cars。
- 期望效果：让异构代理发挥互补优势，在复杂灾区环境下完成更多感知任务。
- 标题与正文的偏差：标题强调 route planning，但正文真正的关键在于针对异构代理设计的 MARL 信息处理与网络结构。

## Algorithm Design 快照
论文面向灾害响应群智感知任务，研究 UAV、工人和车辆三类异构代理如何协同执行路径规划以最大化任务完成率。作者指出，不同代理在速度、可达性、续航和地形适应性上差异显著，简单地把它们当作同类 agent 会损失协同效率。为此，论文提出 MANF-RL-RP，在全局-局部信息融合和异构代理模型结构上做了针对性设计，使各代理既能利用本地状态，也能考虑跨类型协作关系。

## 图1系统框架草案
- 系统实体：空中 UAV、地面工人、车辆、灾区任务点/感知点。
- 任务/数据流：任务由三类代理按可达性和代价进行分配，各代理沿规划路线依次完成感知。
- 控制/优化变量：每类代理的路线选择、任务分配、全局与局部信息融合结果。
- 约束来源：灾区道路与地形、UAV 续航、工人与车辆速度差异、任务时效。
- 画图提醒：建议把三类代理画成三条不同颜色的能力通道，突出异构性。

## System Model
- 论文不是单一 UAV 路径规划，而是异构多代理协同调度。
- UAV、工人和车辆在机动能力与可达区域上互补，因此任务分配必须结合代理类型。
- 目标函数侧重任务完成率而非单一移动距离，体现灾害响应场景的任务导向。
- 该系统模型与经典 TSP/VRP 的主要差别在于代理异构性和任务紧急性。

## Algorithm Design 详解
- 第一步是构建包含 UAV、工人、车辆的异构多智能体任务模型。
- 第二步是在网络结构中同时处理全局信息和局部信息，以兼顾协作与个体决策。
- 第三步是设计适用于异构代理的 MARL 路径规划算法 MANF-RL-RP。
- 第四步是与 Greedy-SC-RP、MANF-DNN-RP 等基线比较任务完成率。
- 第五步是开放实验代码与数据示例，提升后续复现实验的可追溯性。

## Introduction 写作素材
- 灾害响应里只靠 UAV 往往不够，因为地面代理在近距离确认和复杂路况穿行上有不可替代性。
- 真正关键的问题是如何把空中与地面异构代理组织成互补的任务系统。
- 这篇论文适合支撑“从单 UAV 感知走向异构协同感知”的引言推进。

## Related Work 写作素材
- 与单一 UAV 路径规划不同，本文显式引入工人和车辆。
- 与把异构代理简单共享参数的 MARL 方法相比，本文强调全局-局部双信息处理。
- 与贪心或静态分配方法相比，本文更适合灾害场景中的动态协同。
