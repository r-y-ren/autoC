# 任务队列与时延保障模型

## 定义
[[任务队列与时延保障模型]]描述任务到达、排队、服务和离开的动态过程，以及这些过程如何转化成平均时延、统计时延、缓存溢出、首动作延迟、QoE、AoI 或长期稳定性约束。

## 为什么重要
很多 UAC 论文的真实难点不是单时隙最优，而是任务会持续到达、持续堆积，系统必须在长期运行中维持稳定与可服务。随着研究对象从传统任务卸载扩展到视频服务、URLLC 通信和 LLM 规划，时效保障的含义已经从“平均完成时间”扩展到“体验、信息新鲜度与交互响应”。

## 常见建模方式
### 1. 平均时延或完成时间建模
- 适合基础卸载与资源分配问题。
- 重点在总体效率。

### 2. 队列稳定性 + Lyapunov 方法
- 代表论文：[[Dai2024_车联网中的UAV辅助任务卸载]], [[Chen2025_Lyapunov辅助DRL的轨迹与资源联合优化]], [[He2024_UAV辅助MEC服务质量体验最大化的在线联合优化]]
- 适合处理长期随机到达与长期约束。

### 3. 统计时延与缓存约束
- 代表论文：[[Huang2024_多UAV车载边缘计算动态任务卸载]], [[Bai2024_多UAV边云协同时延感知任务卸载]]
- 通过 stochastic network calculus 或服务链分析给出时延违规概率、缓存溢出界或端到端时延上界。
- 适合可靠性和 SLA 导向问题。

### 4. 服务链双阶段时延建模
- 代表论文：[[Cong2024_ParallEdge计算移动并行的5G6G边缘计算]]
- 把一次上传、一次返回和中间处理过程分开建模，强调移动与计算重叠后如何压缩总完成时延。
- 适用：移动边缘服务器与广域覆盖场景。

### 5. 首动作延迟建模
- 代表论文：[[Chen2025_TypeFly低时延大模型无人机规划]]
- 关注用户下达任务后系统给出第一个可执行动作所需时间。
- 适用：交互式规划与具身智能系统。

### 6. QoE / MOS 与队列稳定联合建模
- 代表论文：[[He2024_UAV辅助MEC服务质量体验最大化的在线联合优化]], [[Hoang2025_6G空中小蜂窝中多UAV基站自适应三维部署]]
- 用 QoE 或 MOS 作为长期目标，同时用虚拟队列保证资源与推进功率稳定。
- 适用：体验导向的在线部署和在线卸载场景。

### 7. 有限块长下的 BLER / AoI / latency 联合建模
- 代表论文：[[Hoang2024_有限块长NOMA多用户配对UAV系统性能分析与优化]]
- 把 BLER、时延、goodput 与 AoI 放进同一短包通信框架。
- 适用：URLLC 和时效敏感通信场景。

### 8. AoI 驱动的信息新鲜度建模
- 代表论文：[[Hou2025_AoI感知的异构UAV-USV-UUV网络水下目标围捕优化]]
- 强调信息距离最近生成时刻已经过去多久，而非仅关注传输完成时间。
- 适用：搜索、跟踪、监测和状态更新任务。

## 常见变量与参数
- 到达率
- 服务率
- 队列长度
- 时延上界或违规概率
- 缓存容量
- 任务完成时间
- 首 token / 首动作时延
- QoE / MOS
- BLER / goodput / AoI
- 调度周期与重规划周期

## 写作提醒与常见坑
- 明确任务是随机到达还是静态已知。
- 明确目标是平均时延、完成时间、统计保障、QoE，还是 AoI / 首动作响应时间。
- 如果使用 Lyapunov，要交代队列如何构造以及它约束的对象是谁。
- 如果进入 URLLC 或有限块长场景，不要继续只用 Shannon 速率近似。
- 面向搜索、跟踪或交互式系统时，不要把“时延”与“信息新鲜度”混为一谈。
