# 安全与服务保障

## 主题概览
这条主线已经从“性能最优之上的附加安全约束”演化成“可信、可靠、可感知、可治理的服务系统设计”。当前语料说明，保障不只包括体验、时延和成功率，也包括物理层安全、链上资源交易、身份认证、密钥治理和公平服务。

## 研究判断
- 新语料说明“安全与保障”已从链路保密和服务可得性，扩展到身份认证、密钥治理、链上资源交易、自治集群可信基础设施，以及监测部署本身带来的社会负效应。
- Batch_02 的关键增量是把随机 LoS/NLoS 可靠性建模正式接进主线，说明服务保障不再只是“附加约束”，而开始成为系统目标本身。
- Batch_04 则进一步提醒我们，监测效用越高未必越好；噪声、隐私侵扰和安全距离等负效应也需要被正面写进系统设计。
- Batch_05 进一步把“安全”从窃听与身份扩展到智能抗干扰、图学习驱动的多用户保密通信，以及时间域合谋窃听下的协同安全中继。
- Batch_06 继续把保障主线推向“韧性 + 生成式安全控制”：一方面开始正面讨论节点失效后的拓扑恢复，另一方面开始出现扩散模型驱动的多目标协同安全通信。
- Batch_07 则把这条主线进一步推到“可信治理 + 主动防御 + 物理系统安全”层：友好干扰开始被写成多智能体在线协同问题，RSMA 安全波束赋形与部署联动进入主线，跨域认证、链上带宽交易和信任增强量子联邦学习把治理机制补齐，FDI 联合防护与加固数字孪生则把研究边界推进到真实飞控安全和可信物流系统。
- Batch_08 则进一步把“安全链路”推进到光学与量子层：[[Trinh2025_光学RIS提升HAP-UAV场景FSO量子密钥率]] 说明空中安全不只发生在射频窃听博弈里，`ORIS + FSO + QKD` 也开始成为值得单列的安全基础设施分支。
- Batch_09 则提醒我们，“保障”还包括服务不断档与身份不被伪装：[[Li2025_DroneMA基于移动性对齐的无人机AI欺骗检测]] 把物理层欺骗检测带进实飞链路，[[Rizvi2025_面向韧性运行的无人机间服务干扰监测]] 和 [[Roy2025_Serv-HU面向UaaS的服务接力机制]] 则把服务干扰识别与跨服务商接力机制推进到运行韧性层。

- 当系统进入自治蜂群、无人值守部署和基础设施缺失环境时，谁来认证、谁来授权、谁来更新密钥、谁来可信交易都会成为核心问题。
- 这条主线非常适合承接“为什么 UAC 研究必须从优化问题走向可信系统问题”的写作逻辑。

- Batch_12 说明“保障”正在继续向系统内生安全和飞行控制韧性延伸：不仅要保密和认证，还要识别群内异常、区分故障与攻击，并在故障发生后继续安全编队与控制。
