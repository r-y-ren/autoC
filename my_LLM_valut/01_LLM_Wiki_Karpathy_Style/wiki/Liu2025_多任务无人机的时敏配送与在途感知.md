# Liu2025 多任务无人机的时敏配送与在途感知

## 单行摘要
论文面向同时执行包裹配送与在途感知的单无人机场景，利用 `FH-MDP + 阈值切换策略` 联合控制飞行速度与感知动作，在保证时限配送的同时尽量节能并获取感知收益。

## 题目驱动研究框架
- 研究场景：低空物流与沿途感知并行发生的单无人机任务场景。
- 研究对象：多任务无人机、配送截止时间、沿线 POI 感知任务、飞行能耗。
- 核心问题：配送必须按时完成，但沿途感知又希望尽量多做，二者都直接受速度与悬停行为影响。
- 标题承诺的方法：delay-sensitive goods delivery and in-situ sensing using a multi-task drone。
- 期望效果：在不违背送达时限的前提下，通过在线阈值决策兼顾感知回报与能量效率。
- 标题与正文的偏差：正文真正的创新点不只是“多任务”，而是把速度选择与是否感知统一成可证明单调性的有限时域决策问题。

## Algorithm Design 快照
论文把“快送达”和“多感知”写成一个有限时域马尔可夫决策问题：无人机在每个时隙可以全速、巡航，或在 POI 上悬停感知。由于剩余距离、已用时间和街区位置共同决定未来代价，作者进一步证明 Bellman 方程具有单调性与次模性，从而构造出一类可在线执行的阈值策略。无人机无需每次重新做高复杂度动态规划，只需比较当前剩余距离和已用时间是否触及阈值，就能切换最优动作。

## 图1系统框架草案
- 物流主线：起点、固定配送路线、目的地、严格到达时限。
- 感知支线：沿途街区中的若干 POI、对应感知奖励与悬停时长。
- 决策层：动作集合包括全速、巡航和悬停感知。
- 状态变量：剩余距离、当前街区、已用时间。
- 画图提醒：把“配送为硬约束、感知为软收益”画成主次双层结构，会更符合论文本意。

## System Model
- 无人机沿预规划路径飞行，总路程和最晚到达时间已知。
- 街区被划分为有无 POI 两类，只有在含 POI 街区才允许感知动作。
- 无人机动力消耗由飞行速度和悬停感知共同决定，配送超时会产生高额惩罚。
- 系统优化目标不是简单最短路，而是感知收益、飞行能耗和超时风险的联合代价最小化。

## Algorithm Design 详解
- 先将多任务控制写成 `FH-MDP`，状态由剩余距离与街区位置构成，动作包括不同速度与感知。
- 再把“按时送达”写成强惩罚约束，使配送优先级压过可选感知收益。
- 通过证明 Bellman 方程的单调性和次模性，得到最优动作关于剩余距离和时间的阈值结构。
- 最终策略可以在线运行：无人机只需判断当前状态与阈值的相对关系，就能实时切换动作。

## Introduction 写作素材
- 低空物流系统并不总是“只送货不感知”，很多实际任务天然要求无人机在途中顺带完成环境信息采集。
- 多任务无人机的难点不是多一个任务，而是不同任务的优先级和时限差异会直接改变飞行控制逻辑。
- 一旦把沿途感知视为可选收益，速度控制和任务选择就不能再分开讨论。

## Related Work 写作素材
- 既有配送工作常偏向单一物流目标，缺少对沿途感知收益的统一建模。
- 既有多任务路径规划方法常依赖离线优化，难以在线响应新出现的感知请求。
- 该文把“配送-感知”写成带阈值结构的 FH-MDP，是低空物流与在途感知结合的代表页。
