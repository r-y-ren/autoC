### A 题《基于主从空间分解与关联的移动通信网络 PCI 规划》（全国一等奖，MC2400319，国防科技大学）

**解题骨架**（据摘要页 p1 与目录）：
1. 定义综合冲突度 = PCI 冲突 MR + 混淆 MR + 模3干扰 MR 之和，作全篇统一目标度量；
2. 基于区域冲突度将海量小区空间分解为"主要区域/次要区域"；
3. 以模拟退火为框架融合分层编码、图软着色、动态邻域、扰动策略，提出"主从伴随优化算法"（主要区域全局优化、次要区域伴随受主要区域影响）解问题一；
4. 问题二升级为三层串行：分别以冲突/混淆/模3干扰 MR 最小为各层目标，前层解作后层约束，逐层主从伴随优化；
5. 问题三再叠加禁忌表（避免重复访问解）与稀疏矩阵（降内存），求解全区域综合分配。

**亮点**：
- 大规模组合优化的**分解-分层降维**思路完整：把"解空间爆炸"的 PCI 分配拆成主/从区域关联优化 + 三目标分层串行，可直接应对工程级小区数量（摘要 p1）；
- **量化基线对比**：与 GA/SA/PSO 对比，综合 MR 值降低约 25%（摘要 p1，属该赛"结果说话"评审口味的典型满足）；
- **收敛性证据链**：给出迭代 82 次收敛至综合 MR=26175451、问题二冲突/混淆 MR 均为 0 等具体数值（摘要 p1-2）；
- 学术性包装完整：含国内外研究现状、组合优化复杂性分析、算法伪代码（目录 1.2/2.1/3.4.3 节），远超赛制"正文约 30 页"的最低要求（全文 58 页）。

**不足与可改进点**（核对维度：最优性/鲁棒性/假设强度/格式合规）：
- 启发式算法无最优性差距证明：未报告与下界（如 LP 松弛/已知名单最优）的 gap，"最优"仅体现为迭代收敛（摘要 p1）；
- 分解阈值（主/次区域划分标准）的敏感性未见讨论，换数据集稳健性存疑；
- 58 页正文显著超出"正文约 30 页"的格式建议（来源：meta 提交物规范[7]），虽然"排版格式不做统一要求"，页数失控在部分评审口味下是扣分项；
- 摘要跨两页（p1-2），信息密度但篇幅超长，第一页未见"问题-方法-结论"式收束。

**可迁移性**：
- "统一冲突度量 → 空间/结构分解 → 主从分层优化 → 禁忌加速"是可复用的大规模离散优化模板，适配供应链选址、频谱分配、排班等题面（复用成本：中，需自建邻域结构）；
- 摘要按问题分节、每节附"主要结论（1）（2）（3）+具体数值"的写法可直接套用；
- "对比基线选经典启发式（GA/PSO/SA）并给百分比改进"是最省力的量化证明路径。

### B 题《基于深度学习的甲骨文图像分割与文字识别模型》（全国一等奖，MC2406982，华侨大学）

**解题骨架**（据摘要页 p1 与目录）：
1. 预处理流水线：Otsu 二值化 → 闭/开运算 → 高斯滤波 → 中值滤波，消点状噪声与纹理干扰（问题一）；
2. 单字分割：改进 YOLOv5——PP-LC 轻量主干 + SE/GSPPF 空间金字塔 + CA 注意力 + FocalCIoU 损失应对样本不平衡（问题二/三）；
3. 消融实验逐项验证各模块贡献（目录 5.3/第六章"自动单字分割模型的改进"）；
4. 识别：CNN baseline（训练 0.963/验证 0.898）→ MobileNetV2（验证 0.983、AUC 0.99），成对 t 检验证明差异显著（问题四）。

**亮点**：
- **baseline→改进→消融→统计检验**四步论证链完整，每个改动都有独立证据（摘要 p1；目录 5.3.2/第六章）；
- 改进点全部对准甲骨文拓片的具体痛点（噪声/小目标/类别不平衡），不是为改而改（摘要 p1）；
- 双模型对比 + AUC + 成对 t 检验，量化说服力强于常见的只报 accuracy。

**不足与可改进点**（核对维度：泛化性/数据划分/方法-赛题匹配）：
- 摘要称 MobileNetV2"在训练集上达到了完美的准确率"——训练集 100% 是过拟合信号，文中未见正则化/dropout/早停的针对性讨论（摘要 p1）；
- 验证集与测试集是否分离未在摘要与目录层面体现，泛化结论强度存疑；
- 深度学习堆叠与"数学建模"的关联论证薄弱（该赛评审偏好数理模型，纯 CV 工程流需要额外的数学化包装，本文用形态学/滤波器等传统图像处理补了一部分）；
- 识别环节仅两类架构对比，未尝试few-shot/模板匹配等更适合甲骨文小样本的路线并说明取舍。

**可迁移性**：
- "预处理流水线（二值化+形态学+双滤波）+ 改进 YOLO 分割 + 轻量分类器对比"整套 CV 题面模板可复制到任何图像类赛题（复用成本：中低，改进模块即插即用）；
- 消融实验表 + 成对 t 检验是让"深度学习改进"在数模评审面前站得住的最小证据集，可直接搬用；
- FocalCIoU 应对样本不平衡的思路可迁移到任何检测类子问题。

### C 题《基于 LSTM-ARIMA 和整数规划的货量预测与人员排班模型》（全国一等奖，MC2402447，扬州大学）

**解题骨架**（据摘要页 p1 与目录）：
1. 问题一：57 站点货量双粒度预测——日粒度用 LSTM、时粒度用 ARIMA（数据特点分治，附平稳性检验"0.01，则历史数据可以使用"，正文 5.4 节）；
2. 问题二：解析运输路线变化，把变化路线货量按比例向相关分拣中心重分配，得货量变化率并修正预测模型；
3. 问题三：整数规划排班——目标最小化总人天数，约束=处理货物量/人员优先使用/小时人效均衡，用"简单的任务分配算法"求解；
4. 问题四：特定中心 SC60 升级为多目标规划（总人天数+正式工出勤率均衡双目标），遗传算法求解。

**亮点**：
- "预测 → 业务规则重算 → 规划排班"的**闭环业务链**结构清晰，四问层层递进且复用前问输出（摘要 p1）；
- 按数据特点分治选型（日/时两粒度各配 LSTM/ARIMA）而非一套模型打天下（摘要 p1）；
- 排班约束贴近真实运营（人员优先级、人效均衡、连续出勤），整数规划建模规范（摘要 p1；目录 5-6 章）。

**不足与可改进点**（核对维度：预测精度量化/求解最优性/格式）：
- 摘要未报告任何预测误差指标（MAE/MAPE/R²），预测质量仅由"结果表 1-4"承载，量化说服力弱于同届 A/B 题论文；
- 整数规划用"简单的任务分配算法"求解（摘要 p1），启发式与精确解关系未说明，最优性无 gap 论证；
- LSTM 对 57 站点逐站建模的计算成本与小样本风险未讨论；
- 细节粗糙处：摘要"详见结果表 1,。"有标点笔误；题号写作"（C）"带括号与规范"题号 C"略有出入；全文 29 页贴近"约 30 页"下限，深度型评审可能嫌论证密度不足。

**可迁移性**：
- "时序预测 + 规则重分配 + 整数规划排班 + 多目标特例分析"是物流/运营类赛题的万能骨架，2025 D 题（见 winners/2025.md）同构获奖路径可互证；
- 双粒度分治建模（日/时）可直接套用到任何含多时间粒度问法的题面；
- 复用成本低：LSTM/ARIMA/整数规划均有成熟库，四问拆解结构可模板化。
