### A 题 · Modeling Smartphone Battery Drain（O 奖，东北大学秦皇岛分校 2616026，Ben Fusaro Award）

**深构对象**：东北大学秦皇岛分校官方新闻（2026-05）——队员刘灿霖、赵浩廷、欧敏君（均为 2024 级），指导教师张尚国；与 [BLOG] 名册（Liu Canlin/Zhao Haoting/Ou Minjun，advisor Zhang Shangguo）**逐名吻合**，队级归属确证。[NEUQ] **材料等级：校方官网新闻层（策略/培养侧），论文模型内部不可核。**

**解题骨架**（任务层重构，据 [PDF-A 新闻稿页]）：
1. 官方任务链：建电池耗电随时间演化模型（不同使用条件）→ 分析屏幕亮度/应用活动/网络使用/环境条件对续航的影响 → 估计 time-to-empty → 给出改善电池性能的策略建议；
2. A 题为 2026 参赛量第二大题（8,574 队）但 O 占比六题最低（0.070%）——数据/机理混合题的高淘汰结构 [PDF-A 机读计数]；
3. 队伍背景：三名 2024 级低年级学生 + 张尚国（该校 2023 年首枚 O 奖后第二次摘 O）[NEUQ]。

**亮点**：
- 低年级队摘命名奖：2024 级（大二）学生拿下 Ben Fusaro Award（创造力维度命名奖），佐证"选题匹配+培训体系>资历" [NEUQ；BLOG]；
- 校级培养体系可复证：公共选修课→校内选拔赛→"基础知识拓展、技能实训到实战演练"全链条，该校累计 2 O/25 F/104 M/419 H [NEUQ]；
- 连续获奖结构：该校 2023、2026 两届 O 奖，非偶然爆发 [NEUQ]。

**不足与可改进点**（核对维度：模型主线/方法/数据/验证——均不可核）：论文模型层（电池建模形式、参数标定、验证方式）在会员墙后，校方新闻属宣传性文本无技术自评；A 题六支 O 队均无公开论文镜像（GitHub 按队号检索无果，2026-08-28 核验）。**UMAP Journal 摘要版为最高优先级补采目标。**

**可迁移性**：
- "机理+使用场景数据"双驱动的电池衰减题是 A 类连续题的标准结构（对照 [PDF-A] 任务四段式：建模→归因→预测→建议），可作我方 A 类解题 checklist；
- 低年级组队策略：早进培训体系（选修课+校内赛）而非等课程修完——对以"出成绩"为目标的队伍，时间线前移一学期。

### B 题 · Creating a Moon Colony Using a Space Elevator System（O 奖，浙江大学 ZJUI 2602524，SIAM Award + COMAP Scholarship Award）

**深构对象**：ZJUI 学院官方新闻（2026-02-06）+ [BLOG] 名册。队员刘昱绚、韩文哲、沈梓珩（2024 级 ECE，均为大一/大二），论文题名 **"A Multi-Objective Optimization Framework for Sustainable Lunar Logistics"**。[ZJUI; BLOG] 名册逐名吻合（Yuxuan Liu/Wenzhe Han/Ziheng Shen，advisor Yuxuan Liu）。**材料等级：校方官网新闻层（含论文题名、模型名与任务链细节），模型公式层不可核。**

**解题骨架**（据 [ZJUI]，模型名与量化结论均为新闻原文转述）：
1. 核心问题定位：2050 年 10 万人月球基地，如何把 **1 亿吨建材**从地球运到月球；
2. 抓技术矛盾：太空电梯成本低但运力/周期受限 vs 火箭快但成本与碳排放高——跳出"单一运输方式优劣对比"，建 **综合月球物流模型 ILLM**（Integrated Lunar Logistics Model），在成本/时间/环境影响三目标间优化；
3. 三场景量化对比（电梯单独/火箭单独/混合），结论：任何单一路径都无法同时满足经济性与 2050 时限 → 提出**混合运输策略**；
4. 动态修正：把设备故障概率、电梯缆绳摆动、火箭发射失败风险、地月水资源补给约束、碳排放上限纳入模型；
5. 输出兼顾工程可行性、经济合理性、环境可持续性的全周期物流方案。

**亮点**：
- 洞察力：把题目从"电梯 vs 火箭"重构为"物流网络多目标设计"——拒绝二选一是该队自述的核心创新 [ZJUI]；
- 任务全覆盖：成本/时效/可靠性/环境影响四维全占（对照 [PDF-B 新闻稿页] 官方任务描述），且每维都有约束进模型而非口头讨论 [ZJUI]；
- 表述策略：首次参赛队赛前系统研读历年 O 奖论文（结构/图表/叙事），但明确警惕"按模板套写"，赛中先花"大半天"做问题拆解、模块划分与分工，再进建模 [ZJUI]；
- 双奖佐证：SIAM（技术）+ COMAP 奖学金（综合表现）同收，六题 6 支奖学金队之一 [RES]。

**不足与可改进点**（核对维度：公式/参数/求解器/验证——均不可核）：新闻层未给出目标函数形式、权重处理（Pareto 前沿 vs 加权）、亿吨级物流的离散事件仿真细节；"混合策略最优"的结论在其表述中未附最优性 gap 或敏感性证据；参赛 25 页原稿不可得，以上为新闻层可见度的真实边界。

**可迁移性**：
- **"多目标优化框架命名+三场景对比+工程风险动态修正"的三段式**可直接移植到任何"方案比较类"赛题（B/E 类通吃），复用成本：低（框架半天可立，仿真按题定制）；
- 备赛方法可复制：研读 O 奖论文学结构但设"反模板"红线；开赛后先慢后快（先拆解分工再建模）——与 2024 届 Harvey Mudd（Duke 同构）"写作与结构优先"互证 [ZJUI；对照 winners/2024.md D 条目]。

### C 题 · Data With The Stars（自述 O 奖队员镜像，队号未标注；官方锚点：苏州大学 2612354 SIAM+奖学金 / 威斯康星麦迪逊 2631531 MAA）

**深构对象**：GitHub 仓库 `lnlll162/2026_mcm_c_o_prize`（创建于 2026-02-03，即赛程结束次日；描述"2026-美赛C题O奖"）——含 README 方法总纲、solution_plan.md（20KB 主线方案）、AI 使用报告、全量脚本与 34 季 bootstrap 输出。[GH-C] **材料等级：队员自公开镜像（方法一手·复现级），但仓库无队号/证书/校名，19 支 C 题 O 队中无法定位具体队——队级归属 verified: false，技术内容按"自述 O 奖稿"采信。**

**解题骨架**（据 [GH-C] README+solution_plan）：
1. 问题重构： Dancing with the Stars 类节目每周由"评委分+粉丝票"合并定淘汰，而真实粉丝票数保密——把粉丝份额 p_{i,w} 当**隐藏变量**，仅用可观测的评委分与淘汰结果反解；
2. 评委份额 j_{i,w}（当周评委总分标准化）+ 粉丝份额 p（每周在存活集合上满足 simplex 约束），合并得分 C=α·j+(1−α)·p（Percent 规则），另评估 Rank 规则（等价变换 C'=−R 统一评估口径）；
3. 损失设计：只用可观测淘汰者 e(w) 的 logistic 排序损失 L_elim + 平滑正则 R_smooth + 中心化正则 R_center，在多解中选"稳定代表解"，诚实声明"真实票数未知且多解"；
4. 验证：全 34 季分段评估（S01–27 vs S28+），**bottomN_rate=0.9767（ALL）、top1/top2=1.0000**；切换点敏感性 S0∈{27,28,29} 结论稳定；
5. 扩展：bootstrap（B=50/季）量化不确定性；规则偏向性指标+争议案例复盘（season 30 week 3、season 21 week 7）；名人特征（年龄/行业）影响分析含显著性检验；新赛制设计（动态 α(w)+Judges' Save）并仿真对比新旧规则。

**亮点**：
- 洞察力：识别"反推隐藏变量+多解正则化"这一问题的本质难点，README 置顶"真实票数未知且多解，输出的是稳定代表解+置信区间"——把不可辨识性本身写成贡献而非回避 [GH-C README]；
- 正确性：评估口径工程化（bottomN 支持多淘汰周、top-k 区分单淘汰周、N/A 与淘汰后记 0 的预处理规则明示）；分段+切换点敏感性+posthoc α 扫描三重稳健性检查 [GH-C README 输出文件节]；
- 完整度：题目任务链（评估合并规则→公平性/偏向→争议复盘→新赛制设计）逐项有脚本与输出文件对应，复现命令逐条可跑 [GH-C README]；
- **AI 合规样板**：AI 使用报告披露 Cursor Cascade 三次使用（写作组织/验证脚本/AI 报告草拟），声明"所有数值结论以本地脚本输出为准，AI 建议仅在端到端跑通后采用"——对 COMAP 2026 AI 政策（meta.md ai_policy）是教科书式执行 [GH-C AI_Use_Report_CN.txt]。

**不足与可改进点**（核对维度：身份/数据泄漏/验证强度）：
- **身份不可核**（最大缺口）：仓库无队号、无证书、owner 匿名，"O 奖"为自述；19 支 C 题 O 队均无法排除/确认，采信需降级标注——UMAP 摘要版出版后应做方法指纹比对；
- top1/top2=1.0000 的"完美"指标主要反映**用淘汰结果反推再预测淘汰**的内洽性（同源性偏乐观），非真泛化预测力；未见对未参与反推周的 held-out 验证口径说明（solution_plan 提及 LOOW-CV 仅列为"可选扩展"，主线用固定 α+posthoc 扫描）[GH-C README 快速开始节]；
- 新赛制（动态 α(w)+Judges' Save）为 AI 辅助起草章节，其仿真对比的独立性存疑（同一团队既设计方案又评估方案）[GH-C AI 报告第 1 条]。

**可迁移性**：
- "隐藏变量反推+排序损失+正则选代表解+bootstrap 区间"是 C 类数据洞察题的强模板（凡"结果可观测、机制量保密"的题皆适用），复用成本：中（1-2 天搭主管道）；

- 反面教训：评估指标要防"用答案造答案"——自洽指标（复现淘汰率）必须与 held-out/前瞻指标分开报告。

### D 题 · Managing Sports for Success（O 奖，Duke University 2631725，MAA + COMAP Scholarship + Leonhard Euler Award）

**深构对象**：Duke Trinity College 官方新闻（2026-06-17）+ [BLOG] 名册。队员 Daniel Cheng（数学/经济双学位）、Malachy O'Donnabhain（数学/哲学）、Zain Radwan（数学/电子与计算机工程），导师 Veronica Ciocanel；三人因橄榄球结识的大二队。[DUKE; BLOG] 名册逐名吻合。**材料等级：校方官网新闻层（方法细节丰富），公式层不可核；2026 唯一三奖队（含 ICM 侧最高命名奖 Euler）。**

**解题骨架**（据 [DUKE]，方法细节为新闻原文转述）：
1. 案例锚定：选 Cheng 主队英超水晶宫（Crystal Palace F.C.）为建模对象，把"体育 franchise 运营优化"落到具体联赛规则上；
2. 白板先行：先花大量时间"把题目拆开"（'huge and messy'），商定总体结构后按强项分工——Radwan 球员评估与伤病风险、Cheng 票价与收入优化经济模型、O'Donnabhain 统计框架整合；
3. 位置标准化球员价值：自创 **PP90**（performance per 90 minutes）指标——门将/前锋不能用同一套统计，按位置分别建模再标准化可比；
4. 跨域移植：把棒球 **WAR**（Wins Above Replacement，替代级球员上胜场贡献）思想移植到足球，量化"该球员相对典型替补的贡献"；
5. 风险定价：模型合成表现统计+预期出场时间+伤病风险估计球员对球队成功概率的影响；显式纳入**降级风险**（英超降级损失约 $1 亿量级，电视转播+收入），"球员价值部分以其降低降级风险的程度定价"；
6. 数据稀缺对策：职业体育数据多为私有，"设计在可得数据上仍可用的指标"成为方法约束本身。

**亮点**：
- 创造力：PP90+WAR 移植双指标设计，把领域不对称（位置异质性）内建进指标而非事后修正 [DUKE]；
- 洞察力：抓住 D 题题眼"竞技成功与财务健康的动态权衡"，把降级损失（约 $100M）作为风险定价锚点，直通官方任务要求的"给老板的信" [DUKE；PDF-D 新闻稿页]；
- 任务链全覆盖：球员表现/伤病/名单决策（队变量）+收入/成本/估值/融资（商业变量）+工资帽/收益分享/扩军（联盟约束）三组变量均有对应模块 [DUKE 对照 PDF-D 任务描述]；
- 选题方法论：选题=兴趣+工具匹配（"运营研究+经济+统计建模一次全用上"），队友信任降低沟通成本（"math worked because the collaboration worked"）[DUKE]。

**不足与可改进点**（核对维度：公式/数据/验证——不可核）：新闻层无模型形式（成功概率模型、收入函数、约束优化的求解方式）、无验证结果；水晶宫数据的具体来源与年限未披露；PP90 的位置标准化方法（分位数映射还是 z-score）不可见。**该队论文将刊于 UMAP Journal（年内）[DUKE]，为 D 题最高优先级补采目标。**

**可迁移性**：
- "领域指标自造（位置标准化）+成熟指标跨域移植（WAR）+尾部风险定价（降级损失）"三件套可平移到一切"评估+定价"类题（D/E/F 通用），复用成本：低-中；
- 分工模式（经济建模/评估建模/统计整合各一人）+先白板后编码的流程，与我方三角色快循环结构同构，可作 role-play 模板。
