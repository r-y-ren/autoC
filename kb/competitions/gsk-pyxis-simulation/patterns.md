## 四、反面观察（常见失分模式，若有依据）

- **非法动作/异常/超时即判负**（forfeit，对手得 1.0；引擎 README/AGENTS 直抓）：掩码越界、动作头长度/类型/取值错误（含负出价与 >£100B 出价）、actTimeout 60s/步超时——工程鲁棒性缺陷一票致命，是本赛最大单点失分风险。
- **无支付能力检查的拍卖超支破产**（引擎 README： winning bid above your cash bankrupts you；掩码可行性为一阶判断，组合动作仍可能总超支）：一阶合法 ≠ 全局可负担，现金流量表管理失误直接出局。
- **时序性现金陷阱**（引擎 README：试验成本与读数先于收入扣费，破产逐笔扣费即时检查）：存在"本可被当步收入覆盖的破产"——只看期末现金的策略会死于步内扣费次序。
- 观测仅含己方组合，对手信息只经低概率 alert（20%/50%/70% 管线泄露 + 0.8 概率 BE 花费泄露）到达（引擎 README）——假设对手动作完全可观测的建模即系统性误设。
- PTRS 隐藏且读数有 ~21% 单样本噪声、付费读数按 1/2/4/7/12 倍阶梯计价（引擎 README）——把噪声读数当真值的贪心资助策略是机制性陷阱。
- 侵权红线：本库不构成对官方规则的变通建议，所有策略须以开赛后 Kaggle rules 页为准。

## 五、赛点检查表（评审标准 → 可执行检查项；快循环验收清单的派生源）

- [ ] 鲁棒性外壳：任意观测下返回合法动作 dict（头名/长度/类型/范围全对；两出价头无掩码自校验）——非法动作零容忍
- [ ] 步内预算闸门：动作集合总成本 ≤ 当前现金（含 BD/site 出价上限约束），先于扣费次序模拟破产检查
- [ ] 破产保护：现金临界步的防御性弃置（drop fee = 0.25×当前阶段剩余成本）与读数降档策略
- [ ] PTRS 贝叶斯更新：多读数精度加权融合（误差 ~1/√N），读数成本阶梯（1×→12×）纳入信息价值计算
- [ ] 市场进入次序博弈：1/n^α 惩罚（α 至第 4 进入者 = 2.0）下的进入/跟随决策，先发劣势已禁用的规则修正
- [ ] 情报利用：alert 流（含泄露的 BE 计数）反推对手管线与营销节奏
- [ ] 对 seed/对手分布稳健：Bradley-Terry 定榜机制下的方差控制（自博弈 + 对 knapsack/random 基准的批量 evaluate）
- [ ] 本地全链路：make("pyxis") 对局 → replay.json 导出 → CLI 提交 → episodes/logs 回读调试
- [ ] 开赛后 48h 内：rules 页 AI/资格/提交频率条款核验并回填 meta

## 六、对本框架的启示（喂给 K-02 / 验收报告）

- 方向契合：多智能体不完全信息博弈 + 长时序资源分配（100 步、结果滞后到达、~80% 折损）——与 RL/规划/不确定性决策类技术栈高度契合；官方捆绑 PettingZoo 训练 API 与 MaskablePPO 兼容掩码，**自博弈 RL 与搜索/启发式混合是天然起手**。
- 工程要点：obs 解码器（unflatten_to_dict_obs）一次性搭建即获字典视图；引擎 evaluate 的换座双打（每 seed 双局）应作为策略回归测试的标准协议。
- 合规栈：无 AI 限制条款（待开赛复核）+ 隐私条款（GSK 获得用户名/邮箱）+ 引擎层判负红线；数据侧无外部数据集依赖，合规面干净。
- 策略性观察：$50,000 奖池 + 论文集共著，赛事体量与 kaggriculture（10×$5,000）同档但头部集中（5 档递减）；开赛即入（公告开赛日已延迟 6 天，上线窗口临近）需作为战役时效假设。
