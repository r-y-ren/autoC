## 二、深构条目

### 1. BackstageCommercials（First Prize Overall，$15,000）

来源：https://devpost.com/software/backstagecommercials（2026-08-27 实抓，项目页发布 2026-03-16）

**技术方案骨架**（从题目到成果 5 步）：
1. 场景选帧：OpenCV 比较相邻帧、按背景运动最小排序，Nova 模型从中选定最佳起始帧；
2. 放置规划："adjuster" Nova 模型输出放置位置（XY 角点 + 参考宽高）；
3. 物理合理性校验："critic" Nova 模型判定是否悬空/穿模，不合格则回到第 2 步重试（闭环）；
4. 生成与传播：FLUX Kontext + Finegrain 商品放置 LoRA 将商品融入场景，bbox 传播到场景后续帧，YOLOv8-Seg 分割前景演员并重新合成到商品之上；
5. 购物代理：Nova 2 Lite 推理代理（识物→提取描述→网搜）+ NovaAct UI 代理（浏览器加购/心愿单），语音指令 "Find this tablecloth on Amazon" 触发弹窗直达商品页。

**亮点**：
- 技术创新：adjuster-critic 双模型自校验闭环（生成前置校验，避免无效渲染）；"只生成场景首帧 + bbox 传播 + 前景遮挡合成"把 3 分钟/帧的生成成本摊薄到整场景；4-bit 量化解决 24GB VRAM 门槛。三层成本工程（量化/单帧生成/复用）直接回应 60% 权重的 Technical Implementation。
- 技术创新（Nova 用法）：一次项目串联 Nova 视觉选帧、Nova 2 Lite 推理代理、NovaAct 浏览器代理，且各自承担非同质角色。
- Impact：面向流媒体"隐形原生广告"的变现叙事（广告即场景），商业故事完整。
- 完成度：端到端跑通——场景理解→物理合理放置→动态广告更新→购物代理。

**不足与可改进点**（核对维度：技术验证/场景泛化/评测数据/合规）：
- 无任何效果评测（广告辨识度、观看体验 A/B、放置成功率 critic 拒绝率等均未给出）；
- 场景泛化受限自认：快速运动/镜头移动场景不可用，且整场景只真正生成首帧（静态假设）；
- 2D 放置，3D 为"下一步"；
- 往影视内容里植入个性化广告的版权/披露合规问题全文未提（品牌授权、广告标识法规）。

**可迁移性**：
- adjuster-critic"生成前校验-重试"模式：任何图像/场景生成类赛题都可用，成本低（两次小模型调用）；
- "只生成关键帧 + 参数传播"的摊薄成本思路 + 量化部署：适合算力受限的黑客松环境；
- NovaAct 购物代理（识物→搜索→加购）是可整体复用的 demo 剧本。

### 2. Oracus AI（Second Place Overall，$7,000）

来源：https://devpost.com/software/oracus-ai（2026-08-27 实抓；单人项目）

**技术方案骨架**（5 步）：
1. 用户输入产品描述 + 营销素材；
2. Orchestrator 代理（Nova 2 Lite，Bedrock Converse API + JSON 约束输出）规划任务、guided SQL 查询用户画像库、分派专家代理；
3. 六代理分工：用户画像（调查数据→画像入库 Postgres）、市场分析、营销、产品经理、财务；
4. 画像匹配：Titan Embeddings G1 嵌入画像存 ChromaDB，按被测产品做相似性检索；
5. 专家代理 JSON 汇报 → synthesis 代理生成跨 14 项市场指标的预测报告 + 战略 playbook（<2 分钟）。

**亮点**：
- 技术创新：多智能体"专家面板辩论"替代真人焦点小组；关键工程洞见"给所有代理同一个数据库（画像库）而不是在代理间同步上下文"；Nova JSON mode 解决结构化输出可靠性；延迟从 6 分钟压到 2 分钟。
- Impact：直击焦点小组贵/慢/偏差痛点；已落地信号——demo 时 400+ 用户、$29/月付费档。
- 完成度：Next.js + FastAPI + Vercel 全栈上线并有付费档，非纯 demo。

**不足与可改进点**（核对维度：实验效度/规模/验证数据）：
- "AI 画像能预测真实市场反应"的核心效度未验证（无与真实焦点小组/历史数据的对照）；自述 Chain-of-Thought + 画像丰富度"解决"了真实性，属自评；
- 每次运行 ~10 画像/代理、6 分钟起步的原始数据未给出规模上限；画像库预计算的模式对临时细分市场查询支持弱；
- "20× 便宜"等对比数字为粗估，无测算过程。

**可迁移性**：
- "六专家代理 + 汇总代理"的评审面板模式可平移到任何"模拟人类评审团"类赛题（答辩预演、用户调研、内容评审）；
- JSON 约束输出直写数据库 + guided SQL 传上下文，是多代理数据一致性的低成本方案；
- "已有付费用户/注册数"这类落地信号在 Judging 的 Impact 维度上是强弹药，我方作品应预埋可展示的增长钩子。

### 4. Project Memoria: The Dementia Assistant（Best of Multimodal Understanding，$3,000）

来源：https://devpost.com/software/project-memoria-the-dementia-assistant（2026-08-27 实抓；单人项目）

**技术方案骨架**（5 步）：
1. 端上录音器全天捕获对话（Record），摄像头在检测到"新主体"（物品）时拍摄并嵌入；
2. Nova 2 Lite（Bedrock Converse API）分析对话流、识别"阶段"转换（自然话题切换）；
3. 仅对进入新阶段的片段做 LLM 重摘要、重复片段跳过——token 降约 85%；
4. 事实抽取入知识库，Nova 多模态嵌入 + ChromaDB 向量检索，MongoDB 存运营数据；
5. 四入口交互：Q（对话问答）、Record、Detect（物品定位）、Journal（AI 日记 + 情绪基调日历）；FastAPI 后端按 Strands 风格 agent-工具架构部署 AWS；成本 $0.0027/用户/天（约 350 条消息）。

**亮点**：
- 技术创新："对话阶段切分 + 增量重摘要"是记忆类应用的真实降本技术点（85% token 缩减）；物品照片用多模态嵌入挂到当前对话形成情景记忆；
- Impact：55M 患者基数 + "为患者保管记忆"的照护者替代叙事，社区价值维度强；
- 完成度：现场 demo 全流程（现场对话→上台准确回忆），物品检测 demo 零失误；给出单用户日成本核算。

**不足与可改进点**（核对维度：评测数据/隐私合规/工程成熟度）：
- 85% 缩减、$0.0027/天等关键数字均无测量过程（消息长度分布、召回质量对比缺失）；检索准确率/回忆正确率完全未测；
- 录音涉及患者及对话第三方（家人、医护）的知情同意与隐私，全文未处理；
- 录音 SDK 处于 dev 模式（生产 API 稳定性自认未解决）；Bedrock Guardrails 因免费档不可用降级为 prompt 工程护栏（自认脆弱）。

**可迁移性**：
- "阶段切分增量摘要"可直接用于我方任何长对话/记忆流赛题，是廉价高收益的 token 工程；
- $/用户/天的成本口径是 Impact+完成度的加分表达方式，值得套用；
- "被动捕获记忆 + 四入口查询"的 UX 拆分是记忆类应用的可复用信息架构。

### 5. Title AI（Best of UI Automation，$3,000）

来源：https://devpost.com/software/title-ai（2026-08-27 实抓）

**技术方案骨架**（从题目到成果 5 步）：
1. **Nova Reel 合成数据**：文生视频生成"用户操作县登记处网站"的短视频，CV 技术再把视频转成可执行的浏览器自动化指令——开发期不触碰真实目标网站；
2. **Nova 2 Lite 推理预算路由**：小模型前置分流用户查询（自述约 Nova Pro 1/7 成本）；
3. **Strands SDK 多代理**：OCR+空间几何模型、文档摘要器、3 个专职搜索代理、完备性校验代理、监督者；
4. **Nova Act + Act-SDK** 执行浏览器自动化；OCR 本身是用 Nova 模型按县登记文档版式微调的浏览器内 OCR；
5. **Nova 2 Sonic** 语音输出"无 PDF 的口头产权承诺摘要" + Bedrock Knowledge Bases 分层检索县登记细则；末端 human-in-the-loop 升级界面。

**亮点**：
- 技术创新：用视频生成模型造浏览器自动化训练数据（prompt-to-plan）是全名单里最反常规的 Nova 用法；"完备性校验代理"把多代理系统的收敛性问题显式建模；Nova 全家桶（Reel/2 Lite/Act/2 Sonic/KB/微调）覆盖面第一，正中 60% 技术权重里"Nova 集成度"；
- Impact：自称切入 $3.6T 房地产产权保险行业（title commitment 报告自动化），自述"首个可自主检索任意美国县登记处的平台"；给出人机协同产能数字（2.7x agent-augmented / 1.5x human-augmented）；
- 完成度：12 阶段管线叙述完整，覆盖水权检索、metes-and-bounds 复杂地块等难例。

**不足与可改进点**（核对维度：数字可验性/覆盖声明/合规责任/工程细节）：
- 关键数字全部自述：2.7x/1.5x 生产力、"1/7 成本"、测试集规模与构成均未给出可复现口径；
- "any US county" 为营销口径，实际覆盖县数未披露；
- OCR 微调（数据量/评测指标）细节缺失；
- 产权承诺是担责文书，错误的法律/准确率责任、语音摘要的可靠性验证完全未讨论——对落地是硬伤；
- 合成数据到真实网站的泛化差距未量化。

**可迁移性**：
- "视频生成→自动化指令"的合成数据思路适合一切"目标网站不可抓/不可碰"的场景（我方做 RPA/爬虫类赛题时的合规替代路径）；
- "路由小模型降本 + 完备性校验代理"两个组件可独立移植到任何多代理管线；
- Nova 全家桶的组合展示方式（每层都点名一个 Nova 能力）是应对"Nova 集成度"评审的直接模板。

### 6. flare（Best of Voice AI，$3,000）

来源：https://devpost.com/software/flare-gdyebn（2026-08-27 实抓，发布 2026-03-03；GitHub Vision-Stack20/Flare-CLI，2 人团队）

**技术方案骨架**（4 步）：
1. CloudWatch 日志异常检测；
2. Nova 生成根因分析（RCA）；
3. **打电话给 on-call 工程师**并播报 RCA（Nova Sonic SDK 语音）；
4. 保持在线做语音分诊助手，按需实时拉取线上基础设施数据。

工程侧：fork Nova Act SDK CLI（约 1000 行 TypeScript）改造成"会造工具的 agent"——用 NovaActClient 观察屏幕/键盘、act() 执行、rollBack() 自校验；工具自建循环为"创建一个 CPU 告警→验证出现→回滚→再排程"；异步栈 aiohttp/asyncio/aiofiles；uptime robot 监控。

**亮点**：
- 技术创新：把 Nova Act SDK 从"用工具"改造成"造工具"（自建-自验-回滚闭环，rollBack 自校验是真 agent 工程点）；"留在电话线上做分诊"把语音从单向播报升级为双向工作流；
- Impact：3 AM on-call 痛点叙事具体可信（创始人亲历），DevOps 受众共鸣强；
- 完成度：告警创建-验证-回滚闭环演示成功；GitHub 开源（Flare-CLI）；

### 7. SpatialMath AI（Best Student App，$3,000）

来源：https://devpost.com/software/spatialmath-ai（2026-08-27 实抓，发布 2026-02-28；4 人学生队 Shaan/Shravan/Soumya/Nithya，FBLA-100 战友，3 CS + 1 历史教育）

**技术方案骨架**（4 步）：

- "单次 JSON 约束输出驱动整个前端场景"的模式：把我方作品的 LLM 调用都收敛成 schema 化单次调用，成本低、可靠性高；
