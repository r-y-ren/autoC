# 2026年中国高校计算机大赛—大数据挑战赛（第十一届 C4-BDC）

以下正文全部基于 2026-08-27 实抓（来源编号对应 frontmatter `sources`；快照存于 `kb/raw/heywhale-c4-bigdata-2026/`：api-detail.json、2026-official-notice.pdf/.txt、agreement.pdf/.txt、tsinghua-bdc.html、tab0-8 各栏目 md）。

## 主办与定位

- 体系沿革：2016 年由教育部三个计算机类教指委与全国高等学校计算机教育研究会联合创办"中国高校计算机大赛"（C4），现由全国高等学校计算机教育研究会主办；"大数据挑战赛"为其模块之一，自 2018 年起入选"全国普通高校大学生竞赛榜单内竞赛项目，成为国内高校 A 类赛事，2026 年更被评为计算机类最高的五星级赛事"（来源[1][2][3]，三源文字一致）。
- 本届（第十一届，2026）：由清华大学、大数据系统软件国家工程研究中心主办（通知抬头称"联合承办"），上海和今信息科技有限公司提供竞赛平台支持（来源[1][2][3]）。
- 面向全球开放，不限年龄国籍；在校生（高职高专/本科/研究生）与科研机构、企业从业人员均可参赛（来源[1][2]）。
- 规模（平台 API 实测，2026-08-27）：5457 人报名、3393 支队伍、4052 次作品提交（来源[1][4]）。
- 官方渠道：大赛官网 https://nercbds.tsinghua.edu.cn/bdc.html ；竞赛平台 https://www.heywhale.com/u/2026BDC ；邮箱 data@tsinghua.edu.cn（来源[1][2]）。

## 赛题（本届主题：沪深 300 金融时序预测选股）

基于沪深 300 指数成分股的历史股价数据，建立机器学习模型预测未来一周收益最大的股票组合（不超过 5 只、累计占比不超过 1），按在线评测排名（来源[1][2][3]）。数据不限制格式/内容/范围，只需公开可免费下载；官方基准代码基于 baostock 数据，另与 Tushare 合作提供参赛专属免费数据权限（有效期至 2026-08-31，来源[1] 6-3 通知）。评测细节：A 阶段第 1 次提交因假期"T+5 直接复用 T+4 数据"（来源[1][2]）。

## 赛制与时间线

三阶段：报名&组队（3-26 至 7-15）→ 线上赛（3-26 至 8-2，A 阶段 3 次提交窗口 + B 阶段 1 次）→ 决赛（8 月中下旬，现场答辩）（来源[1][2]）。

- 组队：单人或 2-3 人/队，可有 1 名指导老师；每人限 1 队；全体队员须平台实名认证（来源[1][2]）。
- 在校生奖项资格：全队为中国在校学生且同校（指导老师亦须同校），以 2026-05-30 学籍为准、学信网验证（来源[1][2]）。
- 提交机制（4-29 变更通知后）：先提交 result.csv 按得分排名，靠前队伍再入围 Docker 提交（A 阶段每次前 20 名，B 阶段取各奖项名额上限的 120%）；Docker 改经平台专属入口上传（来源[1] 4-29 通知）。
- B 阶段代码复核与资格审核（8-10 通知）：初测成绩高于基线者提交 Docker + 学籍/教师凭证；收集范围扩大至初测前 490 支队伍，最终获奖从该 490 支中产生、不再顺延（来源[1]）。
- 晋级决赛规则：B 阶段通过代码审核的队伍中，在校生单独排名前 3 直接晋级，其余按 B 榜成绩前 3 晋级（来源[1][2]）。
- 决赛期间受邀选手食宿由组委会负责，其他费用自理（来源[1][2]）。

## 奖项（奖金池总额 5.48 万元，税前；获奖须成绩好于基准程序，空缺不补）

结构详见 frontmatter `award_levels`（来源[1] tab"晋级与奖项" + 来源[2] 规程，两源一致）。奖金核算交叉验证：决赛奖金 2+1+0.8+0.4×3=5.0 万 + 月月星上限 6×800=0.48 万 = 5.48 万，与"奖金池总额 5.48 万元"吻合；据此判断全国奖与赛区奖仅颁证书（规程表格无奖金列）。基准程序 GitHub：THU-BDC2026（来源[2]）。
