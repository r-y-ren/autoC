## 二、深构条目（每篇一节，四节必备）

### BioPhys-Bridge（赛道一·一等奖，个人队，完成人 徐*扬）

**材料等级：一手**。GitHub 仓库 qyxu1994/Biophys-Bridge（README、参赛技术报告 reports/technical_report.md、数据卡 data/release/data_card.md，快照 [2]，2026-08-28 实抓）+ HuggingFace 数据集 qyxu1994/BioPhys-Bridge（数据体所在，卡片页本网络未能直抓，存在性由仓库双链接与检索结果佐证——见缺口声明）。归因依据：作品名与名单完全一致，仓库引用字段作者 "Xu, Qingyang" 与脱敏名"徐*扬"吻合（[2] Citation 节）。

**解题/创作骨架**（[2] 技术报告 §6 十二步管线，代码型作品的技术方案主线）：

1. **候选池构建**：从 Europe PMC 等 OA 兼容元数据源建开放获取论文候选池（含 DOI/PMCID、许可、领域与模型家族猜测、量化关键词）。
2. **批量选择与 PDF 获取**：按领域×模型家族分布追踪选 100 篇/批的均衡解析批，PDF 下载不可覆盖、失败写 download_report.jsonl。
3. **MinerU 解析与规范化**：MinerU API（项目配置记为 v4/API 模式）批量解析，产出每文档 full.md+payload.json，再规范化为 document.md/document.json/evidence_blocks.jsonl/parse_metadata.json；source 字段保留 MinerU parse identifier（规则强制项"MinerU 使用方式"落于管线第 4-5 步与 §7 专节，mineru_artifact_coverage=1.0）。
4. **抽取与结构化**：regex-first 抽取 + evidence-only LLM 结构化（提示词强制：无证据字段返回 null，不得编造）。
5. **五重质量门**：Pydantic/JSON Schema 校验 → 内容质量门（拒绝模板残留/弱任务/断词）→ grounding 审计（每个量化值必须能在其引用证据块中找到）→ 确定性物理审计 → 发布导出（分层 split + gold 样本 + Sci-Evo 视图）。
6. **产出**：500 案例 JSONL（400/50/50 分层 split）+ 1517 个 agent 任务 + de-leaked 评测 harness + 双基线（lexical_retrieval_baseline 0.114 / gpt-4o-mini 0.229 overall）。release_finalized_at 2026-05-31，恰为提交截止日。

**亮点**（按赛道一评审五维归类，[2]；维度定义引 [5]=赛道一 API 实抓原文，见 meta）：

- **AI-Ready 与科学推理支持（30 分，最高权重）**：Schema 单一事实源（Pydantic 生成 JSON Schema、禁未知字段、跨字段不变量）+ stable evidence_id 引用完整性 + 四类 agent 任务（derivation 355 / mechanism_from_evidence 480 / next_experiment_design 403 / discrepancy_explanation 279）——直接对齐"能被主流大模型/智能体直接调用进行训练、微调或推理"的维度原文；并附可运行的评测 harness，基线分数入仓（README Benchmark Summary 表）。
- **科学表达与跨模态理解（20 分）**：每案例绑定 text/table/formula/figure-caption 证据块（计数 128601/1507/496/4987），3+ 模态案例占 80.4%、均值 2.944 模态/案例；Sci-Evo 轨迹七阶段（研究问题→假设→方法→量化观察→物理解释→失败/修正→下一步）正对该维度"模拟真实科学探索过程、含多步决策与推理链"的原文。
- **构建工程质量与可复现性（20 分）**：12 步可追溯/可恢复管线（各阶段写 runs/ checkpoint 与指标）、排除账对账（exclusion_counts_reconciled=true）、测试套件、依赖锁定（pyproject 可选组 [llm]/[hf]）、GitHub 不跟踪原始 PDF/MinerU 中间产物的轻仓设计。
- **科学价值与探索创新性（15 分）**："物理模型→生物机制"桥接范式显式类型化（bridge_type 六类，如 binding_thermodynamics_to_binding_mechanism）；107 案例（21.4%）显式含失败/修正阶段——把 Sci-Evo"允许失败与修正"的数据范式定义做成可数产物。
- **开放共享程度与生态影响力（15 分）**：代码 MIT + 数据 CC-BY-4.0（正中赛事推荐协议）；500 案例源许可 490 CC-BY-4.0 + 10 CC0-1.0，逐案例在 source.license 留痕；GitHub+HuggingFace 双发布；BibTeX 引用块。
- 另有评审工程化巧思：单设 contest gold（10）/extended gold（30）样本集与 test split 全量专家标注——为评审预置金标准。

**不足与可改进点**（核对维度：技术报告自报指标、领域均衡、评测强度、合规披露——均有 [2] 实据）：

- **物理一致性核验覆盖极窄**：physics_consistency_checked_rate=0.02（500 案例仅约 10 例运行了适用的闭式关系检查，pass rate 0.8）——"物理模型赋能"的核心卖点仅在小样本上做了确定性核验，属最明显短板。
- **专家标注覆盖 16.2%**（81/500，集中于 test split 与 gold 样本；train 400 案例无专家物理/生物复核层）。
- **基线单薄**：真模型仅 gpt-4o-mini 一档、154 任务；无更强/开源模型对照，说服力有限。
