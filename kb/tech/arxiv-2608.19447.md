# EventTime：多尺度对比学习量化事件对时序的冲击

## 是什么

Sun Yiming、Chen Shengyu、Chen Zhengzhang、Chen Haifeng 等（2026-08-19 提交 arXiv，cs.LG）提出的 **EventTime**：多分辨率框架，融合长时域市场上下文、短时域事件前动态与事件元数据，含事件融合模块（把时间表征与事件属性关联、唤起相关近期市场模式）；训练用动态对比目标，按事件与序列构造正负样本对以对抗稀疏监督。同时发布 **SECURE** 数据集：网络安全事件与股票市场序列配对，附结构化与 LLM 衍生语义特征。

## 解决什么问题

网络级冲击（如网络安全 breach 披露）会突发打断金融时序并造成异常损失；事件以离散记录（新闻/监管文件/公开库）披露，后果却在连续市场动态中展开——形成"事件条件化影响预测"问题：用事件前历史+有限元数据估计披露后短期异常损失。常规预测模型依赖趋势/季节性等内生模式，对稀疏、异质的外部事件无能为力，高影响样本稀少+市场噪声加剧了学习难度。

## 相比前方法优势（论文自报）

- 多分辨率建模（长上下文+短程事件前动态+元数据）优于 SOTA 时序与事件感知基线；
- 对比目标产生更事件敏感的表征，对不完整元数据更鲁棒；
- 短期影响估计更具可解释性；
- 附带真实场景数据集 SECURE（含 LLM 衍生语义特征）。

## 如何用于比赛

1. **数模-事件影响评估题主用**：冲击类题目（疫情/政策/舆情对指标影响）把问题形式化为"事件条件化影响预测"：事件前多尺度特征 + 事件属性编码 → 影响量级回归；对比损失专治"大事件样本极少"的数据痛点，这是常规事件哑变量方法没有的武器。
2. **黑客松跨域 demo**：题材=网络安全事件的市场冲击预警；LLM 衍生事件语义特征的用法（从非结构化披露文本抽事件向量）本身可独立复用为任何文本-时序融合方案的参考。
3. **方法论移植**：事件/序列双感知的正负样本构造策略可平移到任何"稀疏标注+外部冲击"场景（设备故障、断供、极端天气）。
