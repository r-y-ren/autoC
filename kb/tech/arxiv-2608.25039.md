# LifePlanner：融合社媒信号的地理空间规划 LLM 智能体基准

> 来源：https://arxiv.org/abs/2608.25039 （arXiv v1 提交于 2026-08-25，cs.AI，comments: 25 pages, 7 figures, 11 tables；抓取日期 2026-08-28）

## 是什么

arXiv 2608.25039（Dong、Peng、Shi 等）提出 **LifePlanner** 基准：把地图数据与大规模本地社交媒体帖子融合，通过 **MCP 工具集**暴露给被测 LLM 智能体，评测套件覆盖 **4 个任务类别 × 3 档难度**（以下描述均来自本次抓取的摘要页）：

- 动机：行程设计等地理空间规划要求 grounded 工具使用、含噪证据检索与多约束推理，而现有基准只提供干净的地理数据与工具，缺少人们日常规划真正依赖的开放社媒信号；
- 结果：前沿 LLM 在简单检索上表现良好，但复杂规划通过率跌至 **40.2%**；
- 失败分析把错误主要归因于**大型多模态库中证据获取不完整**、工具使用不精确、约束整合薄弱——而非模型规模或推理长度，意味着进步来自更好的 grounded planning 而非单纯 scaling。

## 解决什么问题

LLM 智能体评测与真实规划场景之间的鸿沟：干净数据 + 干净工具的基准高估了 agent 在"信号开放、噪声真实、约束交织"的日常规划任务上的能力，也定位不出到底错在哪个环节。

## 相比前方法优势

- 首批把**本地社媒信号**作为一等证据源纳入地理空间规划基准（地图之外引入人们实际参考的口碑/现场信息）；
- 评测按任务类别 × 难度分级，能定位能力坍缩点（简单检索 vs 复杂规划）；
- 失败归因分析给出可操作的改进清单（证据获取 / 工具精度 / 约束整合），且排除了"堆规模即可解决"的侥幸路径。

## 局限

- **无代码与数据集发布链接**（arXiv 页 comments 仅页数图表信息，runnable=false），benchmark 全量复现成本高；
- 社媒数据在比赛/作品语境存在可得性与合规约束——复用时需替换为公开 API 或开放数据源，与原基准设置不再严格对齐；
- 40.2% 等数字为作者自报实验结果（v1 预印本），未见同行评审信号。

## 如何用于比赛（比赛映射展开）

- **适用赛种**：黑客松数据与算法题，尤其是文旅、城市服务、本地生活赛道（行程/路线/活动规划是高频题型）。
- **打法（失败模式即路线图）**：作品按论文的三类失败模式逐项对策——(a) 证据获取不全 → 分层检索 + 按地理/时间范围预过滤的 MCP 工具设计；(b) 工具使用不精确 → 参数校验与工具描述收紧；(c) 约束整合弱 → 把用户约束显式结构化后再进规划器。每项对策配上前后对比的小评测，形成"针对已知失败模式的消融"叙事。
- **自建评测**：按 4 任务 × 3 难度的框架自构 20-50 条测试用例（公开 POI + 公开点评数据），即可低成本复用其评测方法论而不必复现整个基准。
- **成本**：地图 API + 社媒开放数据 + MCP 工具封装为中等工程量（reuse_cost=中）；无需训练，纯推理侧组装，适合 48-72 小时赛程。
