# CTRL：把 LLM 从"预测器"降级为"控制器"的时序预测闭环

> 来源：https://arxiv.org/abs/2609.23257 （arXiv abs 页实抓，抓取日期 2026-09-22；v1 提交于 2026-09-20，cs.LG/cs.CL，一作 Minkyoung Kim。以下分析基于本次抓取的摘要与 Comments 原文）

## 是什么

面向非平稳时序预测的 LLM 混合框架（摘要口径），核心是**解耦语义推理与定量预测**：

- **冻结底模出基线预测**：定量预测交给冻结的数值预测骨干，LLM 不直接生成数字；
- **LLM agent 作控制器**：专门的 LLM agent 分析预测误差——按趋势/季节/不规则三分量分解后读入，输出**紧凑控制信号**（control signals）；
- **轻量残差解码器**：把控制信号转换成对基线预测的修正量；
- **免标签测试时自适应（TTA）**：仅凭输入统计量检测分布漂移并触发适配，不需要标签、不需要重训；
- **成本**：摘要自述每次预测 3-24 次 LLM 调用，经缓存机制压到这个量级。

发表：ACL 2026 Findings（论文自述，18 页 9 图 22 表）。

## 解决什么问题

现有 LLM 时序预测两条路线各有失败模式（摘要口径）：把 LLM 降为数值预测器，浪费了它的推理与语义理解强项；让 LLM 直接生成预测，在非平稳设定下预测失稳。CTRL 的主张是第三条路：LLM 的角色是**控制器**——只决定"修正什么、修多少"，不定量生成；基线预测的数值责任留在专门模型上，非平稳鲁棒性由控制回路与 TTA 承担。

## 相比前方法优势

- **角色分工**：LLM 只做定性控制不做定量生成，兼得推理能力与数值稳定性（对照两条现有路线的失败模式设计）；
- **免标签 TTA**：分布漂移检测只依赖输入统计量，无需漂移后标签——赛场真实场景（赛期新数据无标签）恰好匹配；
- **成本可控**：3-24 次 LLM 调用/预测（缓存），不是逐时间步调 LLM 的烧钱架构；
- **平稳场景不丢分**：摘要自述在平稳序列上保持 competitive——适配机制不会在正常场景拖累基线。

## 局限

- **无官方开源实现**：abs 页无代码链接，GitHub 检索 0 命中（2026-09-22 实抓），runnable=false；全部指标为作者自报，摘要未列基准与基线名单、未给出对比数字；
- "紧凑控制信号"的具体协议（信号维度、离散/连续、控制器提示词设计）在摘要层不可见，模式自建时这部分全靠自行设计，是复现的最大不确定点；
- 需 LLM API：赛期离线环境或 API 预算受限时不可用（3-24 次/点的调用量在长序列滚动预测下会累积）；
- **库内定位**（LLM×时序族去重）：CEDAR（arxiv-2608.25871）是"底模残差+LLM 辅助事件文本匹配修正"，修的是**外生事件偏差**；本卡修的是**分解误差+分布漂移**，且多了 TTA 闭环，占位不同；Compositional Spectral Prompts（arxiv-2609.02093）是提示词构造路线；MetaCaster（arxiv-2608.23473）是训练轻量预测器的 agent harness。本卡占"LLM 只做控制器+免标签 TTA"位。

## 如何用于比赛（比赛映射展开）

- **适用赛种**：数模-预测与评估（含政策/事件/极端年份等非平稳因素的预测题）。
- **打法**：
  (a) **闭环修正叙事**：底模用赛内验证过的轻量预测器（DLinear/PatchTST 类），STL 分解误差后让 LLM 输出结构化控制信号（如 JSON：趋势修正方向/幅度档位、季节相位偏移、是否触发漂移警报），小 MLP 头把信号映射为残差修正——每一层都可解释可画图，论文可引 CTRL 为模式出处；
  (b) **TTA 作为鲁棒性章节**：用输入统计量（均值/方差漂移检测）做免标签适配触发，写进模型的鲁棒性设计与误差讨论，是多数队伍不会覆盖的加分点；
  (c) **成本论证**：3-24 次调用/点的口径可直接引用，回应评委"LLM 上时序是不是又贵又慢"的质疑。
- **成本**：reuse_cost=中——无代码需按模式自建，但组件（STL、控制信号协议、残差头）都不重，主要工程量在 LLM 调用编排与提示调优；先在历史数据的"模拟漂移段"预演确认增益再上线。
