# Mimir：让 LLM agent 管灌溉——物理知识不可变，学会修复的只有 agent

> 来源：https://arxiv.org/abs/2610.02038 （v1 2026-10-01，cs.AI；abs 页无 Comments、无代码链接；抓取日期 2026-10-03。本卡内容出自本次抓取的 arXiv 摘要页。）

## 是什么

arXiv 2610.02038（Yimeng Liu、Mi Zhang、Younsuk Dong、Zhichao Cao）把 LLM agent 放进**长程物理控制**场景——灌溉：动作改变未来状态、误差跨决策复利、且 agent 必须从经验改进却不许改写物理知识。与摘要任务（即时反馈、失败可重置）不同 regime，Mimir 的方案是**两个修复时间尺度**：

- **快回路**：结构化物理接口 + 确定性模拟器——每个动作提案先经前向模拟检查、修订后才执行；
- **慢回路**：把反复出现的失败模式固化为**持久化原则**（persistent principles）供后续决策引用，而物理模型本身保持不可变。

效果（摘要自报）：在所评估参照中聚合控制成本最低；比历史灌溉调度回放**省水约 51%**。消融：去掉前向模拟、校验修订或持久化上下文任一组件成本都上升；更大的 LLM **没有单调增益**。

## 解决什么问题

LLM agent 的能力证据几乎都来自可重置的情节式任务；长程物理控制里"试错"有真实代价且不可回滚。Mimir 回答的问题是：如何让 agent 在不污染领域知识（物理模型）的前提下，把运行经验变成可控精度的改进——把"可学习性"从模型层挪到 agent 层的原则沉淀。

## 相比前方法优势

- 架构分工清晰：物理模型负责"对"，agent 只负责"修自己的行为"——避免了让 LLM 微调/改写领域模型带来的幻觉固化和不可审计；
- 快回路的"执行前模拟校验"把错误拦截在造成代价之前，慢回路的失败原则沉淀提供无梯度、可人工审计的经验积累通道；
- "大模型无单调增益"的结论对成本敏感场景（边缘部署、按 token 计费）是实用利好：小模型+好回路即可；
- 库内无同族卡：kb/tech 现有农业相关卡均为 UAV/通信优化类（alam2024、han2024 等），无"LLM agent+物理控制"卡，本卡是空位。

## 局限

- **无开源实现**：abs 页无 Comments、无代码链接（2026-10-03 实抓），复现需自建灌溉物理模拟器与整套回路，成本高；
- 结果为作者自报预印本，"最低成本"是相对"所评估参照"的措辞，非绝对 SOTA 主张；
- 单一领域（灌溉）单一模拟环境，跨域迁移（能源/调度）只是架构推断，论文未验证；
- 摘要未披露真实田间部署数据，落地差距未知。
