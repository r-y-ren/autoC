# 检索增强的环境义务分类：头尾混合多标签架构

## 是什么

Yoon, Ruggles, Lee, Singh（2026-08-24 提交 arXiv，cs.IR/cs.AI，美国 FERC 水电许可文书场景）把"识别环境缓解义务"形式化为 **135 类结构化分类法上的多标签分类**。核心挑战是标签极度稀缺：40/135 类零训练样本、26 类不足 5 个样本。论文发现监督 BERT 管线在常见类表现好，但**无论何种数据增强策略，未见类的 F1 恒为 0**；于是提出以检索到的类定义（category definitions）为条件的 RAG 分类管线，实现全标签空间零样本泛化；再加混合管线 = 微调 BERT 检测（高召回）+ RAG 分类（零样本覆盖）。在全量 2017 份许可文书（5,860 段、135 类）上：混合 Micro F1 0.524 > BERT-only 0.477 > RAG-only 0.416，且在各训练支持桶一致占优。

## 解决什么问题

长尾/零样本标签场景下的多标签文档分类：监督模型对训练时没见过的类完全没有泛化能力，纯零样本分类器精度又不够——两各自的长处互补。

## 相比前方法优势

- 干净的三方消融（0.477 / 0.416 / 0.524）证明混合架构不是拼凑，在全部训练支持桶上一致占优；
- 核心机制是 prompt 级的（把检索到的标签定义放进上下文），无需训练新模型即可复现；
- 真实监管语料 + 真实 135 类分类法，非合成基准。

## 局限（如实标注）

- **无官方代码**：arXiv 页无 Comments、无仓库链接（2026-08-28 抓取确认），runnable 无法核实——复现需自建"嵌入检索 + 类定义 prompt"管线；
- 绝对 F1 0.524 属温和水平，非任务上限声明；单领域（水电许可文书）验证；
- FERC 文书数据的授权与再分发条款未在摘要页说明，赛场复用数据需自查合规；
- maturity: paper。

## 如何用于比赛

1. **Kaggle-竞赛（主用）**：长尾标签 NLP 赛题（罕见类、测试集含新类）的即用打法：监督模型管头类，检索"标签定义 + 少量近邻样本"作上下文让 LLM 零样本管尾类/未见类，分数层合并；论文已量化"增强无法救未见类"——赛场直接跳过增广救尾类的弯路。
2. **黑客松-数据与算法**：政策/监管文书智能审阅原型（环保合规审查、ESG 披露抽取、招投标条款审核）：领域故事 + 混合架构 + 真实分类法叙事完整，工程上是 API 检索 + LLM 组装，短周期可出 demo。
3. 风险控制：头/尾分数融合阈值需在自有验证集上调；零样本分类器对标签定义文本质量敏感，赛场上值得为标签定义做一轮 prompt 打磨。
