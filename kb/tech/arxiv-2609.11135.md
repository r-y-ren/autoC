# SolCloudLLM：天空图像×时序双向融合的 LLM 光伏/辐照度短临预测

> 来源：https://arxiv.org/abs/2609.11135 （arXiv 摘要页实抓，抓取日期 2026-09-16；v1 2026-09-10，作者 Ken Chen、Maneesha Perera、Wei Wang、Sachith Seneviratne、Hansani Weeratunge、Saman Halgamuge；以下分析均基于本次抓取的摘要页内容）

## 是什么

面向短临（short-term）**光伏（PV）功率与水平面总辐照度（GHI）预测**的 LLM 多模态融合框架 **SolCloudLLM**（摘要口径）：

- 天空图像 patch 与时序 patch 对齐 → **双向多模态融合**（bidirectional multimodal fusion）构建统一表示 → 映射进 LLM 嵌入空间完成预测；
- 在 **SIRTA 与 SKIPP'D** 两个数据集上评测：全预测时域 MSE 一致优于最强基线，**最大相对 MSE 降幅 25.4%**（作者自报）；
- 增益集中在**多云条件**——该时域误差由云致 ramp（cloud-induced ramps）主导；**少样本设定下几乎全部最优**，而其他深度基线在少样本下退化到有时输给非学习的物理方法。

## 解决什么问题

短临光伏预测的误差由云团过境 ramp 主导——纯数值历史序列"看不见"正在逼近的云；地基天空图像是关键互补物理信号，但站点历史数据稀缺（少样本）时现有深度方法又撑不起来。摘要立论：依赖纯数值历史数据难以预期 incoming cloud。

## 相比前方法优势

- **双向融合而非单向拼接**：图像信息流入时序表示、时序上下文亦反哺图像特征（框架主张，摘要口径 bidirectional）；
- **少样本优势恰好命中赛题约束**：比赛数据少、外推远，多数深度基线此时反不如物理方法，本方法在该设定下几乎全最优；
- **增益归因清晰**：集中在多云/ramp 条件，即误差代价最高的场景，而非全时域均匀的边际改进。

## 局限

- **无代码**（摘要页无链接，2026-09-16 实核）：LLM 骨干 + 图像编码 + 双向融合模块全需自建，赛期 3-4 天内复现压力大；
- **数据前提**：需要天空图像流——多数赛题不直接提供；卫星云图公开但需自行对齐时空分辨率（SKIPP'D 数据集有第三方公开使用记录，2026-09-16 GitHub 搜索实核；SIRTA 获取性需赛队自查）；
- 数字为**作者自报**：仅 2 个数据集、"25.4%"为最大值口径；晴天/少云条件下相对物理基线的优势幅度摘要未披露；
- LLM 推理开销与赛期算力约束摘要未报，需读正文评估。

## 如何用于比赛（比赛映射展开）

- **适用赛种**：数模-预测与评估（光伏功率/辐照度/风光新能源预测是电工杯、研赛、国赛能源题高频题型）；带气象图像辅助数据的 Kaggle 能源赛同型。
- **打法**：
  (a) **有图像流时的结构性差异**：绝大多数参赛队只做数值时序，"天空图像+时序融合"是论文级差异化叙事；即便不做双向融合，"云图特征 × 数值特征"的简单融合对照也足以撑起消融一章；
  (b) **少样本协议照搬**：按其 few-shot 评测设定把自家方法、naive 物理法、深度基线在多档数据比例各跑一遍——"小数据下深度基线输给物理法、我们的方法保持最优"这张表是答辩利器；
  (c) **纯数值题借论据**：无图像数据的光伏题可引其"云致 ramp 误差主导"结论，为引入外部气象特征（云量/辐照度预报）提供正当性。
- **成本**：reuse_cost=高——无代码、LLM 骨干 + 多模态对齐需自建，且依赖赛题提供或可获取的图像数据流；仅建议作为有图像数据赛题的差异化主攻或无图像赛题的叙事论据。
