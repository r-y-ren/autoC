## 选型结论

以下结论仅由上述 24 张库内卡片支撑，按赛题形态给出。

### 按赛题形态选型

- **不规则时间戳采样（医疗随访、稀疏传感、丢包监测流）** → D 组配对：DNBNet（2608.17284，预测端，官方代码可直接 clone）+ CSE 指标（2608.17293，评估端，加权 MSE 一行级改写）。同一重要性采样思想贯穿"预测+评估"即是完整方法论叙事。
- **概率区间/CRPS/分位数计分** → DecoVAE（2608.20052，轻量可解释主力，CPU 可跑）或 CLaST（2608.20025，对比正则叠加在自有生成管线上）；输出端一律再套 SPACE（2608.17333）共形椭球校准，把"经验分位"升级为"有限样本覆盖率保证"。评估走"点误差+覆盖率+CRPS"三层。
- **节假日/促销/政策突变类销量与负荷题** → ReasonCast（2608.15291）的结构化事件字段+选择性门控与 CEDAR（2608.25871）的"基础预测器+残差事件修正层"叠用（卡片互引支持）；题目附新闻/报告文本 → SCENARIODIFF（2608.17164）三级智能体流水线（先快照匿名仓库）；题问"事件影响多大" → EventTime（2608.19447）的事件条件化影响预测+对比损失。
- **电价/供热/电表等能源题** → Chronos-2 零样本基线按 MSMI 思路组织协变量（2608.11359）+ TabPFN-TS 起点配置"小时级+24h+12 周+气温"（2608.20024）；多市场/多机组且评排序时加 14106 的横截面检查。
- **弱可预测目标或排序/相关性 metric** → 2608.14106：先诊断预测坍缩（预测近平坦+横截面离散），损失中加权校准项与横截面相关项，全程监控幅度防膨胀。
- **"要不要引入外部变量"是分歧点的题** → 2608.25128 两前置检查（末值捷径 ρ_h、信息增量 δ）事前止损；不满足就把精力还给特征工程与残差修正。
- **相似日/类比检索类题** → 2608.23221 未来监督重排，但必须朴素末值锚定/相似日/重排三方 A/B 择优（论文自陈简单规则常胜）。
- **评审重视可解释性的题** → 按需求选层：建模层 Fuzzy-MoE（2608.20761，regime 路由透明化）、表征层 ConceptTS（2608.21277，概念瓶颈+干预做灵敏度分析）、事后层 NVExplain（2608.25080，lag-horizon 归因热力图填误差分析节）。
- **算力受限/宽变量** → AsyTO（2608.16098）自实现作主力，但先与 DLinear/TiDE 同台对比。
- **超短历史（十几个点）** → MetaCaster 内核（2608.23473）：LLM 按题面领域知识合成伪历史+轻量模型，三方对照防合成偏差。
- **"模型怎么选"论证** → LiveHouse-TS 滚动前验协议（2608.17299）+ 智能电表基准的轻量选型证据（2608.18675）+ TRACE-CASH 的"搜索过程即证据"叙事（2608.16410，降级为 Optuna 实现）。

### 组合打法

1. **事件驱动销量题全家桶**（促销/节假日题）：2608.25128 事前诊断确认事件信息增量 → DLinear 级轻量基线（引 2608.18675 支撑选型）→ ReasonCast 结构化事件特征+选择性门控 → CEDAR 式残差事件修正层专攻突变日 → 评估按 LiveHouse-TS（2608.17299）分时间窗滚动报告。逻辑链：每一步都有库内卡片的实证或方法论背书，突变日处理是拉开名次的分水岭（CEDAR 卡结论）。
2. **不规则采样题"预测+评估+区间"三件套**：DNBNet 主力（17284）+ CSE/MSE 双排名并列报告（17293）+ 题面要求区间时叠 SPACE 校准（17333）。三张卡复用成本均为低-中，互不冲突且故事线自洽。
3. **能源题"零样本+归因"双引擎**：Chronos-2 零样本+MSMI 协变量（11359）与 TabPFN-TS 起点配置（20024）双基线对照 → 有排序诉求加 CalibRank 诊断（14106）→ NVExplain lag-horizon 归因热力图（25080）写"模型检验/误差分析"节。零样本为主降低工期风险，归因图提供答辩差异。

### 不推荐场景

- **规则均匀采样数据上强推"去偏"**：DNBNet 与 CSE 的收益集中在真不规则场景，规则采样上退化为常规口径（两卡局限原话）——但 CSE 作为低成本评估自觉并列报告仍可保留。
- **纯点预测 MAE 计分的赛题押注概率建模**：DecoVAE/CLaST 的概率优势在点误差口径下打折（20052 卡明示）。
- **稳定无事件序列上无差别堆文本/语义特征**：ReasonCast 实测无差别干预使稳定期 WMAPE 恶化 1.68pp——事件修正必须带门控，只在事件窗/高不确定性序列启用。
- **高信噪比目标强套排序损失**：CalibRank 现象主体在金融收益类弱可预测目标上演示，负荷/销量类未必触发；且直优化相关性有幅度膨胀超一个量级的翻车风险。
- **δ≈0 或末值捷径主导时上多模态/外部变量**：2608.25128 的分布无关不可能性结论——此时任何融合机制都无增益，投入即浪费。
- **3-4 天赛期内完整复刻无代码重系统**：CEDAR、MetaCaster、TRACE-CASH、SCENARIODIFF 全系统均属高成本（无代码/栈重），一律取最小可行版或降级实现。
- **纯精度导向题用 ConceptTS 概念瓶颈**："competitive"=对标非超越，概念瓶颈精度税需在题目上实测。
- **论文里声称复现了无代码论文本身**（TRACE-CASH 等多卡明示）：只能如实写"受其启发的设计"。
