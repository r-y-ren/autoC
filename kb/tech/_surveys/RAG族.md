## 选型结论

### A. 评测口径决策树（先于一切 RAG 作品的答辩准备）

1. **默认起点（任何 RAG 作品，半天内可落地）**：arxiv-2608.26385 的 canary 集 + 非对称评分。理由：族内唯一"开源完整 + 无训练 + 领域无关"的口径，把准确率同质化对比变成 canary 违规率对比，且自带失败归因。
2. **需要讲清"错在哪一层"**：叠 arxiv-2608.24753（RAT）的条件分解 P(R)·P(A|R)·P(T|A,R)；标注预算紧张时用其"judge 当噪声观测"融合方案，并按其结论优先标"检索成功"而非"任务成功"。
3. **评委/自检质疑"证据真被用了吗"**：用 arxiv-2608.23252 的 LOO 探针（长文档集按题抽样）；同卡分配律顺带把预算从"一次堆宽上下文"改为"窄上下文×多次迭代"（+16.7~20.5pp 论文口径背书）。
4. **防御型作品的评测维度**：直接查 arxiv-2608.24977 的威胁模型三层（corpus/retriever/generator）与其基准菜单，不自造 taxonomy。
5. **组合与裁剪**：canary（弃权激励）+ RAT（层归因）+ LOO（利用率）构成三层评测栈；赛期按预算裁剪，**最低配 = canary**（成本低、差异化最直观）。三卡口径互相印证：canary 的弃权激励与 22634 的选择性回答、24753 的弃答建模在"该弃权时弃权"上一致。

### B. 防御选型决策树

1. **第一步永远是 arxiv-2608.24977**：定威胁模型（打什么目标、防在哪一层），这决定后面选哪张卡。
2. 威胁 = 语料投毒 → arxiv-2608.23965 思路自实现（免训练/免标签/黑盒，代理编码器用现成句子编码器替）；主打"可认证恢复"叙事；动手前自验诚实多数与表征分离两前提。
3. 威胁 = 跨层级/跨区域外推错误 → arxiv-2608.22634 层级感知检索 + 选择性回答；**客观题评分制先按赛规调拒答阈值再上**。
4. 评审明确加分的隐私项 → arxiv-2608.25735 的短清单思想 + DP 叙事引用；不做全套密码学（见不推荐清单）。
5. 架构侧随题面形态选型（与防御层正交）：长视频 23011 / 长叙事长文档 25486 / 图域冷启动 25123 / 语料获取入口 oc / 人群规则问答 26604 / 长尾多标签分类 23241。

### C. 不推荐清单

1. **不推荐复现 arxiv-2608.25735 全套密码学管线**：reuse_cost=高、无公开实现、约 10% 开销系 10Gbps 链路实测（赛场更差）——只取叙事层 + 粗排原型，赛前明确 demo 边界。
2. **不推荐把 arxiv-2608.26385 的商用系统数字（97-98%、16.7% vs 98.1%）当自家预期值**：厂商自评利益相关、英文事实问答单基准、评测对象为商用产品——取框架不取数字（铁律 4）。
3. **不推荐依赖 arxiv-2608.24753 官方仓开箱即用**：抓取日实核为 Under construction 占位（1 commit、0 stars、无 License）。
4. **不推荐把"宁可拒答"（26385 弃权激励 / 22634 选择性回答）直接搬进"不答与答错同责"的客观题赛制**：拒答即丢分，双刃剑。
5. **不推荐引用 arxiv-2608.25123 作为"已验证方法"**：在投 M.S. 论文、代码 email 索取未实测——冷启动思路可用，背书不可用。
6. **不推荐在长文档集上全量跑 arxiv-2608.23252 的 LOO 探针**：成本随文档数线性放大（每查询 k+1 次前传）——按题抽样。
7. **不推荐 arxiv-2608.23011 用于高信息密度视频或非 QA 任务**：合并收益假设未在此类素材验证——赛前用题面数据验证冗余假设。
8. **不推荐把 arxiv-2608.26604 的画像维度照搬到非规则类语料**：其 schema 绑定单机构规则文档结构，迁移需重建。
