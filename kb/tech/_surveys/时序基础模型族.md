## 选型结论（TSFM 押注前的低成本体检流程）

三卡收敛于同一立场：**TSFM 是任务依赖的部署选项，押注前必须体检**（22968 给"何时值"的先验，24303 给"怎么验"的协议，24033 给"分类任务免费试"的选项）。体检流程五步，全部无需训练：

1. **任务形态分流（22968 先验）**：退化预测/异常检测类题 → 默认轻量方案（TCN-AE/OCSVM 级），TSFM 不进主方案；预测残差诊断类 → TSFM 可试；时序分类且标签稀缺 → 进第 4 步试 ChorusTIC。
2. **模式体检（24303 协议）**：列出赛题数据的关键模式清单（趋势/谐波/体制转换/能量释放等），对每个模式构造参数化合成生成器，对候选 TSFM（Chronos-2/TimesFM-2.5）做单因子干预，测零样本输出的模式保真度；命中已知失效先验（持续性高估/体制转换突变失效）→ 该模式所在赛题慎押，或预置兜底模型并在论文中引用失效清单作选型依据。
3. **成本计量（22968 协议）**：候选模型跑时延/峰值 VRAM/state-dict 尺寸，与精度并列进对比表——赛场算力与演示时延约束下的硬指标。
4. **基线对照（22968 协议 + 24033）**：out-of-fold + 配对 bootstrap CI 的轻量基线对照；分类题加跑 ChorusTIC 零训练基线（动手前先处理其无 license 风险）；TSFM 只有显著优于轻量基线才进主方案，否则降级为集成成员/残差建模，或仅作对照章节素材。
5. **押注判据（三条件同时成立才押）**：(a) 体检未命中失效先验；(b) 成本计量可承受；(c) OOF+CI 显著优于轻量基线。任一不成立 → TSFM 退出主方案。

**组合打法**：数模论文的"模型选型论证"章节 = 24303 体检协议 + 22968 三件套协议（精度/统计/成本并列）+ 24033 防泄漏 ICL 评测（分类题）。三个协议合计成本约等于两次推理 API 扫描 + 一次自建合成器，是赛场可承受的最低体检配置。

**不推荐**：
- 不推荐把 TSFM 当轻量拟合模型的默认替代（22968：退化/异常任务轻量全面占优且更省——时延/VRAM/state-dict 全维度）。
- 不推荐只报基准总分引用 22968/24303 的结论（须保留"任务依赖"限定，防断章——BDG2 上 TimesFM 有占优设定）。
- 不推荐在 license 缺失状态下把 24033 的 checkpoints 直接进作品分发链路。
- 不推荐以"合成体检通过"替代真实数据的 out-of-fold 验证（24303 生态效度局限）。
