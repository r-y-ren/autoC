# RATL：检索历史预测残差做鲁棒多变量时序预测的即插即用修正层

## 是什么

He 等 5 人（2026-09-03 提交 arXiv:2609.03937，cs.LG+cs.AI）提出的 plug-in 残差检索与反馈修正方法（摘要页+API 元数据 2026-09-04 实抓）：冻结任意基座预测器，以其历史预测残差构建 train-only 检索记忆；推理时在因果可用性约束下检索相似历史上下文的残差轨迹，由 set-aware router 在预测块（forecast block）与变量两级上选择组合；再用改进模块把检索结果转成对冻结基座的误差修正信号。主实验以 iTransformer 为冻结基座，测试了跨基座迁移性。**无代码、无 venue（Comments 为空），runnable=false**。

## 解决什么问题

RAG 式"检索外部证据补参数模型"直接搬到连续回归会不鲁棒——检索到的目标值在量级、尺度、局部动态上不可比；而常规预测管线把残差只用于模型优化与误差诊断，从不把个体历史残差样本留作推理期可访问的记忆。RATL 把检索对象从"历史目标值"换成"基座模型自身的历史预测误差"，规避量级/尺度失配。

## 相比前方法优势（论文实证结论）

- 在多数实验设置下提升冻结基座预测器（论文原话 most settings，非全部）；历史残差与当前上下文匹配时含可复用的预测信息；
- 消融：学习型路由强于裸残差反馈；基于验证集的修正强度选择能限制残差过注入；
- 改进模块跨基座可迁移（测试了多基座），对不完美检索有一定鲁棒性。

## 局限（如实标注）

- **无开源实现**（arXiv 页与 API 元数据均无代码链接，2026-09-04 实抓），复现需从零实现检索记忆、因果约束与路由器，成本高；
- 提升是"多数设置"而非一致显著，无 venue（预印本），结论未经同行评审；
- 基座专用记忆：换基座需重建记忆；预印本基座主用 iTransformer，对传统统计/GBDT 赛道基线的适配未验证。

## 如何用于比赛

1. **分布漂移预测题的修正层（数模-预测与评估，主用）**：训练段规律在评测段走样时，冻结已训好的模型，用训练期残差建 kNN 记忆，推理时检索相似历史窗口的残差加权修正——免重训、只用历史信息，作为论文方法论落地为简化版（检索 + 线性融合 + 验证集调修正强度）；
2. **Kaggle/数据竞赛的残差记忆修正**：强基线之上逐块/逐变量修正，与 blend 正交可叠加；为每个基座单独建记忆；
3. **答卷叙事**：把"误差诊断"升级为"误差记忆复用"，配合因果可用性约束论证评测合规性。
