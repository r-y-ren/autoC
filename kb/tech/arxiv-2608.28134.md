# AdaRDiff：把经典差分变成可学习、可逆、可并发的即插即用模块

> 来源：https://arxiv.org/abs/2608.28134 （arXiv export API 实抓，抓取日期 2026-09-20。以下分析基于本次抓取的摘要原文；未发现代码发布）

## 是什么

把经典差分（减去邻近历史值以去除趋势/季节结构）改造为**可学习算子**：AdaRDiff 用可学习权重对历史时刻做加权差分，得到平稳化残差序列供预测模型使用，再用自回归方式把剥离的成分还原回去重建预测——单一算子联合捕获趋势与季节。重建 admits 闭式卷积表达，可在 GPU 上并行（较朴素递归实现至多 33.7 倍加速）。训练用两阶段调度（先时间结构发现、后重建学习），依据是对线性预测模型的梯度理论分析。八个跨电力/天气/交通/能源基准上取得摘要口径 SOTA；参数开销可忽略；作为即插即用模块集成到八个多样化骨干（线性模型到 Transformer）中的大多数上带来提升，线性骨干至多 +25.9%、iTransformer +18.3%。

## 解决什么问题

差分是处理非平稳时序的经典手段，但依赖手选阶数与周期，因此在近年的深度预测架构里基本缺席——模型被迫在原始量纲里同时学结构去除与预测。AdaRDiff 让"差分"本身成为端到端可学习的组件，预测模型只需处理平稳化残差。

## 相比前方法优势

- 相比手选阶差分/STL 分解：差分权重可学、周期不需预设，趋势+季节一个算子处理；
- 相比可逆归一化类技巧（RevIN 等）：差分作用在时间结构上而非统计量上，二者正交可叠加（此推断为设计层推断，正文未读、需赛内验证）；
- 闭式重建带来工程可行性：不是又一个慢模块，33.7 倍并行加速意味着赛期真实可用；
- 骨干无关：八个骨干"大多数"改善，作为 topping 风险低。
