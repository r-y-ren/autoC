# c117 실제 폐기 손실 확인

사용자 실행 진단16경기 완료. 원본 결과와 양쪽 행동 해시·보상·체크포인트·상점·정책
카운터가 일치함을 저장 결과에서 재확인했다. 무효·건강 검사 실패·정책 예외가 없고
양쪽 현금 장부 잔차도 모두0이다. 계측에 의해 관측된 행동이나 결과가 달라지지 않았다.

## 확인된 실제 손실

| 품목 | 16경기 합계 |
|---|---:|
| EGG | 76 |
| FERTILIZER | 36 |
| STRAWBERRY | 2 |
| 전체 | 114 |

이16경기는 창고 초과 예상 카운터가 양수인 조건을 골랐다. 7개 상대, 8개 상대/시드
조합, 독립 시드4개, 양쪽 좌석이다. 모든16경기에 폐기가 있었지만 전체 경기의 폐기
발생률이100%라는 뜻은 아니다. 표시 가격을 곱해 확정 회수 이익을 주장하지 않는다.

폐기 시점은 step623에서108개, step695에서4개, step599에서2개였다.
step623은0부터 센25일의 마지막 시간이다. 이 시점의16경기 모두 시장 거래 후
자동 입고 직전 창고 재고가0이었고, 일꾼들이 든 물량은102~108개였다.
전체20개 폐기 이벤트 중18개에서도 직전 창고 재고가0이었다.

## 원인과 개선 방향

공식 엔진은 일꾼 행동→시장 거래→상점 소비→일말 자동 입고 순으로 처리한다.
자정 자동 입고는 일꾼 순서대로 창고 용량100까지 넣고 나머지를 버린다.
step623의 대표 사례에서는12개의 밀과2개의 우유가 이미 거래된 뒤에도 운반 재고가
108개 남았고, 뒤쪽 일꾼이 든 달걀6개·비료2개가 버려졌다.

따라서 핵심은 기존 창고에 남은 재고의 추가 판매가 아니라 **운반 중 물량을 거래 전에
입고·판매할 수 없었던 병목**이다. 비료 보유량을 무조건 줄이거나 판매 주문량만
늘리는 수정은 이 경우를 해결하지 못한다.

다음 후보의 단일 가설은 용량 초과가 예상되는 날 일부 물량을 더 일찍 내려놓고
판매해 일말 폐기를 줄이는 것이다. 먼저 실제 위치·남은 행동·수확 의무를 확인해야
한다. 자정에는 위치와 고용 상태가 초기화되므로 마지막 시간의 이동/PASS 대체를
검토할 수 있지만, 해당 일꾼이 창고 인접 위치에 있는지는 현재 장부로 확인되지 않는다.
인접 위치를 가정하거나 입고 성공을 예측만으로 단정하지 않는다.

일찍 운반하면서 놓친 수확·급식·비료 작업, 입력 재고 부족, 실제 체결 가격과 상대의
시장 이익을 포함해 비교한다. 실제 폐기 감소와 최종 승점 개선을 따로 측정한다.
이 손실은 개선 근거이지 최상위권과의 전체 성능 격차를 설명하는 증거는 아니다.
