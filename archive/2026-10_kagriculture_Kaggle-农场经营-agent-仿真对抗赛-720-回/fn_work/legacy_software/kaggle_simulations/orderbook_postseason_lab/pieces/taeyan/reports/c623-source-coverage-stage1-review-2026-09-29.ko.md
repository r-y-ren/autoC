# c623: 공개 상대 모델 추가 1차 검토

c623은 24경기(기준 12개 재사용, 후보 12개 새 실행)를 완료했다. 12조건에서 기존 12승을 모두 유지했고 승리 전환은 아직 없다. 평균 자기 현금 +56.5, 상대와의 점수차 +111.83이다. 최신 Harvest V87을 만난 세 세계에서만 변했고, 점수차 개선은 각각 +108·+513·+721이다. 다른 상대의 9조건은 행동과 양쪽 전체 경제가 그대로다.

전 경기의 719회 실제 호출, 전체 상태, 공식 누적 시간, 양쪽 콜백과 리플레이 행동 해시, 현금 원장을 확인했다. 후보 응답 8,628개와 관측 불변성이 일치하며 새 급식 실패·무효 명령·자금 부족·종료 결함이 없다. 생산·폐기 등 원 비교 검사도 통과했다.

다만 원 완료 기록의 execution_pass는 false이며 그대로 보존한다. 1352831483 세계에서 새 상대 모델이 435턴에 제거되어, 이번 감사에 넣은 ‘상대 모델이 719턴 내내 남아 있어야 한다’ 조건을 충족하지 못했다. 별도 저장 기록 진단에서는 사용된 435회 상대 행동과 비공개 상태가 모두 정확했다. 434턴의 기존 토마토 투자 후처리가 예측 계산 후 토마토 씨앗 5개와 고용 주문을 추가했고, 다음 공개 상태가 저장 예측과 달라져 모델이 제거됐다. 최종 자기 행동으로 계산하면 실제 전이와 일치한다. 제거 후 그 모델의 예측은 사용하지 않았다.

따라서 이 현상은 실제 명령이나 기록의 무결성 오류가 아니라 대응 범위가 짧아지는 한계로 판단했다. 원 실패를 통과로 덮거나 정책을 고치지 않고, 별도의 소유자 상대승률 검토에서 확대 검증을 지지했다. 적용 세계가 모두 노출됐고 개선은 한 상대에만 있으므로 아직 채택 근거는 완성되지 않았다.

c624는 같은 소스9605abd8과 압축파일95abe368을 유지한다. 모델이 제거된 기존 세계를 남기고, 결과를 보지 않고 선택한 새 세계379291030·480749602를 추가한다. 상대는 Harvest V87·Forecast·TTV·Lucas에 Demand·Shepherd를 더한 6개이며 총36경기다. 9경기와 4개 비교 감사를 재사용하고 27경기만 새로 실행한다. CPU 워커8개, 모델 하위 작업자0개다.

현재 공개 노트북 4개의 최종 전체 바이트를 기존 검토본과 대조했다. 최신 Harvest1612.5·TTV2127.2는 조회 시점의 연결 제출 점수이며, Shepherd는 연결 점수가 없어 강도를 단정하지 않는다. Forecast/Lucas는 역사 대조군이고 계보 중복 한계도 유지한다. 새로 조회한 Master 제목의 노트북은 실제 TTV와 동일한 소스를 만들기 때문에 별도 상대 수에 포함하지 않았다. 첫 Demand TLS 오류와 일반 추출기의 부수파일 충돌 오류는 보존하고, 정확히 동일한 전체 노트북과 기존 최종 읽기 검증을 재사용했다.

현재 채택은 c614/local370이다. c624의 새 세계 결과·손실·실행을 검토하고 QA·등록본 읽기 검증·두 단계의 모든 유효 경기 편입까지 끝나야 새 채택을 판단한다. 캐글 제출은 하지 않았으며 새 명시승인이 필요하다.
