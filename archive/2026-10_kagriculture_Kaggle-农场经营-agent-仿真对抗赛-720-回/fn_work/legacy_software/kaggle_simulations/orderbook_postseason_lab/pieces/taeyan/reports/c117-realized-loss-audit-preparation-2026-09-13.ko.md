# c117 경제 손실 진단 준비

사용자가 c122 가설 검증 384경기를 실행하는 동안 독립적으로 진행한 개선 준비다.
c122·c117의 정책, 공통 실행기, 기존 경기 파일은 수정하지 않았다. 아직 새로운
정책의 성능 개선을 주장할 근거는 없으며, 실제 손실의 원인을 먼저 측정한다.

## 저장 기록에서 확인한 신호

c117의 완료된 외부 192경기 중 77경기에 `warehouse_projected_unresolved`가
양수였다. 합계 454, 경기별 최대 10이다. 이것은 부모 정책이 계산한 창고 초과
예상량의 누적 카운터이며 실제 버려진 수량이나 회수 가능한 이익이 아니다.
해당 패널의 `input_stock_shortfalls`는 0이었다.

부모 `_r51_close_warehouse`는 12~28일 마지막 시간에 품목 판매와 밀 예약을
고려하지만 입력 의무가 있는 비료를 추가 판매하지 않는다. 이 사실만으로 비료를
팔아도 된다고 결론내릴 수 없다. 뒤의 정책 계층이 명령을 바꿀 수 있고, 실제로
버려지는 것이 저가 밀인지 고가 생산물인지도 구별해야 한다.

## 준비한 도구

`state/agent_experiments/c117_realized_loss_audit_20260913/`:

- `run_audit.py`: 공식 엔진의 실제 거래 체결, 고용·토지 지출, 수확·급식·비료
  사용에 따른 재고 변화, 일말 창고 자동 입고 중 실제 폐기량을 관측한다.
- `manifest.json`: 원본 c117 해시, 기존 job/result, 상대 소스, 실행기와 엔진을 고정한다.
- `run_loss_audit.ps1`: 사용자 실행, 중복 평가 방지, 완료·실패 알림과 소리.

양수 카운터가 있는 상대/시드 조합 중 상대를 순회하며 8조합을 선택하고 양쪽
좌석을 포함했다. 7개 상대, 총 16경기다. 이미 관측한 발견용 조건을 의도적으로
고른 원인 분석이며 일반화 평가나 무작위 손실률 추정이 아니다.

각 진단은 실제 반응형 원본 경기를 다시 실행한다. 기록 기능을 추가했을 때도
기존 결과의 양쪽 행동 해시·최종 보상·상태·체크포인트·상점·정책 카운터가 같아야
한다. 다르면 원인 해석을 중단한다. 현금은 초기 현금과 모든 실제 거래·고용·토지
지출 합계로 최종 보상과 정확히 맞아야 한다. 함수는 실행 후 복원되며 별도 프로세스에서
실행한다. 정책에 진단의 상대 비공개 정보나 미래 정보를 전달하지 않는다.

Python AST와 PowerShell 파서 검사는 통과했다. 실제 계측 실행과 무변경 비교는
아직 사용자 실행 전이다. 계측 비용이 시간 제한에 영향을 줄 수도 있어 실행 검증이
필요하다. 기존 성공 기록을 보존하며 일치 실패를 숨기거나 기준을 낮추지 않는다.

## 결과에 따른 개선 분기

1. 실제 폐기가 없으면 창고 보호를 성능 개선 가설에서 제외하고 예상량 카운터의
   정확도 문제로 분리한다.
2. 실제 폐기가 있으면 날짜·품목·운반자·당시 창고 구성을 확인한다. 필요 재고를
   팔거나 경쟁 상대의 시장을 유리하게 만들지 않는지 별도 반응형 비교가 필요하다.
3. 고가 생산물의 폐기가 반복되면 보관 여유 확보 또는 운반 시점 개선 중 하나를
   c117의 별도 파생 후보로 구현한다. 급식·비료·개막·판매를 동시에 바꾸지 않는다.
4. 버려진 품목의 수량이나 표시 가격을 그대로 개선 가능 수익으로 취급하지 않는다.
   체결 가격 변화, 대체 노동, 실제 회수 가능성을 포함해 검증한다.

현재 c122 실행이 우선이며, 이 진단은 c122 완료 후 다음 명령으로 실행할 수 있다.

```powershell
Set-Location 'H:\dev\kaggle-data\kaggriculture-strategy-meta'
& '.\state\agent_experiments\c117_realized_loss_audit_20260913\run_loss_audit.ps1'
```

완료 표시는 `DONE: ...c117_realized_loss_audit_20260913/results.json`이다.
강제 종료로 잠금 파일이 남으면 실제 관련 프로세스가 종료됐는지 확인한 후 처리한다.
