# c328 — 다음 두 턴 상대 순매도 학습

판정: 사전 기준 FAIL. 우유·딸기의 예측 개선은 관측됐지만 양털은 clock/market 대조군보다 악화했다. 정책 적용·추가 확인·새 게임 시뮬레이션·제출 없음. 기준선 public v9/4 유지, 보호 blind 7240–7255 미사용.

## 이전 시도와 달라진 점

c315/c316은 먼 미래 생산량 예측이 별도 자료에서 실패했다. c326은 내장 단기 매도 예측의 낮은 정밀도를 확인했지만, 그 예측을 제한한 정책은 실제 승점을 크게 잃었다. c327은 최종 자기 행동을 반영한 상대 매도 관측을 수리했으나 승률 개선은 없었다. 따라서 관측 정확성·예측 정확성·행동 가치를 분리한다.

c328은 기존 c316의 정확 원장 203경기와 c308 특징 추출기를 재사용한다. 시즌 전체 생산 대신 관측 t 이후 t+1,t+2의 실제 순시장 유입 합계가 4u 이상인지 학습한다. 현재 동시 행동 t는 대상에서 제외했다. SELL은 가격>1일 때만 시장 유입으로 세고 BUY_PRODUCT는 뺀다. 관측 가능한 과거 매도 추정은 최종 자기 행동과 시장 변화로 계산하며, 원장의 정답으로 보정하지 않는다.

## 자료·구현 감사

- 훈련 179경기/양좌석 196,900행, 평가 24경기/한 좌석 13,200행. 관측 t=150..699. 양측 제출 버전·경기·시드가 두 집합 사이에 겹치지 않는다.
- 훈련 71버전, 평가 양측 합계 25버전. 버전 분리가 계보 분리를 뜻하지 않는다. 평가 24경기는 c316에서 장기 예측에 이미 관측된 자료이므로 새로운 blind 확인이라고 부르지 않는다.
- 리플레이 해시·엔진·원장 재현·현금 잔차·API 좌석 보상 확인. 203개 재추출 배열 전부 최초 산출물과 값 동일.
- 자기 매도 투영 801,054건 중 오차 1, 사용 가능한 상대 순유입 742,033건 중 오차 1. 사전 허용 상한 1% 아래. 오류는 훈련 경기 110241766, 좌석0, t694의 딸기 6u 예측/실제2u. 투영 창고가 용량100에 도달한 사례이며 정확 원인을 추가로 증명한 것은 아니다. 자료에서 제거하거나 정답으로 덮어쓰지 않았다.
- 특징 597개는 훈련 파일에서만 만든 스키마. 상대 비공개 재고·미래 행동·미래 상점·경기/제출 ID는 입력하지 않는다. 공개 농장/노동자 위치는 기존 c308에 이미 있던 특징이다. 시간/시장/상점 대조 특징은86개.
- 원본 추출은 numpy 정수의 JSON 저장에서 실패했고 v2는 자체생성 문자열 object-array 비교 로딩에서 실패했다. v3에서 저장 자료형만 수정했다. 원본·실패 계약/로그 보존.
- 첫 학습 실행은 로더가 압축 X를 열마다 반복 해제하여 모델 생성 전에 중단했다. v2는 파일당 한 번 읽는다. 데이터·RF 설정·판정 규칙 불변. 전체 RF 학습50.8초, 대조 RF7.2초, 각12jobs 순차 실행. 소스/모델 해시 전후 일치.

## 고정 모델과 결과

3출력 RandomForestClassifier: 64 trees, depth8, leaf32, max_features1.0, seed328. 전체 모델은 관측+추정 이력, 대조군은 전체 사건 빈도/일·시각 빈도/최근3일 같은 두 턴/clock-market RF. 모든 품목에서 모든 대조보다 Brier가 낮고, 경기 단위 bootstrap 95%의 전체 평균 개선 하한>0이어야 통과한다. Brier는 낮을수록 좋다.

- 우유: 전체 0.048857, clock-market 0.052331. Average precision 0.3849 대 0.2644.
- 양털: 전체 0.044619, clock-market 0.043881. Average precision 0.2647 대 0.2536. 정렬 지표 개선과 확률오차 개선은 다르다.
- 딸기: 전체 0.050567, clock-market 0.059421. Average precision 0.4803 대 0.2851.
- 전체 모델은 나머지 세 단순 대조보다 세 품목 모두 Brier가 낮다. 전체 평가 사건율은 우유6.30%, 양털5.27%, 딸기7.31%.
- clock-market 대비 품목 평균 Brier 개선 0.003863, 경기24개 묶음 bootstrap 95% [0.002440,0.005242]. 경기21/24에서 평균 개선. 13,200행을 독립 경기로 취급하지 않았다.
- 양털 조건 실패로 최종 FAIL. 성능이 좋은 두 품목만 사후 선택하거나 양털만 다른 모델로 바꾸지 않는다. 모델 확률 보정/설정 재탐색도 하지 않았다.

이 결과는 짧은 매도 예측에 관측 정보가 일부 도움이 된다는 제한된 증거다. 상대 반응의 반사실적 예측, 실제 판매정책 이득, 현재 상위권 우세는 입증하지 않는다. c326의 실패를 고려하면 예측 개선만으로 판매를 보류하거나 앞당길 근거도 부족하다.
