# c622 완료와 c623 공개 상대 모델 추가

c622는 수정된 Harvest V87 대 c614 저장 경로 3개를 정확히 복원했다. 경로마다 자기 행동 719개, 상대 행동과 비공개 재구성 각각 719개, 공개 상태 전이 718개가 일치했다. 제안 선택에는 현재 공개 관측과 소스로 재구성한 상태만 사용했고, 실제 상대의 행동과 비공개 상태는 사후 채점에만 사용했다.

개별 추가 대응 제안은 65개이며 자기 현금 변화 합 735, 상대와의 차이 변화 합 1,463이다. 세 세계별 상대차이 합은 430·333·700이고 불리한 개별 제안은 없었다. 이 합계는 고정 경로에서 각 제안을 따로 채점한 수치로 전체 경기 이익이나 승리 전환이 아니다.

완료된 실전 대조 5개를 재사용했고 모두 공개 첫 전이에서 새 모델이 탈락했다. 최대 −34,261 패배에 맞는 상대라는 근거도 없다. c620의 원 실패는 검증기의 마지막 행동 기록 오류로 보존했고, c622는 유효하게 복구된 c621 경로로만 완료했다. 같은 원 감사나 경기의 반복은 없었다.

기존 c526 공개 모델 확장은 전체 64조건 중 대상 상대 6조건에서 개선됐고 새 세계의 한 패배를 승리로 바꾼 전례가 있다. 이는 방법 선택의 근거일 뿐 새 모델의 효과를 입증하지 않는다. 이전 c586의 Harvest 8cff 소스는 제안 0이었고, 이번은 실제 최종 소스가 다른 V87 75f6이다.

c623은 현재 c614에 이 정확한 공개 소스 하나를 예측 후보로 추가한다. 생산·가격 조건은 바꾸지 않는다. 라이선스와 원 안내문을 압축파일에 보존했다. OFF 전체 행동, 최초 대응 가능 시점 이전 행동, 실전 대조 탈락, 기존 응답 방어 검사를 묶어 진행한다.

1차는 진단에 노출된 3세계와 최신 Harvest V87·Forecast·TTV·Lucas의 12조건, 두 정책 총 24경기다. 유효한 기준 12경기를 재사용하고 후보 12경기만 새로 실행한다. CPU 워커 8개이며 모델 하위 작업자는 없다. 공유 계보와 노출 세계 한계를 별도로 유지하고, 한 소스의 두 단계와 최신 상대 확대·새 비선별 세계·공식 누적 시간·양쪽 행동 해시·전체 실행·QA·모든 유효 기록 편입을 통과하기 전에는 채택하지 않는다.

현재 기준은 c621 정정 근거의 c614/local370이다. 캐글 제출은 없으며 새 소유자 승인이 필요하다.
