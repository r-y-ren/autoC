## 새 후보 c134

`agent/c134_input_tour_prefix.py`는 불변 c129에
`agent/overlays/c134_input_tour_prefix.py`를 붙인 독립 후보다.
SHA-256: `5ccb4c52acf8c27d13fcbf2001d545321e2e1af47611561bf8d20c4c96e8320e`.

코드 검토에서 기존 선택기는 비료 작업 경로를 탐욕적으로 늘린 뒤 전체 경로를 한 번에 수익성 평가한다는 점을 확인했다. 뒤쪽의 저효율 방문 때문에 앞부분의 유용한 방문까지 거절될 가능성이 있다. c134는 동일 경로의 3개 이상 방문으로 된 앞부분들을 비교하고, 기존 가격·수확량 예측·비용 1.5배 기준으로 더 유리한 부분을 선택한다. 동률이면 원래 경로를 유지한다.

실제 투입 전에는 기존 상위 제어기가 추가 비료 보충분, 다른 작업자 투입, 창고·현금·주문 한도를 다시 검사한다. 후보의 앞부분 비교에서는 이 추가 비용 전체를 반영하지 않으므로 그 검사가 필수다. 경로 변경은 추가 작업자 물류와 시장 공급을 바꿀 수 있어 반응형 검증이 필요하다. 비료 투입 부족의 원인을 이미 확정·해결했다는 뜻은 아니다.

현재 가격 예측을 새로 높이거나 수익 기준을 완화하지 않았다. 개막·부모 소스는 보존했다. 컴파일·재귀적 literal-exec 정적 검사 통과, **경기 검증 0회·미승격·미제출**이다. telemetry의 `input_prefix_prefix_choices`는 경로 선택 횟수이며 실제 고용·비료 적용 성공과 구분해야 한다.

c133 당근 전환, c132 사료 절감은 별개 후보로 비교한다. c132의 기존 최종 검증 실패는 유효하며 이 진단으로 자동 합격시키지 않는다.

- 19건 × c129/c132/c133/c134 = 76개 후보 진단.
- 신규 7건의 c125 대조 진단 + 실제 거래 원장 7개 = 추가 14작업.

결과에서 원본 재현·현금 원장 잔차0, 실행 오류·시간 위반, c133/c134 미발동 시 c129 완전 동일성을 확인한다. 패배 전체의 이득·퇴보와 c125 대비 c129 차이를 함께 보고한다. 오류가 있으면 결과를 저장한 뒤 실패 알림을 띄운다. 상점과 상대 행동을 고정한 진단은 실제 상위권 승률이 아니며, 통과한 가설만 새 시드·다양한 반응형 상대 평가로 넘긴다.

## 후속 판단 순서

1. 신규 7건의 원장으로 밀·당근·계란·축산물 매출과 사료·비료·고용 비용 차이를 확정한다.
2. c134의 작동·실제 비료 적용·수익 개선을 확인한다. 미발동 또는 손해면 그대로 기록하고 확대하지 않는다.
3. c133의 파종·수확 실현을 확인해 당근 전환 가설의 유효성을 판단한다.
4. c132는 평균 이득을 보존하면서 상대 가격 이득으로 생기는 퇴보를 별도 수정한다.
5. 거위·계란 증산은 관측 공급 부족과 정상 동선에서의 생산·수확 비용을 먼저 계산한 후 독립 후보로 검토한다.

이번에 새로 읽은 모든 시드는 연구용 관측 조건이다. 후보 승격에는 별도의 미관측 최종 평가가 필요하다.
