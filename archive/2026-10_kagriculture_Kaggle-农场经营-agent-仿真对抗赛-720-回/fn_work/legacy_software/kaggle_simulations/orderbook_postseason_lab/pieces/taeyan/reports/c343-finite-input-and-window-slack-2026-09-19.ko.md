# c343 — 실제 비료 수령과 구간 여유의 한계

c342의 위치 계약을 유지하면서 일부 비료 운반을 복구했지만, 선택된 생산 계획 전체는 실행 불가 상태다. 전략 강도 판정이나 제출 권고는 없다.

## 이전 시도와 이번 차이

c342는 모든 시작·끝·고용 위치가 같아도 시비 8회가 주머니 비료 부족으로, 식재 1회가 잡초로 실패했다. 기존 c170/c334의 시비 투어와 c321 계열의 관측 복구를 확인했다. 추가 일꾼이나 별도 비료 구매를 도입하지 않고, 이번에는 이미 예약된 경로의 PASS 또는 마지막 PASS 한 칸만 사용한다. 움직이는 경로를 한 칸 밀 경우 같은 구간의 끝 PASS를 소비하고, 고용 경계를 넘지 않는다.

현재 주머니 재고·창고 재고를 보고 다음 DROP 또는 기존 비료 PICKUP 전의 시비 요구만 충족하도록 유한 수량을 받는다. 잡초 칸의 PLANT는 뒤에 여유가 있을 때만 DIG 후 한 칸 미룰 수 있다. 소유하지 않은 원본 작업을 지우거나 순간이동하거나 가상 재고를 주지 않는다. 미래 자체 명령은 여전히 녹음에서 만들어진 연구 계획이며 배포 정책이 아니다.

## 공유 엔진 결과

수리 off의 필드 사건·현금·씨앗 대체·위치·출생 기록이 c342의 전체 결과와 동일했다. 수리 on에서는:

- 실제 PICKUP 4회, 비료 5u 수령. 요청한 수량이 모두 공식 엔진에서 체결됐다.
- 지역 시비 성공 3/11→7/11.
- 지역 수확 토마토 27→34, 당근 11→12. 목표 40/15에는 미달.
- 식재 실패 1회는 그대로다. 해당 1스텝 구간에 DIG와 PLANT를 모두 넣을 여유가 없다.
- 구간 시작 113·끝 113·출현 263 모두 원본과 일치.

추가 계측 재생에서 모든 유닛 작업의 실제 주머니·창고 상태를 기록했고, 직전 수리 on의 전체 기존 출력과 동일함을 확인했다. 공식 전체 재생은 off/on/행동 불변 계측의 3회이며 고유 세계 1개다. 독립 경기 표본이나 세 번의 개선 증거로 세지 않는다.

## 남은 구간의 최소 작업량

남은 실패가 있는 4구간에 대해 타일별 작업 순서를 보존하고 타일 간 순서는 자유롭게 바꾸며, 창고 어느 접근 칸에서나 한 번 비료를 받을 수 있는 정확한 최단 작업량을 계산했다. 비료는 부족하지 않다고 낙관적으로 가정했다. 작은 4문제는 모든 작업 순열을 별도로 열거한 결과와 일치했다.

- d21 actor2: 용량17, 최소12. 시작 시 실제 창고 비료5u. 기존 경로를 재정렬해 수령을 포함할 여지가 있다. 아직 그 재정렬 경로의 전체 게임 실행을 검증한 것은 아니다.
- d23 farmer: 용량10, 최소11. 현재 시작 재고0에서 이 배정을 실행할 수 없다.
- d23 actor7: 용량6, 최소7. 두 칸 시비에 필요한 PICKUP 한 칸이 부족하다.
- d24 actor7: 용량1, 최소2. 잡초 제거 후 식재가 불가능하다.

이는 **현재 구간 경계·작업 배정·도착 재고**의 불가능성이다. 이전 구간에서 비료를 미리 싣거나, 다른 일꾼/구간에 작업을 옮기거나, 다른 재배 계획을 택할 가능성을 기각한 것이 아니다. 전략 전체나 플래너 구조의 상한으로 해석하지 않는다.

## 판단과 다음 구현 조건

현 공동 모델은 작업 수만 맞추고 어떤 작업을 어느 재고의 일꾼에게 주는지 표현하지 않는다. 이것이 원인인데 모델을 그대로 둔 채 가격·물량만 다시 검색하지 않는다. 다음 c344는 시비·식재 등 작업 종류, 실제 PICKUP, 일꾼의 재고 흐름을 경로 선택에 포함하는 작은 모델부터 확인한다. 원본 KEEP 지원을 잃으면 그 모델을 수리해야 하며 원본이 나쁜 전략이라는 뜻이 아니다. 잡초는 미래 발생을 미리 보는 대신 관측 후 복구할 작업 여유가 필요하다.

현재 사후 모델의 상한이나 생산 회복은 기대 수익이 아니다. 양측 시장 주문 고정·씨앗 묶음 구매·미래 관측 구간이라는 c342 한계가 유지된다. v9 기준선, 보호 blind, 동결 후보·계약은 불변이고 새로운 강도 평가 0건이다.
