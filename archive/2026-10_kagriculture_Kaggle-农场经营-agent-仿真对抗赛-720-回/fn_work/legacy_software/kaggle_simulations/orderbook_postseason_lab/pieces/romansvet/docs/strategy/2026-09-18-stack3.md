## 5. Additivity

`PES − (PE + SPLIT − E)`, all vs FT2 on the same boards:

* POOLED169: 759 − (468 + 381 − 25) = **−65** (se of the pooled statistic 157)
* 241: 665 − (418 + 348 − 27) = **−74** (se 129)

The two arms are **additive to the noise**: PUMPCLIP's opening and the terminal-day
route stack touch different days and do not fight. The interaction is half a
standard error, negative in sign but unmeasurable. This is the same reading STACK1
got for PUMPCLIP × ENDROUTE, now with the two extra route switches on top.

PES's variance is PUMPCLIP's (sd ~2,000/board) and its t comes from the mean, not
from SPLIT's tightness (sd ~550). The pair is worth more than either alone and the
coin bar falls out of PE's size, not SPLIT's precision.

Rule: SHIP if pooled d > 0 and t ≥ 3 over the **shipped E** and no class at t ≤ −2.

* PES vs E: POOLED169 **+733 t +4.68**, 241 **+638 t +4.93**, theirs +14 / +89 — **d > 0 and t ≥ 3 PASS**
* Classes: every POOLED169 leg positive; FRESH72 +444 t +1.94; engine class t −0.12 (28) / −1.30 (25 double-gated) — **no class at t ≤ −2 PASS**
* §115b coin bar (+450 and t ≥ 3) vs FT2: **+759 t +4.85 PASS** — PE alone missed it (+418 t 3.22 on 241), SPLIT alone missed it (+348, bar is +450)

**PES is the best upload of the three.** It beats PE by +247 t +6.19 and SPLIT by
+317 t +2.47 on the same 241 boards, it is the only one of the three that clears
§115b, and its rival-purse cost (+89/board on 241, +14 on POOLED169) is the smallest
per coin gained of the set: SPLIT alone hands the rival +131 for +348, PES hands
+89 for +665.

The one caveat carried forward, unchanged from STACK1: the engine class is neutral,
and it is neutral because two topleg3 boards lose ~67k each to PUMPCLIP's opening.
If we ever face that class often, the fix is those two boards, not this cell.

**No switch flipped, no tarball, no merge** — ship prep is a separate agent. The
default of all five switches is untouched on this branch; `S/stack3/run_pes.sh`
carries the exact PES string.

## 10. SHIP (2026-09-18, branch `stack3ship`)

`plan.ENDROUTE2_ON = True` and `plan.ENDROUTE2_SPLIT_ON = True`, on top of the
`stack1ship` PUMPCLIP tree — the PES cell of §2, flipped as one cell and not as
two switches, because §7 is the only form in which the two route arms and the
opening were ever measured together. The knobs are the judged ones and none
moved: `ENDROUTE2_SPLIT_TURN = O.SELL_TURNS[-1]` (18),
`ENDROUTE2_SPLIT_MIN_VALUE = 400`, `ENDROUTE2_SPLIT_MAX_TURNS = 9`.

**Gene block** [USER 2026-09-17: it carries EVERY shipped switch]. Both names
are appended to `plan.SWITCH_GENES` — `ENDROUTE2_ON` as column 13,
`ENDROUTE2_SPLIT_ON` as column 14 — and `policy.N_SWITCH_GENES` goes 13 → 15.
Both ride the VECTOR rather than the branch:

* ENDROUTE2 is a **BUDGET and a PRICE** — `turn_budget` and the hire scan's
  `per_unit` are int32 arrays every downstream site *compares* against
  (`labour`, `walk_u`, `_cut`'s `bud`), never a Python shape, so a gene-OFF day
  carries the `SELL_TURNS[-1] + 1` budget the DROP branch set;
* SPLIT is a **MASK plus three SCALARS** — `bank_day`, `bl_gain`, and the
  deadline/value/leg triple, whose gene-OFF values are exactly
  `O.SELL_TURNS[BANK_LOT]` / `BANK_MIN_VALUE` / `BANK_MAX_TURNS`, i.e. the three
  numbers `_routes`' `bank_late is None` arm already compared against.

Concrete OFF still computes nothing at all and hands `_routes` the narrow
3-tuple, so the *arity* — the one part of SPLIT that is shape and not value —
stays untraced and the shipped program is untraced rather than merely equal.

**The dependency moved from an assert to the vector.** ENDROUTE2 spends turns
into ENDROUTE's row and SPLIT spends ENDROUTE2's turns; the module asserted the
combination away, which a gene block cannot do — the ES draws all four columns
independently. `plan._sw_all` ANDs the requirement into the effective value, so
a draw that takes the row away takes its dependants with it and the search sees
the ENDROUTE-off program instead of an exception. The module-level asserts,
which police the tree that ships, are unchanged.

**LAYOUT**: widening `sw` shifts `g12` again, 7,494 → 7,560, and `N_PARAMS`
7,527 → **7,593**; `--train-only sw,swb` is 495 coordinates. The 7,065 prefix
rule is UNCHANGED, so the shipped 6,789 champion still pads with the whole block
zero and decodes to exactly these new defaults — `submission/theta.npy` is
untouched. A theta trained under the 7,428, 7,461 or 7,527 layout is not a
prefix of this one and must be remapped.
