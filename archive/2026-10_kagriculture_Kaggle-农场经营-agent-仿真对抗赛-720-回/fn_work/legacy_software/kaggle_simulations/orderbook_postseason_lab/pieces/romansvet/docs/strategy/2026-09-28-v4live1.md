## Method
- **Census.** `census.py` calls ListEpisodes fresh for 56612145 and 56634350, and reuses the LIVECENSUS2 cache for 56600971, which is retired. Replays come from the caches (S/v4live1/gz, livecensus2, livewatch22/21/19); only the 1 missing replay was fetched. Games are parsed with `S/livewatch22/lw22.py one()`.
  - h1 = the rival's money in our step-1 obs.
  - fam = the rival's d2 crops (lw22 `fam`).
  - fired = `v56obs`, the V56 h1 market signature.
- **Judge rows.** S/v4max1/res/seats.tsv: 170 v2-fired seats (band 120, faithful 41, pool 8, tapes 1), JC1 faithful flag, W base/arm. The mh4v2 arm fires the V56 kernel on every h1 <= 2,550, so on any listed value it equals the v3/v4g arm.
- **Estimators.**
  - LEVEL = 100 x sum_v share_v x (faithful arm W rate_v - live body W rate_v).
  - DELTA = 100 x sum_v share_v x (faithful arm - faithful base W rate_v).
  - share_v uses all 379 games, because rival h1 cash does not depend on our arm.
  - A value with 0 faithful seats contributes 0.
  - Bootstrap: 4000 draws, resampling live games and judge seats (and D18 seats for Table C) with replacement; 5th and 95th percentiles.
- **D18 rows.** S/handback2/res/D18.csv paired per label with S/handback1/res/base_v4g.csv (82 seats, W 54 -> 59).
