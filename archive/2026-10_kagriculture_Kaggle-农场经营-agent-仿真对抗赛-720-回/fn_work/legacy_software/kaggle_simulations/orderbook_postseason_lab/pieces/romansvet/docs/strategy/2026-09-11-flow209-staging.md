# flow209 / flow210 staged — the §73 block-SNR arm on two seeds, and why the settling test holds it

Staging box, 2026-09-11, ~50 min, CPU only. No GPU, engine legs, judge lock or ssh; nothing
launched or killed; `src/` untouched.

**Deliverables.** `S/flow209/launch_flow209.sh` (md5 `3d2df5f0f573d2013e2643473b5c1ac8`, GPU0,
seed = candidate B `flow193_g100_hr.npy` `7fcf3948`) and `S/flow210/launch_flow210.sh`
(md5 `87a7cba6c25979aa832e47d36b68c58d`, GPU1, seed = hr `flow172_g1000.npy` `f091deb2` =
`theta.npy` extracted from `submission_flow172_g1000_pair_hr.tar.gz` `8274d577`). Both byte-derived
from `launch_flow206.sh` (`36fa34a2`); every rung, tape and gate board identical. Recipe and full
arithmetic: `S/flow209/README.md`.

**The nine changed tokens.** `--train-only gp,dh,ds,g5,gb5,w3,b3,b1` (**d_train = 1,191** of 5,997
live, measured with `train_mask × live_mask` in arms-next — §73's number exactly); `--sigma 0.01`;
`--optimizer sgd`; `--lr 1.8e-4` (‖g‖ on the subspace re-measured at **47.534**, ‖m‖ = 0.2294‖g‖ =
10.904, 0.002/10.904); `--weight-decay 4e-7` (= 1e-4·(1.8e-4/3e-3)², since decay here is
`(1−wd)·(θ+δ)` and not lr-scaled: pull 2.2e-6/gen = 0.11 % of the step, against 28 % at flow206's
1e-4); `--pop 4096`; the two seeds; `--seed 309/310`; the GPU default. Memory is set by `--chunk`,
not `--pop`, so pop 4096 is staged **with the current 179-episode rungs** — the price is 8× the
wall-clock per generation, not memory (assumption stated, not measured). `SEED_ROOM_PURSE_ON` is a
`plan.py` constant, not a flag: both scripts **guard** it, a busy GPU, a missing seed theta and an
existing `train.log`, and refuse to start on any mismatch.

**The settling test does not clear the block list (`S/snr/settling.py`).** §73's instrument does not
exist — `blocksnr.py` has no such option and `switch0/census.json` labels 56 *step directions*, not
the 1,024 eps pairs — so the label was rebuilt by decoding day-0 Macro at θ_B ± σε_i (the
`cos_ALL` column reproduces blocksnr to four digits). **0 of 1,024 pairs preserve B's day-0 Macro at
any training σ**: the literal test has an empty sample. Under the narrowest wall label (day-0 wheat
tile still 11) the §73 blocks and the cliff blocks keep the *same* share of their reference at
σ 0.01 (0.63 vs 0.66) and `gp`/`dh` **flip sign** at σ 0.02. Not a confirmation, and too
underpowered to be a falsification. **Staged, not launched; the launch decision is the user's.**
