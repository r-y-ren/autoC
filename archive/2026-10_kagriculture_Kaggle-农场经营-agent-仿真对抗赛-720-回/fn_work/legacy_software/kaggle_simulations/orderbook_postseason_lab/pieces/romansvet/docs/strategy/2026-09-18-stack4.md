## 5. Verdict — SHIP PESR

Rule for this agent: ship if the increment over PES has d > 0 with t ≥ 3 and no leg
at t ≤ −2.

* increment **+87 t +6.54** (POOLED169) / **+91 t +6.82** (241) — **d > 0, t ≥ 3 PASS**
* legs: +2.94 / +3.26 / +2.67 / +4.29 / +3.12, engine class +5.47 — **no leg t ≤ −2 PASS**
* two-purse: theirs **−36 / −39** a board — the increment is gift-negative, it takes
  coins off them as well as adding ours
* against the shipped E: **+821 t +5.26** / **+729 t +5.69**; §115b vs FT2 **+846 t +5.43**

**PESR is the best upload in this family**: it beats PES by +91 t +6.82, SPLIT by
+408 t +3.19 and E by +729 t +5.69 on the same 241 boards, and its POOLED169
rival-purse delta is −22, the first negative one of the set.

The caveat is PES's, carried forward unchanged: the engine class is neutral because
of two topleg3 boards that lose ~67k each to PUMPCLIP's opening. If we ever face that
class often, the fix is those two boards.
