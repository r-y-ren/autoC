## Commands

Build the exact live set from the checked live-game source.  `dl.sh` writes
`info.seed` to the adjacent `.seeds` sidecar; the BAND3 cutter and builder
verify both tape variants before writing judge inputs.

```bash
export JAX_PLATFORMS=cpu
jq -r '.[] | "\(.ep) \(.opp_seat)"' \
  S/livewatch10/games_56370365.json > S/band3/live250_epseat.txt
EPSEAT=S/band3/live250_epseat.txt bash S/band3/dl.sh
EPSEAT=S/band3/live250_epseat.txt P=6 bash S/band3/cut_all.sh
LIVE_GAMES=S/livewatch10/games_56370365.json \
  EPSEAT=S/band3/live250_epseat.txt EXPECT=250 \
  BASE_REGISTRY=S/winjudge/town_band3.json \
  IDS_OUT=S/actionrl/live250_ids.txt \
  REGISTRY_OUT=S/winjudge/town_live250.json \
  SELECTION_OUT=S/band3/live250_selection.json \
  .venv/bin/python S/band3/build_set.py
```

## Verdict

**MELONVETO_POST would have changed the live record, and harmed it: 166–84
would have become 163–87 (net −3 wins).**  The paired margin shift is small
relative to its uncertainty (`t=+1.15`) and does not rescue the adverse flip
count.  Keep MELONVETO_POST off for this shipped configuration.
