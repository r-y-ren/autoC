## 4. Verdict

**Flat-then-jump — the g100 pass was a lottery draw — with the g11–g99 interior permanently
unmeasurable.** The stop rule cannot have truncated a monotone climb, because no climb exists on
either side of g100: the remote gate reads 57.3 → 53.2 → 57.3 → 54.8 % and the held-out families
read −307 → +412 → −292 → −108 pooled coins vs the seed, a single positive excursion at one of four
sampled generations. B's advantage over its own seed was **never significant on the band**
(+412, t 1.51, 60 boards — under the §115 promotion bar of +450 with t ≥ 2); it cleared the stop rule
on a four-leg conjunction, and the two later draws from the same walk gave it all back while moving
in a direction **orthogonal** to the one that produced it (cos −0.02, +0.00). Net displacement is 34 %
of path length — below even diffusive scaling — so the 100-gen run is a confined walk on a fixed-norm
shell, not a directed search. A second, sharper defect surfaced: **the remote gate rejected B itself.**
At gen 111 g100 scored 57.3 %/+3,028 against the bar 57.3 %/+2,692 — identical win count (71/124, net
flips 0 < `min_flips 5`), 12 % more margin — and the `win` metric with `min_gain 0` discards ties, so
the gate is blind to margin and would never have surfaced the theta we shipped. B reached production
only because the watcher fetched the record file and judged it locally. E-A's premise ("its g100
passed everything") is therefore false as stated: g100 passed the *local* judge and was *refused* by
the remote gate, exactly as g10 was. The 10-gen stop rule is not the lever to fix here; the gate
metric is. UNVERIFIED: the flip decomposition behind g100's 71/124 (train.log prints only the totals),
and anything about generations 11–99, for which no artefact of any kind survives.
