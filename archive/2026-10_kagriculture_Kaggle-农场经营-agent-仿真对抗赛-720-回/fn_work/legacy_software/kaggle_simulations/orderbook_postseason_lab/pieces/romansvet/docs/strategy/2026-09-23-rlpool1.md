# RLPOOL1 — PPO fine-tune of head_940 against the REACTING public-notebook pool, real engine (2026-09-23)
Branch `rlpool1` (worktree `kagg3_wt_rlpool1`, from master 6d1b57b8). Code `S/rlpool1/`. plan.py / head.py untouched.

## Design
* **Why**: RLREVIEW1 — every PPO continuation (flow260-268) trained vs open-loop tapes/clones in the JAX sim, which pay volume that
  gifts. Here every rollout is a **real kaggle_environments game** vs an opponent that re-plans (notebook `main.py`), so the sim
  cannot be the thing learned.
* **Rollout** (`rollout.py`): our seat = shipped planner (`live_expert.SWITCHES` = cfog3 string) + a **sampling** head (numpy
  `head.forward_value`, per-slot categorical; records day/feats/acts/logp/V per dawn = 30 dawns/game). Opponent = file agent in
  its own module image (`eval_vs_baselines._play`). POOL1 lesson applied: `actTimeout=600` patched into every `make()`, any seat
  < 5,000 = `void` (never trained/gated; 0 so far).
* **Opponent mix** (`rlpool.py`): 30 % self-play vs the shipped tarball `dist/submission_res940_cfog3.tar.gz` (frozen head_940,
  unpacked to `S/rlpool1/selfopp/`); 70 % pool, of which 80 % uniform over the **V-series train labels + live V56**
  (v38, v34, v53, v41, v31, v25, nathanjacob pipe_8 fork, `S/v56leg/main.py`) — POOL1: V-series are the only families that beat
  us — and 20 % the other 17 train labels weighted by (public score − 1900).
* **Split** = ESPOOL1's `S/espool1/split.tsv`, copied verbatim to `S/rlpool1/split.tsv` (label level; 24 train / 12 held;
  held V-series = v39, v55, haideptry). Bank snapshot: POOL1 keep=1 (36 labels) → `S/rlpool1/bank/<label>/` (`meta.json`
  committed, code gitignored; `bank.tsv` = POOL1 rows).
* **Boards**: 50 % LIVE250 dev100 (idx 0..99, pinned seed+town, random seat), 50 % fresh seeds (drawn town). Held-out100
  (idx 150..249) never trained on.
* **Reward** (terminal, γ = 1, GAE λ 0.95 on the head's value): `sign(margin) + 0.1 · margin/1e4` — the win term dominates
  (a 10k margin = 0.1); no per-step shaping.
* **Update** (JAX on GPU1): clipped PPO 0.2 + **β = 0.1 · KL(π‖π_head940)** (trust region to the shipped head) − 0.001·entropy;
  value head on a stop-gradient trunk (value loss cannot move the policy); Adam lr 3e-5 linear→0.1×, grad clip 0.5,
  4 epochs × 4 minibatches, stop at approx-KL 0.01. Async: the worker pool stays saturated, every 24 finished games = 1 update
  (behaviour logp from the worker handles in-flight staleness). Checkpoint `head_<u>.npz` every 5 updates.
