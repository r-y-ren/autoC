## 3. The switch

`plan.ENDROUTE_ON` (OFF). One extra SELL row, **day 29 only**, on
`ENDROUTE_TURN` = **22** — day 29's last *executed* turn (`episodeSteps` 720, step
718; a turn-23 row would never resolve, and 22 is also the hour the engine class
itself liquidates on). It offers `ENDROUTE_ASK` = 100 units of every product,

SELL is clipped to the shed unit by unit (`_commit_unit`,

starve and no tomorrow for the quote it walks down. It is an **amount**, not a
price, so it cannot take a coin off any earlier row.

Seat-symmetric: the same nine product slots in the same order as every other SELL
row (`sim/market.py`'s `assert_no_cross`), emitted from the shared planner.

OFF, `endrow` is `None`, the row is not written and `rollout.MARKET_TURNS` is the
set it always resolved, so the champion decodes byte for byte:
`tests/test_endroute.py` pins whole-plan sha256 digests on five boards against a
