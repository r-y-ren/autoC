## Slack rules (engine `kaggriculture.py`)
* WATER, FEED, CARE, COLLECT_FERTILIZER: 0 — daily state reset at dusk (L776-783 plants die at 2 unwatered days, L811-834
  fed/cared/fertilizer_available reset; care bonus is one unit per cared+fed day, so a moved CARE is a lost unit).
  PICKUP/DROP/PLACE/DIG/BUILD: 0 (logistics tied to the day's tasks).
* HARVEST crop: earlier 1 if the same planting held >= the harvested units at dusk d-1 and age d-1 >= first_yield_day
  (L453); later 1 for a non-ongoing crop if age < max_yield_day (rot/decay from hour 0 of day planted+myd+1, L224,
  L752-766), for an ongoing crop if no decay by d+1 and units + tonight's production <= max_yield (L789-802).
  Animal: earlier as above; later if units + tonight's production (1 + care bonus) <= max_held (L822-828).
* FERTILIZE: covers d..d+2 (L481). Useful days = not already covered, plant alive, and in the water-bonus window
  (non-ongoing, L438-443) or a production dusk (ongoing, L797-800). Shift +-1 allowed if the shifted window still covers
  every useful day (and the plant exists on d-1 for earlier).
* PLANT (only in the HF+plant variant): later 1 if the crop still yields by d29; earlier 1 if the tile was empty all of
  d-1. The rest of the chain (waters, harvest) is not shifted — optimistic.
