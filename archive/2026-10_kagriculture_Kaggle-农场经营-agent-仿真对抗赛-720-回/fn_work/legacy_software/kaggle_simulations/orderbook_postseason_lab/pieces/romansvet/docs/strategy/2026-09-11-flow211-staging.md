## 3. The pinned-count decision

166 + 30 = **196 pinned rungs** against flow209's `--episodes 179`. Read from the trainer, not the
flag:

* `Trainer.pinned_block` (`src/kagg3/es/train.py:4413-4429`) returns **every** pinned rung and its
  docstring settles the tempting fix outright: *"Every pinned rung is in the block, including one at
  `--rung-weight 0` … the alternative — dropping weight-0 rungs to save an episode — would make the
  block's size depend on the weights, which is exactly the coupling the flag removes."*
  **Weighting the 85 old-band tapes 0 frees no episodes at all.**
* `pinned_keep` (`:4432-4443`) plays one episode per pinned rung and never truncates; the residual is
  `n_pairs = max((episodes − n_pinned) // 2, 1)` (`:4926`). At 196 pinned and 179 episodes the floor
  clamps to one pair: the run plays **198** episodes/gen and `scripts/train.py:186-195` prints a
  warning. No board is dropped — `--episodes` simply stops meaning what it says.

| option | episodes/gen | cost vs 178 | verdict |
|---|---:|---:|---|
| **(a) `--episodes 200`** — 196 pinned + 2 residual pairs | **200** | **+12.4 %** | **CHOSEN** |
| (b) leave 179, accept the clamp | 198 | +11.2 % | same price, a warning in the log and a 2-episode self-play tail. Worse bookkeeping for 1 % |
| (c) drop the 85 `w2` tapes out of `--tape-actions` | 179 | 0 % | **rejected** — 21 % of the objective removed and 68 residual episodes handed to an all-zero weight vector, i.e. to self-play (`:4547-4551`). §92 #3 asked for a `--rung-weight` change; (a) keeps the objective closest to that, (c) rewrites it |

Cost in full: 4096 × 200 = **819,200 rollouts/gen** against flow209's 4096 × 178 = 729,088 → **+12.4 %
wall-clock per generation**, nothing else. Device memory is set by `--chunk`, not `--pop` or
`--episodes` (flow209 README §MEMORY), so 200 episodes at pop 4096 changes no resident array. The
self-play tail shrinks 12 → 4 episodes (0.96 % → 0.25 %); at pool 1 that is 2 pairs against the
frozen `--init-theta` seed and the current centre, and it is under 1 % of the gradient either way.
The launcher **refuses** above 198 pinned rather than silently overspending; a NEXT60 swap needs
`--episodes 230`.
