# ACTIONRL11 — the WIDE-ASK residual head (BUILT, not launched) — 2026-09-20

**Why.** ENGTAIL/VOLUMEHI/OPSCENSUS put the whole high-band tail (−11.6k VOLUME,
−11.3k PRICE, all d10-19) on ONE number: the Macro plant **ASK**. `n_free` is
26-38 plantable tiles a day and `macro.plant_target` asks for 0-9
(`brain.py:1061-1094`, `n_dev = _qfloor(dev_frac·n_free)`); nothing refuses the
ask, the purse idles 15-39k from d16. The v1 head can move ±4 tiles a crop and
±2 hands — it cannot cross a 20-tile gap, and the two things that FUND a bigger
ask (crew turns, seed) were not in the action space at all.

## Layout table (`S/actionrl/head.py`, `HEAD_LAYOUT` / env `KAGG3_HEAD_LAYOUT`)

| slot | v1 (default) | wide |
|---|---|---|
| 0..4 `d_plant[crop]` | 9 acts, −4..+4 | **13 acts, −6..+6** |
| 5..7 `d_animal[kind]` | 5 acts, −2..+2 | 5 acts, −2..+2 |
| 8 `d_hire` | 5 acts, −2..+2 | **9 acts, −4..+4** |
| 9 `ask_fill` | — | **5 acts: keep / 25 / 50 / 75 / 100 % of `n_free` as a FLOOR on the day's total ask, d ≥ 10** |
| 10 `seed_buy` | — | **4 acts: keep / +1 / +2 / +4 units on the day's seed want** |
| 9..17 / 11..19 `hold_num` | 9×3 | 9×3 |
| **totals** | 18 slots, 92 logits | **20 slots, 125 logits** |

Default is `"v1"`, so `head_940.npz` and the shipped `res940` package are
byte-identical. The npz names its layout in a `_layout` field; `load()` reads
it, **strips it** (the trainer's Adam `tree_map`s every leaf — a bookkeeping
leaf inside the pytree would be differentiated and stepped) and falls back to
the `b3` width, which is unique (92 vs 125), for legacy heads. Every hot
function infers the layout from the array it is handed (`logits.shape[-1]`,
`acts.shape[-1]`), so both layouts live in one process and `numpy_fn` /
`jax_fn` / `gate.sh` / `package_submission.py` need **no** new plumbing.

## Splice points (`src/kagg3/core/plan.py`)

1. `RESIDUAL_PLANT_MAX_WIDE=6`, `RESIDUAL_HIRE_MAX_WIDE=4`, `RESIDUAL_ASK_STEPS=4`,
   `RESIDUAL_ASK_DAY0=10`, `RESIDUAL_SEED_MAX=4` (module constants, ~:1490).
2. `_residual_override` (~:7800) now returns **`(macro, d_hire, d_seed)`**. The
   wide block is guarded by a PYTHON `if "ask_fill" in o:`, so under v1 it is
   not in the traced expression at all and the shipped head decodes byte for
   byte. `ask_fill` floors `sum(plant_target)` at `k/4·n_free` (hour-0 empty
   tiles, the order-free whole-board count the features already show the head),
   clipped to `n_free`, all of it on `_residual_pref_crop` (argmax of the ask,
   ties low) — a VOLUME move, not a mix move. Refused when the day's own ask is
   zero (the `_fill_plant` law: never invent a crop the gene ruled out) and
   before `RESIDUAL_ASK_DAY0`.
3. `_residual_seed_extra` (new, after `_residual_override`): `_rebuy_extra`'s
   shape for the seed rows — extra units priced on the grant's own quote curve
   (`costs[L_SEED0+c]`), paid out of what the walk LEFT, only where
   `fill_target > seeds + granted` (past that `plant_eff = min(fill_target,
   seeds+seed_buy)` makes it dead money), crops walked in index order with the
   purse deducted between them.
4. `_derive(..., seed_extra=None)`: applied right after
   `seed_buy = n_buy[L_SEED0:...]`, and `purse_left` is reduced by what it
   spent. All three `_derive` call sites pass `seed_extra=d_seed`.
5. `_plan_and_stats` (~:10275): `d_seed` carried alongside `d_hire`.
