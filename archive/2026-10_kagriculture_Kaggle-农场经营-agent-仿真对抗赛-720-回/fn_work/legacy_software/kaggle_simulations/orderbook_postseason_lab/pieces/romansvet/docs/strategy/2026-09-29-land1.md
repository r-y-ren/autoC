## 2. PFS's land machinery (master 8d670dad `src/kagg3/core/plan.py` `_derive`, L10671-10797; `brain.py` L1113-1135)
- **Trigger (no day constant anywhere).** `buy_land = nquad < 4 & ~terminal & money >= land_gap & money >= price // LAND_OWN_DEN (2) & land_value + land_bias > 0`,
  where `money` = hour-0 purse net of the day's hire bill and tomorrow's crew reserve, `land_gap = max(price - rev1, 0)` (rev1 = 3/4 of the day's projected
  sales, `LAND_REV_NUM/DEN`; BUY_LAND rides the spare tenth slot of the first SELL turn, after the sells), `land_value` = `BUD.marginal_gain` of the seed /
  animal ranks the 25 new tiles admit, capped by the tiles the crew can reach (`land_reach`), and `land_bias` = the brain gene
  `price x tanh(head[1] + aux[1] x afford) // 256 x 256` (theta7659, not a switch). Order and prices are the engine's: NE 1,000 -> SW 2,000 -> SE 4,000.
- **Existing overrides (all OFF in the shipped string; none sets the Q2/Q3 day):** `PLANT_ASK_QUAD` (Q4 only, d10-19), `Q4_PROG_ON` (+`Q4_BUY_DAYS` (10, 15),
  `Q4_BUY_KEEP`; Q4 only), `Q4_VRP_ON` (+`_DAY/_LAST/_RESERVE`; Q4 only), `MACRO_EXEC_ON` site 2 (a schedule JSON via `KAGG3_MACRO_JSON`, only under
  `MACRO_MODE` "full" / "hands_herd_land", which also rewrite the crew and the herd), the program engine's `land_target`. The shipped SWITCHES string
  (`S/actionrl/live_expert.py`) carries no land entry.
- Live result of that machinery: Q2 on d5 (18/21) / d6 (3/21), Q3 on d10 (21/21), Q4 never (section 1).

**New switch** (worktree `kagg3_wt_land1`, branch `land1`): `LAND_DAY="<q2_day>|<q3_day>|<reserve>"` (default `""` = OFF, one Python-false branch).
From `q2_day` (while 1 quadrant is owned) / `q3_day` (while 2 are owned) on, BUY_LAND on the first day `money >= land_gap + reserve`
(the same post-bill, post-crew-reserve purse plus the day's projected sales that the shipped gate and `Q4_PROG_ON` use), bypassing `land_value`;
99 = leave that quadrant to the shipped valuation. It only adds purchases (`max` with the shipped decision); PFS's own planting logic fills the tiles.
Default-off identity: 6/6 games (first 3 m40 boards x 2 seats vs g0capsfix, `res/rc/la_id_off.csv`) equal to the banked control
`S/judgerival1/res/g0capsfix/pfs.csv` on ours / theirs / o_h1 / t_h1 / o240 / t240 / o432 / t432.
