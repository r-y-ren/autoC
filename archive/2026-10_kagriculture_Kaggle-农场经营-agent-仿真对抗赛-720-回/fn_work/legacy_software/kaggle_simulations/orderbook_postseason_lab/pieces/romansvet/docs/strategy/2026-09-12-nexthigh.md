# NEXTHIGH — the 2780-2950 rung, and what B and hr do on it

2026-09-12. Built by the tape agent from `docs/strategy/2026-09-10-consensus.md §115`
(`docs/strategy/2026-09-12-promotion-rule-hr-slot.md`). Toolkit: `S/nexthigh/` (README there).

## 1. Why
No judge leg covered opponents rated **2750-2950**: NEXT30 (`S/nextband/`) tops out at 2750, TOPB2
starts at 2953, LIVE-C/BAND40 sit at 2350-2650. That gap is exactly the climb that is left — hr is
~2630, the top-10 cutoff is ~2967 — so every promotion verdict so far has been read either well
below the opposition we must beat or on the 2953-3081 tier we do not yet reach. NEXTHIGH fills it:
30 pinned-town tapes of teams whose **current** rating is 2780-2950.

## 2. The set
Leaderboard snapshot 2026-09-12T03:31Z (8,688 teams). 82 teams in 2780-2950; 75 survived the
episode/team/teamId exclusion set (3,906 episode ids, 938 team names, 193 teamIds — every existing
tape, ids file and town registry, rebuilt today so BAND40 is inside it); 34 sampled evenly across
the whole band; 4 refused by the second disjointness pass; **30 cut, verified and kept**, span
**2945.9 … 2782.0**. Every tape is that team's own seat in a **WIN of theirs** (30/30 wins, no
narrow-loss fallback), from an episode that ended 2026-09-12T02:30Z-03:37Z. We play the other seat.
The 2750-2780 fallback strip was **not needed** (the band had 75 fresh teams for 30 slots).

for 25 of the 34 picks those spellings differ. `S/nexthigh/dupteam_check.py` re-checks with the
ListEpisodes spelling and **refused 4 picks whose team already owns a cut tape** (all four TOP50
members cut 2026-09-11): QQ Farming 2949.2 (ep 107783403), Xiangyu Liu 2918.7 (107776180),

tape's own seat, and no tape replays a game we played. (BAND40 noted three such cases after the

## 3. Fidelity
`scripts/tape_opponent.py` replays every cut back over the recorded pre-states: **34/34 drawn and
34/34 pinned-town cuts verified byte-exact, 719 steps, 8 town unlocks each** (`S/nexthigh/cut/`,
and the `verify_drawn` / `verify_town` columns of `teams.csv`). `build_set.py` refuses anything
whose two verify lines are not both `verified`, or whose package / npz / town schedule is missing —
0 fidelity refusals (the only 4 refusals were the dupteam ones). The leg's registry
`S/nexthigh/town_schedules.json` is a **superset copy** of the shared
`S/band2100p/town_schedules.json` (582 rows, byte-equal) + the 30 new rows = **612**; the shared
file is untouched, and `S/nexthigh/town_append.sh` merges the 30 rows back in a quiet window.
`run.sh` refuses to start if any id is unregistered (an unregistered id would silently be played
with a *drawn* town — the failure mode the set exists to avoid).

## 6. What to do with it
* Run it on the next candidate: the column is the only read we have on the opposition between the
  hold-out band and the top tier.
* As a training rung family it is untested — 30 pinned rungs would collide with the launcher's
  `N_PINNED > 198` guard the same way BAND40 does; raise `--episodes` if a future arm wants it.
* The 4 refused cuts are spare tapes of teams already in TOP50; if a later set wants strictly more
  boards, take the leftovers of the 75-team band instead (45 unsampled teams remain).
