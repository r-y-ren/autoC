## 1. Optional-task ledger
* Where: `core/plan.py:_routes` tail sections TAIL_CARE (FEED/CARE hop), TAIL_FILL (COLLECT_FERT / WATER / DIG on
  non-admitted tiles), CARE_FILL (lone CARE). Under `ROUTE_VRP_OPT_ON` each tail op carries `unit_a` = 91/92/93 (unit_a is
  unused by all five ops: render, overflow guards, runtime ignore it) -> works in the jax sim day table and the numpy
  engine planner alike. Parity: 20 dev boards recorded with marks ON + OPT unused = mode ii exactly (95,846 / 91,846,
  15-5).
* Value = the runtime's own price of a displaced job, `overflow._job_cost` (V3 guard): CARE 0.5 x marginal product,
  COLLECT_FERT marginal fert, WATER 1-2 x marginal crop in window (INF when the plant would dry out), FEED/DIG = INF
  (mandatory). A stop is optional iff every op on it is marked and its value is finite.
* Census (dev20, per game): 70 all-tail stops, 69.4 of them lone WATER (value 33 each), 0.3 COLLECT_FERT (26), 2.3 INF
  (survival WATER / DIG / FEED). Tail CAREs land on tiles the block also works (mixed stops = mandatory).
* Rule (`mode2_opt`): try mode ii's drop first; if the hand's stops do not all fit, strip every optional stop,
  re-insert the hand's mandatory stops (must fit), re-insert the optionals by value desc; drop the hand iff the
  optionals left undone are worth < fib(hand). Left stops go to `Solver.skip` (construct / ruin-recreate never
  re-insert them). VERIFY (master) is relaxed ONLY for the exact (tile, op) multiset the solver left (`_OPT_LEFT`);
  every other planner (tile, op), access-tile and pickup-short check is unchanged.

but Δmargin t 0.65 (< 2), tapes 0, faithful -1 -> fails the bar (dev net >= +1, FRESH margin t >= 2, faithful >= 0).

second solve (worst dawn 0.58 s > 0.5) and does not touch VERIFY's 64 fallback days -> stays OFF. Both switches remain
in the code, default OFF (byte-exact master). Optional-task slack inside mode ii is CLOSED as a lever; what is left
in the VRP is VERIFY's fallback days (harvest-sourced wheat pickups / h1 rows, ~3.2 days/game) and the cap on
mandatory work per hand.
