## 2. Formulation / solver (pure python, deterministic)
Task set = every op the planner's day table fires, merged per tile in planner order (a stop = tile, op list, duration).
Vehicles = farmer (4,4) from h0 + each hand from its spawn at hire hour + 1 (spawns solved to a fixed point on the
solver's own positions). One pickup visit per unit (1 turn per kind, before the first consuming stop; item available
at h0 if the dawn shed/seed stock minus h<=2 sells covers the day's use, else BUY row hour + 1). Windows: harvest of a
plant rotting today no later than the planner's hour; land-day tiles from BUY_LAND hour + 1. Units with a mid-day
product DROP/PLACE (same-day sale lots) frozen; day 29 untouched (ENDROUTE drop + sale rows). Objective: sum of unit
finish times (+0.01 moves). Search: planner routes (or cheapest insertion) -> relocate + 2-opt -> ruin-recreate (100
iterations, seeded) ; mode ii drops the last-hired hand while every stop still fits (no optional tasks dropped).
