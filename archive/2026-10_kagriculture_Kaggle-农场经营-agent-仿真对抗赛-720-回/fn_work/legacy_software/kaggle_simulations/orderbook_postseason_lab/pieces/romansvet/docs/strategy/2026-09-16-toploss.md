halved: the same phase profile, the same four crop lines, the same melon unit
price to 1.3 coins, the same ops-per-unit-day deficit in d20-29. Nothing in the

boards (−13,663 on all 19), net −4,460 after the d20-29 recovery — 52 % of the
−8,620 median loss. Classification (a): the melon first-mover rent, already

(`brain.MELON_GENE_ON`, `brain.CROP_DAY_ON`) — **grep only, nothing built.**
