## 1. Method
- Boards: V56 held-out100 LOSS boards of the shipped stack (`S/endfix1/heldout_on.csv`, win=0), 10 smallest |margin|
  (−2 … −1,842) + 2 harder ones (159 −2,314, 207 −2,924). Opponent = live reacting V56 (`S/v56leg/main.py`)
  through `reacting_gate._job`, pinned seed/town/seat; head_940 + LATE_EXEC_ON; actTimeout lifted.
- Decision space = the residual head's own action (v1: d_plant[5], d_animal[3], d_hire, hold[9]). Candidates at
  dawn d = greedy + the best single-slot deviation per group (plant/animal/hire/hold) ranked by the head's log-prob
  drop, filtered for clamp no-ops; K=4. A deviation is forced on every head call of day d.
- Branching = `os.fork()` inside the engine run at the first head call of each day: a branch resumes the exact live
  state of engine, V56 module and our planner — no replay, no sim, shops pinned (true CRN). Every score is a real
  complete engine game (greedy continuation). Beam B=3 (identical purses deduped), days 0..29.
- Control: root greedy game reproduces `heldout_on.csv` **byte-exact on all 12 boards** (e.g. 231 118,732/118,734,
  165 79,917/80,099). Best prefixes of the 6 first boards re-played FROM SCRATCH (`--replay`): byte-exact 6/6.
- Cost: ~260 games/board, ~16 min wall/board at 3 workers (~23 s/game). 12 boards ≈ 3,100 games.

## 4. Verdict — (A), with a gate: our decision space DOES flip the close losses
The head's own action space flips 11/12 lost boards up to −2.3k against the live reacting clone, byte-exact and
replayable; our purse rises on 9/10, but 4/10 flips need the rival's drop. So "no action can flip these" is false; the gap is decision QUALITY per dawn,
and a label set exists. But the labels are sparse (2-11 dawns/board), board-specific, and a hand-distilled rule
loses. Next arm = **BESTRESP2 DAgger** (not a switch):
1. Label farm: run this search on the V56 dev/pool boards (loss AND win boards, ~260 games, 16 min each at 3
   workers; 2 boards in parallel = 7.5 boards/h). Label every dawn on the best path: (64-feature obs, slot, act);
   greedy dawns are labels too (act = greedy). DROP boards/dawns whose best-path Δtheirs > 0 ((b) of ALPHAPROBE).
2. Train: cross-entropy of head_940's slot logits toward the labelled act, KL-anchor to head_940 on unlabelled
   dawns (keep 90 %+ greedy agreement), hold slots excluded (inert).
3. DAgger: re-run the search from the NEW head's own greedy trajectory (the fork harness takes any head), add
   labels, retrain; 2-3 rounds.
4. Gate: the existing held-out100 V56 + pool + tape legs, wins and both purses; the hand rule above is the null.
Cost warning: search ≈ 260 engine games per board; 60 boards ≈ 8 h on 6 cores.
