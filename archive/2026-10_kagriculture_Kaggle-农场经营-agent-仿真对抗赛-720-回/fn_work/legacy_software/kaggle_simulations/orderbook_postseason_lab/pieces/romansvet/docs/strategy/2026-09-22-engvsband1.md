Comparison is mean/game: first 150 manifest-order BAND games with exact engine cash closure (3 terminal-mismatch raws excluded/replaced) versus all 107 reacting-V56 losses. Sales are successful engine commits; price is aggregate coins/units. Effective plant/fertilize and explicit PASS events use the same interpreter. This is descriptive across different cohorts, not a paired causal estimate.
