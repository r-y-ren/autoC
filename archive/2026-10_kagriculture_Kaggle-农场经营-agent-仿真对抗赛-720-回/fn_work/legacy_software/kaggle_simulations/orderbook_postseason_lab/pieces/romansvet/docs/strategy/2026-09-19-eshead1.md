## 1. What was built
* `scripts/train.py --residual HEAD.npz [--residual-head-py]` → `arm_residual_sim` sets
  `plan.RESIDUAL_ON/RESIDUAL_FN` **before the first trace** (`plan.residual_on()` is trace-time), so the
  head is compiled into the population eval, the archetype probe and the absolute report at once.
  **GREEDY**, not sampled: the judged and shipped agent is `head.numpy_fn` (argmax per slot), and
  sampling here would optimise theta against a policy nobody flies. Feature width asserted against
  `plan.RESIDUAL_N_FEAT` (64) and `head.N_FEAT`.
* **Seat rule** [ACTIONRL6]: `RESIDUAL_FN` has no seat argument and `rollout.run_day` builds both seats
  in one comprehension, seat 0 first — so the hook hands every SECOND call `head.noop_override`. Written
  as a **parity**, not `ppo.py`'s one-shot latch, because `rollout.episode` traces two day bodies (the
  scan and the shortened last day) and a latch would leak the head into the opponent of the second.
* `scripts/eval_vs_baselines.py --residual` (+ `--residual-head-py`): arms the head on the `--theta`
  seat in the parent AND through a `ProcessPoolExecutor(initializer=…)`, eagerly (`residual_on()`), because
  `_vendored_imports` strips `KAGG3_*` for the game. `RealGate` passes `--residual` straight through, so
  the gate's candidate is the agent `package_submission.py --residual` ships, not a head-off twin.
* `S/esgene/launch_local.sh`: `RESIDUAL=`, `GPU=`, `PY=` and a git-free root (the staging tree is an rsync).
