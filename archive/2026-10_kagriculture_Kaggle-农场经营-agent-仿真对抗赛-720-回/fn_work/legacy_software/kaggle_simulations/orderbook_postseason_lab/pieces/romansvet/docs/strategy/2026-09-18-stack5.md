## 4. Verdict

**Of the two the agent was asked to rank, CESR is the better upload — by a wide
margin — and it passes the ship rule over the shipped E.**

CESR vs the shipped E: **+538 t +8.87 on 241** (+551 t +7.13 on POOLED169),
every leg positive at t ≥ +2.24, engine class −285 t −0.39 → **d > 0 PASS,
t ≥ 3 PASS, no class at t ≤ −2 PASS**.

PESR fails the last clause where it matters for *this* goal. PESR beats CESR by
+191 a board on our own 241 (t −1.57 against CESR, its only real leg being
BAND180 at −706 t −2.96), and loses to CESR by **+49,342 a board on the engine
class at t +6.62**. We are 2,130 trying to reach 3,000+: the boards that decide
that climb are exactly the ones PESR gives away 49k on. PESR buys ~200 coins a
board from opponents we already beat 86 % of the time and pays two −67k
catastrophes against the class we need to beat. **Do not upload PESR.**

**But neither is the best arm in the tree.** `ESR = CESR − CLIP_CAP_ON` is
+738 t +6.26 on the engine class with **zero negative boards**, and it gives up
only +88 t +1.82 on the 241. For a climb from 2,130 toward 3,000+ the ranking is

> **ESR > CESR ≫ PESR**

and the honest recommendation is to upload **ESR**, with CESR as the fallback if
the band coin is judged to matter more than the engine tail. Both clear §115b
against FT2 (ESR +514 t +11.54, CESR +577 t +7.47) and both clear the ship rule
over E (ESR +450 t +12.61, CESR +538 t +8.87). The single question separating
them is one −18,144 board, and it is `CLIP_CAP_ON`'s.

The natural next cell is therefore `CLIP_CAP_ON` alone on top of ESR, judged on
the engine class board by board — the same autopsy `blowup` did for the pump.

**No switch flipped, no tarball, no merge to master.** `plan.CLIP_CAP_ON`,
`plan.ENDROUTE2_ON`, `plan.ENDROUTE2_SPLIT_ON` and `plan.ENDROUTE_ROW2_ON` all
stay `False` on this branch; the runner carries the strings.

**Gene block** [USER 2026-09-17: it carries EVERY shipped switch].
`ENDROUTE_ROW2_ON` is appended to `plan.SWITCH_GENES` as **column 15** and
`policy.N_SWITCH_GENES` goes **15 → 16**. `OPEN_PUMP_ON` and `CLIP_CAP_ON`
**keep columns 11 and 12** — a zero gene decodes to the module default whatever
that default currently is, so the block still carries both and the search can
take either back without a layout change. The new row rides the VECTOR like the
three before it: it is an AMOUNT, so a gene that asks for the flip zeroes
`endrow2`, every slot stays `MO_NONE` and the day is the OFF day byte for byte.

**The dependency moved from an assert to the vector**, exactly as PES's two
did. ROW2 splits ENDROUTE's row, so without the first row there is nothing to
split; `plan._sw_all(_sw(macro, "ENDROUTE_ROW2_ON"), _er_on)` ANDs the
requirement into the effective value, and a draw that takes the first row away
takes the second with it and decodes the ENDROUTE-off program instead of
raising. The module-level assert, which polices the tree that ships, is
unchanged.

**LAYOUT**: widening `sw` shifts `g12` again, 7,560 → 7,593, and `N_PARAMS`
