## The leg

`S/loss12/run.sh <theta-name> [worktree] [theta.npy]` — mirrors `S/lossflip/run.sh`, but with the
`on2b.py` invocation from `S/carepin/run.sh`:

    KAGG3_TOWN_SCHEDULE=$S/band2100p/town_schedules.json PYTHONPATH=$WT/src \
    .venv/bin/python $S/drainpin/on2b.py "OPEN_PUMP_ON=True" --theta <theta> \
      --games 1 --workers 8 --seed-base 777001 --seed-per-opponent \
      --csv $S/lossflip/<name>_loss12.csv --opponents <12 from S/loss12/ids.txt, in file order>

12 tapes x 2 seats = **24 games**. Writes `S/lossflip/<name>_loss12.csv`, `S/loss12/<name>.log`,
`S/loss12/<name>.summary` (truncated per invocation, history in `.summary.history`, ends
`LOSS12DONE`). `S/loss12/flips.py <name>` prints, against the `flow135_g350` base csv:

    LOSS12 (12 ids, 24 games): base win X -> Y  FLIPS +a DROPS -b  d-margin Z

and `LOSS12: no base` (missing base csv) or `LOSS12: no csv <path>` (leg wrote nothing) instead of
failing. **`ids.txt` order is load-bearing**: `--seed-per-opponent` draws
`seed_base + SEED_STRIDE*(i+1)` off the list *index*, so loss12 rows pair only with other loss12
rows, never with the full-panel `S/lossflip/<name>.csv`.

Wired into `S/judge/judge.sh` after the LEG20/held-out lines, **print only** — the LEG20 > 0 /
H_dm >= 0 gate that decides whether the six drawn legs run is untouched.
