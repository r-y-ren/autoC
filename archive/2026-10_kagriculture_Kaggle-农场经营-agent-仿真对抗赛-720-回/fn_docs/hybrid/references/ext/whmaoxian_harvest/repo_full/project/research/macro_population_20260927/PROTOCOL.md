# Macro population study, 2026-09-27

Research only. No automatic online submissions or release promotion.
All existing root and release sources are immutable.

Genome: crop rotation, livestock substitution, expansion threshold, daily hire cap,
and first-production care valuation. Market-selling parameters remain R2's.
Cap experiments preserve order positions and never remove existing workers.
An observed animal feeding emergency suspends the cap. These are hypotheses,
not assumed profitable changes. Macro execution failures remain in the evidence.

Generation 1: 24 genomes and three frozen reference versions, four fresh worlds,
six opponent implementations, both seats. Outcomes grouped by public programs,
locally reconstructed proxies, and direct reference. Proxies are not private leaders.
No opponent identity or experimental seed is exposed as a strategy input.
Each game audits actual harvest, sales, purchases, wages and land expenses;
terminal cash must equal opening cash plus revenue minus all observed costs.

Selection prioritizes paired public/proxy win points, then worst-family performance,
then paired margin, with direct R2 performance as a veto when below 0.5.
Generation 2 retains eligible elites and mutates/crosses macro genes on fresh worlds.
Any new final confirmation requires frozen source and the unused confirmation split.
A per-family win-rate regression larger than 0.05 prevents final promotion.
No local success certifies 2800 rating. Online calibration is still required.
Synthetic checks, repeated cases, cached rows, development and holdout are distinct.
