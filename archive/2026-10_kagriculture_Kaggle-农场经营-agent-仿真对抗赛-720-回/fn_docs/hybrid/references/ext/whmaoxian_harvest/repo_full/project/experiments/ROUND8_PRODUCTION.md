## 已确认的修复

原19株方案的缺陷不是单纯少雇一人。施肥、收获和交货必须一起计算：

- 原四工修订版以“全组必须在期限内做完并返仓”为前提，第27天直接拒绝整个班组，造成当日漏水、漏收。
- 三工收获可以采出152单位，但依赖午夜集中入仓会挤占100单位仓容；产量不等于可售数量。
- 三工施肥在真实雇工结束时点只剩20个动作，试验中每次只施肥16株。仅使用理想出生点核算21动作是不够的。

最终安排：18日三工种植；19/21/23日在全部植株昨天已浇水时安全跳过；20/22/24/28日双工浇水；25/26日四工浇水施肥；27日五工浇水、收获和交货；29日四工完成最后收获与交货。

第27日五条路线由纯空间搜索生成，目标包含移动、水、收、返仓、放货。搜索没有使用游戏胜负或独立验证种子。五条路线在参考出生点各需19–20动作，运行时再根据真实工人位置选择分组对应。每个目标保留剩余时间检查，无法完成的可选工作按目标跳过，不能因此取消已投入农田整天的维持工作。

资金紧张时优先保留能支付的浇水工人，再决定是否买肥。早期市场订单暂满会先等待原生雇工结束后的空位，避免过早把整天工作锁定为残缺班组。离线修改现金的功能断言：800金币保留2工不买肥，1200保留3工不买肥，2400保留4工并买肥；19个目标各分配一次。这些是局部请求断言，不是低现金整场生存保证。
