## 原则
- 当前排位回放仅用于诊断机制和构造功能断言，不作为泛化胜率。
- 策略只读取合法可见观察，不读取世界种子、对手身份、未公开未来商店或对方私有仓储。
- 开发24个世界、独立确认48个世界、备用48个世界，来自事先固定的哈希；按世界聚类，双方席位不是独立样本。
- 先写经济假设再试验；记录失败分支。比较同一世界、对手、席位下候选与V8的差值。
- 不用弱对手胜利冲淡强对手失败；逐对手类型报告。回放驱动代理不等同原作者自适应私有程序。
- 最终验证不用于再调参；多候选选择必须进行多重比较修正或新的独立确认。
- 官方线上积分和本地胜率不可直接换算。无3000分保证。
