## 3. 本轮实验（全部为本地实测）
| 方向 | 结果 |

| R2 开局 + 新引擎接手（第 12 天切换） | 从 0.52 修到约 0.74 倍，未能追平 |
| R2 + 高价时加雇饲养员 | 32 局全负，0.983 倍 |
| R2 + 空闲时就地照料/浇水 | 严格不亏但平均只多约 9 金币；就地收肥料有害 |

新引擎修过的主要漏洞（可供以后参考）：动物饿跑、作物渴死、成熟作物腐烂、夜间仓库溢出丢货、施肥不足、持续作物收获规则、杂草长期不除、肥料与小麦倒手、按当前价而非前瞻价选作物。

## 4. 发现的有用事实
- R2 的羊只有约 65% 天数喂食，牛 74–86%（隔天喂可存活，但少拿照料加成）。
- R2 有几十层嵌套补丁，内部有 `_CL_PARENT` 等全局名；新增层必须用独特前缀，否则会形成死循环。
- Kaggle 加载器取"最后新定义的可调用对象"，给 `agent` 重新赋值无效，要用新名字收尾。

## 9. 第五轮：收尾阶段

- 结论：组合方案的上限约等于 R2 本身；要超过 R2 需要新引擎在某个阶段做得比录像更好，目前没有做到。
