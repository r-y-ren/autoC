## 淘汰的融合实验

V53 与新回放预测模块在 19 个未参与构建的固定动作验证记录中，都为 17 胜 2 负；扩展的平均金币差仅提高约 52。对同一组 One More Wheat 真实代码，原 V53 为 4/12 胜，扩展后反而只有 2/12 胜。因此 **没有将自制回放扩展合入发布版**。这次实验否定了“加上前十销售历史就一定变强”的假设。

固定回放不会对我们的行为重新决策，这些诊断不是击败实时前十的证据。研究和验证按整场回放 ID 隔离；多队可能来自同一场，记录也不是全独立样本。
