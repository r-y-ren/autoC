## 改了什么
R3 = R2 原样 + 三个只减少浪费的附加层，不改变任何农场动作的路线：
1. **空闲补位**：雇工原地等待时，如果脚下动物当天未照料就照料，脚下作物未浇水就浇水（不移动，不收肥料）。
2. **夜间防溢出**：每天 22–23 点，若今晚自动卸货会超过仓库 100 格，先卖掉仓库里的肥料、小麦等便宜货，保住身上的收成。
3. **收尾清仓**：第 28 天 12 点起不再保留饲料小麦和肥料（之后的喂食、施肥效果都在比赛结束后才兑现），直接卖掉。
