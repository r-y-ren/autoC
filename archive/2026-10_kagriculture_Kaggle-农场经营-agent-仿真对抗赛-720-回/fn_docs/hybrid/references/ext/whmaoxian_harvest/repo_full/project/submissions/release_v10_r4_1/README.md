## 改了什么（相对 R4）
R4 的小麦规则是：只要"仓库 + 携带"超过 85 格，全天随时卖小麦。

错误分析发现，这条规则在小麦价格 35–39 时触发的卖出，事后多数又被原价买回，白白抵消了 R3 在镜像局里仅约 9 金币的领先。R4.1 因此改为：
- 白天只有当小麦价格不低于 40 时才提前卖；
- 22–23 点的防溢出保护照旧，不看价格；
- 肥料规则不变。
