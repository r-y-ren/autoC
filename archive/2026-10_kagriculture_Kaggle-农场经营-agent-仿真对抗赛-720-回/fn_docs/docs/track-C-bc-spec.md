# Track-C 规格：行为克隆（BC）→ 轻量 RL 微调（2026-09-20，ready-for-agent）

> 用户裁决原文："那就试试你说的：BC（从顶部回放行为克隆）→ 成了再轻量 RL 微调"。
> 本规格治理 Track-C 全轨；与终局程序（09-25 对结构决策/09-27 冻结/09-30 终交）并行互不侵占。

## Problem Statement

规则/规划两代路线（v13.x 启发式、v14.x DTSP）已把"选什么结构"修尽，但线上卡在 500-550 分段。跨代法证把残差定位到**day-11 后每回合微观执行效率的复利差**（island-ga 实证：同计划换调度器执行终局差一半；X-ray：榜首比中游少 10 个百分点的发呆回合；CARE 覆盖顶部 348 vs 我方 136-166）。v15 照抄 v48 波次剧本仍 0-16，证明差距不在计划层；v14.3 证明售卖时点对我方架构中性。**剩下唯一有证据支撑的杠杆：把顶部选手的逐回合决策直接学进来（BC），成了再用轻量 RL 微调收尾。**

## Solution

三段式加赛轨道，硬门不过不发射、失败零代价：

1. **M0 数据管线**：从官方回放（top-30 选手优先 + 本机已有语料高分席兜底）构造 (obs 摘要, 全部单位动作+市场订单) 训练对；克隆席过滤；特征/动作 schema 带版本号。
2. **M1-M2 训练**：监督 BC（小 MLP/tiny transformer），训练侧可用任意库；产出**纯 Python 前向推理**（权重硬编码 .py，满足 stdlib-only/离线/≤100MB/微秒级每步）。
3. **M3 评估与硬门**：孪生 d0 全季反事实对 v14.2 基线 + 塌方带 + v48 sanity + 打包/身份门；全过才消耗提交位（≤2 发，09-25/26 窗口）。
4. **M4（stretch，仅当 BC 过门且时间允许）**：轻量 PPO 微调（孪生自博弈 + v14.2 对手池，预算封顶），微调后必须重过全部硬门。

## User Stories

1. 作为协调者，我要一条与终局程序并行的 BC 轨道，以便不侵占 09-25/27/30 的既定决策节奏。
2. 作为数据工程，我要从官方 episodes 拉取 top-30 选手的 ≥60 局对局，以便训练语料覆盖当前 meta 强者。
3. 作为数据工程，我要按"turns 1-51 跨局 byte-identical"特征识别并剔除克隆席，以免学到泛滥的复制品。
4. 作为数据工程，我要特征/动作 schema 带版本号落盘，以便后续模型与数据可对齐复现。
5. 作为数据工程，我要在配额/带宽受限时降级到本机已有语料的高分对手席并如实记录覆盖面，以便管线不因外部依赖卡死。
6. 作为训练者，我要一个 CPU 可跑的小模型首跑（跑通优先于调优），以便 24 小时内拿到第一组对照数字。
7. 作为训练者，我要 bc_eval 评估 harness（BC 装进官方语义 callable，孪生 d0 全季对回放真实对手），以便每组实验都有同口径数字。
8. 作为训练者，我要行为诊断输出（移动率/PASS 率/CARE 次数/雇佣曲线），以便对照 X-ray 榜首带（53.8% 移动/3.8% PASS）定位"学没学到执行层"。
9. 作为训练者，我要克隆学习的市场订单头与单位动作头分组解耦，以便归因时能区分"学不会订单"与"学不会走位"。
10. 作为集成者，我要权重硬编码的纯 Python 推理模块，以便提交包满足 stdlib-only/离线/百 KB 级。
11. 作为集成者，我要推理确定性（同 obs 同动作、无集合迭代序依赖），以便沿用旗关黄金哈希纪律。
12. 作为集成者，我要独立于 v14.x chassis 的 standalone BC 包（不接 src/ 九模块），以便失败时不污染现役候选链。
13. 作为守门人，我要孪生 d0 反事实 26 局注入集上 BC 中位数 ≥ v14.2 的过线判据，以便发射决策有单一数字依据。
14. 作为守门人，我要塌方带判据（终局 <45k 局数 ≤2/26）与 escape/overflow 零异常，以免发射一个高方差炸弹。
15. 作为守门人，我要 v48 h2h sanity（8 局均值不劣于 v15 的 -84.7k），以免对顶级的差距进一步恶化。
16. 作为守门人，我要打包确定性/身份链/stdlib 扫描/100MB 限四件套照走，以便与仓库既有交付纪律一致。
17. 作为协调者，我要 BC 轨预算封顶 ≤2 个提交位（09-25/26 窗），以便任何失败都能零代价弃牌。
18. 作为协调者，我要 M4 RL 微调仅在 BC 过门后解锁且预算封顶（孪生自博弈 ≤12h 墙钟），微调产物必须重过全部硬门，以便 stretch 不反噬已得结果。
19. 作为合规守卫，我要训练只使用公开官方回放（Apache 2.0 竞赛数据），以便全程落在 host 明文允许面。
20. 作为复盘者，我要每组实验的数字与归因留痕（metrics 键 + 台账），以便赛后可审计这条轨的真实价值。
21. 作为多机协作，我要全部产物入库随 commit+push 同步，以便另一台机器可接力。

## Implementation Decisions

- **轨道目录**：全部新文件落 `software/bc_track/`（data/ 特征缓存走 gitignore；models/；scripts/），不改 src/ 九模块、planner/、现役 scripts/（只读复用）。
- **唯一测试缝（one seam）**：agent callable（obs → 单位动作+市场订单）——与本赛一切 bot 同缝；评估缝复用既有孪生 d0 全季注入协议（planner_offline_bench/twin），不新造缝。
- **standalone 而非嫁接**：BC v0 是独立 bot（自己吃 obs 吐全部动作），不嫁接 v14.x chassis；"BC 只做执行层先验、市场层沿用现役"的混合形态列为 M3 stretch 可选，不进主线。
- **数据**：官方 episodes（榜单 CSV 取 top-30 队名 → episodes 接口过滤/近期日集抽样）≥60 局；不足则本机语料高分席 ≥40 席兜底并披露覆盖面；克隆过滤按 1-51 步字节一致特征。
- **特征第一版从简**（钱/畜群计数/地块摘要/价格/库存/回合数/单位位置粗网格），动作=单位动作枚举 + 市场订单参数离散化；schema 版本化，改版必须重训不留旧模型。
- **训练侧自由、提交侧纯 Python**：训练可用 venv 任意库；交付物是把量化权重硬编码进 .py 的前向函数；禁 numpy 等依赖进包。
- **RL 微调（M4）**：仅 BC 过 A/B/C 门后解锁；PPO 在孪生自博弈 + {v14.2, v48 解码版} 对手池；≤12h 墙钟；产物重过全部硬门才可消耗提交位。
- **预算与终局隔离**：≤2 发提交（09-25/26 窗）；09-25 对结构决策、09-27 冻结、09-30 终交完全不受本轨结果影响（除非 BC 过门并线上验证优于现役，届时按既有晋级线裁决）。
- **合规**：只用公开官方回放（竞赛数据 Apache 2.0，host 明文"allowed and encouraged"）；提交 bot 禁网离线；不借鉴无 license 私有代码。

## Testing Decisions

- 只测外部行为：评估数字（同种子孪生对局终局资金/W-L）、推理确定性（同 obs 逐字节同输出）、打包确定性（build --check 逐字节）、stdlib 纯度扫描（包内 import 白名单）、100MB 限。
- 先例沿用：test_build_determinism（打包确定性）、test_planner_flagoff_equiv（黄金哈希思想→BC 的推理确定性）、twin_fidelity（评估 harness 口径）、test_candidate_identity（身份链）。
- 不测：网络内部权重/梯度、训练脚本细节、特征工程实现方式。

## Out of Scope

- 从零自博弈 RL（已按证据否决）。
- 触碰 v14.x chassis / src 九模块 / planner 现役文件。
- 取代或推迟终局程序（09-25/27/30 决策点）。
- 计划空间新轴、售卖竞速、波次剧本复活（均已裁决关闭）。
- 09-27 冻结后的任何行为变更（10 月只有加跑，无新提交）。
- 下载超出训练所需的大体量数据集全量镜像。
